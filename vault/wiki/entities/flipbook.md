# Flipbook

## Who or What
Flipbook is described as an experimental visual browser that generates each page as an image in real time, replacing conventional HTML elements with model-generated pixels. [src-2026-04-23-001]

## Why It Matters
It is a useful reference for the idea that agentic search, world knowledge, and generated multimodal interfaces could collapse browsing, explanation, and eventually action-taking into a single visual surface. [src-2026-04-23-001]
