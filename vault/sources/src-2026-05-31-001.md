# mapcn API Reference

## Summary
This source captures the `mapcn` API reference. It complements the earlier project-level source by documenting the actual component contract: `Map`, `useMap`, controls, markers, popups, routes, arcs, and clustered GeoJSON layers all compose around MapLibre GL while preserving access to MapLibre-style options and lower-level behavior. [src-2026-05-31-001]

## Key Claims
- The API reference confirms that `mapcn` stays close to MapLibre: the root `Map` extends MapLibre `MapOptions`, and many child components extend corresponding MapLibre option types while excluding props that would conflict with the component styling model. [src-2026-05-31-001]
- The core component anatomy is compositional: markers can contain custom content, labels, popups, and tooltips, while routes, arcs, popups, controls, and clusters can be layered inside the same `Map`. [src-2026-05-31-001]
- `useMap` provides direct access to the underlying MapLibre map instance and load state, which supports the project’s stated escape-hatch philosophy. [src-2026-05-31-001]
- The advanced components are not only decorative: `MapRoute`, `MapArc`, and `MapClusterLayer` expose interaction callbacks, MapLibre line styling, feature-state hover behavior, native clustering, and typed GeoJSON feature properties. [src-2026-05-31-001]
- Controlled viewport support through `viewport` and `onViewportChange` makes the map usable in application state flows rather than only as an uncontrolled embedded widget. [src-2026-05-31-001]
