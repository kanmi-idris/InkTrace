# Chrome DevTools MCP repository

## Summary
Chrome DevTools MCP gives an agent tools to control and inspect a live Chrome browser, including screenshots, console messages, network requests, and performance traces. [src-2026-11-04-024]

## Notes
The project officially supports Chrome and Chrome for Testing. It exposes browser content to the MCP client and enables usage statistics by default, with an opt-out flag. It can support a review loop, but does not itself guarantee visual judgment or fixes. [src-2026-11-04-024]
