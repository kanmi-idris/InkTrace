# Shapeshift GitHub README and architecture snapshot

## Summary
The Shapeshift README describes an offline-first text interface that converts natural-language input into typed cards. It separates optional Jev intent classification from deterministic parsing and a UI-stabilizing state machine. [src-2026-10-12-018]

## Key Claims
- The README lists 19 card types, including Event, Reminder, Checklist, Timer, Habit, Color, Split, Expense, Convert, Calculate, Trip, Poll, Contact, Bookmark, Countdown, Time zone, Random, Goal, and Note. The live site also displays 19 types. [src-2026-10-12-018] [src-2026-10-12-019]
- The README says TypeSafe AI's Jev answers 14 typed intent questions in one call, while deterministic code parses dates, amounts, units, and math. [src-2026-10-12-018]
- The README describes offline keyword classification by default and optional online Jev use. It says the API key stays on the server and the app falls back offline if the API is unavailable or rate-limited. These claims were not audited. [src-2026-10-12-018]
- The README says saved cards live in browser localStorage until deleted. [src-2026-10-12-018]
- A state machine stabilizes changes: a challenger must win twice or have very high confidence; signal badges use hysteresis. [src-2026-10-12-018]
- The README requires Bun 1.2+ and lists Next.js App Router, React 19, strict TypeScript, Tailwind CSS v4, shadcn/ui, Motion, chrono-node, and zod. It identifies an MIT license. [src-2026-10-12-018]
