# Demos

## Summary
This source captures the public GitHub repository page for `enzomanuelmangano/demos`, an ongoing collection of React Native animation demos built with Reanimated, Gesture Handler, and Skia. Its main value is as a living reference project for interaction patterns, animation techniques, and performance-oriented UI experiments inside an Expo-based React Native app. [src-2026-04-25-007]

## Key Claims
- The repository describes itself as an ongoing collection of React Native animations crafted with Reanimated, Gesture Handler, and Skia. [src-2026-04-25-007]
- The README points readers to `reactiive.io/demos` as the main browsing surface for the demo catalog. [src-2026-04-25-007]
- The project is presented as an Expo Go project, with a quick-start flow based on `bun install` followed by `bun ios` or `bun android`. [src-2026-04-25-007]
