# Async History Stack: undo and redo for asynchronous changes

## Summary
Async History Stack is a JavaScript and TypeScript library for change history. It separates undo and redo behavior from a particular state-management or editor library. The project repository documents asynchronous actions, cancellation, merging, and limits. [src-2026-10-06-004]

## Key Claims
- A pushed change supplies an apply function that returns a revert function. Both can be asynchronous. [src-2026-10-06-004]
- The API includes undo, redo, cancellation signals, merged entries, automatic merge windows, and a history limit. [src-2026-10-06-004]
- The repository lists MIT licensing and release v1.1.1. The X author describes the library as dependency-free. [src-2026-10-06-004]
