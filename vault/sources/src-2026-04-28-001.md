# SentrySearch

## Summary
This source captures the supplied repository page text for `ssrajadh/sentrysearch`, a semantic search tool for video footage that indexes clips with Gemini Embedding 2 or local Qwen3-VL embeddings and returns trimmed matches for text or image queries. Its main value is as a practical local-first video retrieval pipeline: chunk footage, embed it into a shared vector space, search semantically, and export clips without needing transcription or manual browsing. [src-2026-04-28-001]

## Key Claims
- SentrySearch presents itself as a semantic search system for video footage that can return trimmed clips from free-text or image queries. [src-2026-04-28-001]
- The described indexing pipeline chunks videos with overlap, embeds them with either Gemini or Qwen3-VL, stores vectors in local ChromaDB, and ranks search matches by cosine similarity in the same vector space. [src-2026-04-28-001]
- The tool explicitly supports image-based search queries, which it frames as useful for “find clips that look like this” cases where verbal description is awkward. [src-2026-04-28-001]
- The local backend is positioned as a private offline alternative using Qwen3-VL-Embedding, with automatic model selection between 8B and 2B variants based on hardware constraints. [src-2026-04-28-001]
- The README claims several performance and cost optimizations, including preprocessing, low frame sampling, MRL dimension truncation, optional quantization, and still-frame skipping. [src-2026-04-28-001]
- The project also includes a Tesla-specific metadata overlay mode that can burn speed, time, and optional reverse-geocoded location information onto the exported clips. [src-2026-04-28-001]
- The source emphasizes that embeddings from different models and backends are isolated in separate indexes so they cannot be accidentally mixed at search time. [src-2026-04-28-001]
- The README is unusually explicit about tradeoffs, including backend costs, hardware requirements, preview-status caveats for Gemini Embedding 2, and heuristic limitations around chunking and still-frame detection. [src-2026-04-28-001]
