# 10 GitHub repos so good they probably shouldn't be free

## Summary
Divyansh Tiwari's curated list of 10 open-source GitHub repos spanning AI provider routing (OmniRoute), Office automation (OfficeCLI), leaked system prompts, video editing (OpenCut), AI job search, meeting transcription (Meetily), algorithmic trading (Vibe-Trading), security scanning (Strix), self-hosted AI workspaces (Superpower), and web-to-LLM data extraction (Firecrawl). 11.7K views.

## Key Claims
- OmniRoute: one endpoint for 231 AI providers, 50+ free-tier, token compression 15–95%, automatic fallback. [src-2026-07-22-014]
- OfficeCLI: first Office suite built for AI agents — control Word, Excel, PowerPoint from a single CLI. No installation, one binary. [src-2026-07-22-014]
- System Prompts Leaks: leaked system prompts from Claude, GPT, Gemini, Grok, Cursor, Copilot, regularly updated. [src-2026-07-22-014]
- AI Job Search: Claude Code-powered agent that applies for jobs — analyzes listings, tailors resume, writes cover letters, prepares interview questions. [src-2026-07-22-014]
- Meetily: fully local meeting transcription/summarization (Whisper + Ollama), built in Rust. [src-2026-07-22-014]
- Vibe-Trading: natural language + AI agents for building and executing trading strategies (HKUDS). [src-2026-07-22-014]
- Strix: AI-powered open-source vulnerability scanner. [src-2026-07-22-014]
- Superpower: self-hosted AI workspace, 250k+ GitHub stars. [src-2026-07-22-014]
- All 10 repos are 100% open source and free. [src-2026-07-22-014]
