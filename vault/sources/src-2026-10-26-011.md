# TanStack Redact official product page

## Summary
TanStack describes Redact as a smaller synchronous runtime for React apps. Its current product page reports smaller client JS and CSS totals for starter apps across Start, Vite, Vinext, and Next.js. [src-2026-10-26-011]

## Key Claims
- The page lists TanStack Start, Vite, Vinext, and Next.js integrations. [src-2026-10-26-011]
- The page reports gzip client JS and CSS savings of 47.0 KB for Start, 48.1 KB for Vite, 39.3 KB for Vinext, and 35.7 KB for Next.js. [src-2026-10-26-011]
- It says Start and Vite can omit unused optional features; Vinext and Next.js use the full runtime to retain framework features. [src-2026-10-26-011]
- It says Redact renders synchronously without React's time slicing or interruptible component renders. [src-2026-10-26-011]
- It says React remains responsible for server rendering and Server Components in Vinext and Next.js, while Redact handles the browser. [src-2026-10-26-011]

## Notes
TanStack's launch blog clarifies that the bundle numbers are whole-build totals, include lazy chunks, and do not predict one page's download. [src-2026-10-26-012] The docs warn against treating bundle or microbenchmark results as whole-app speedups. [src-2026-10-26-013]
