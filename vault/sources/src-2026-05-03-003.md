# Principles of Building AI Agents (3rd Edition)

## Summary
This source is a Markdown conversion of Sam Bhagwat’s *Principles of Building AI Agents (3rd Edition)*. It reads like a compact field guide to modern agent construction, covering prompting, model and provider choice, tool calling, memory, MCP, graph-based workflows, RAG, multi-agent systems, and observability or evals from the perspective of someone building around the Mastra ecosystem. [src-2026-05-03-003]

## Key Claims
- The book treats agent building as a stack of concrete building blocks rather than a single framework feature set, including providers, models, prompts, tools, memory, and sandboxes. [src-2026-05-03-003]
- It frames MCP as a practical bridge between agents and tool ecosystems, alongside more traditional tool-calling patterns. [src-2026-05-03-003]
- It presents workflows, branching, suspend or resume behavior, and streaming as core orchestration concerns rather than optional implementation details. [src-2026-05-03-003]
- It treats RAG, alternatives to RAG, and multi-agent control flow as adjacent design choices within a broader agent-system toolbox. [src-2026-05-03-003]
- It gives observability and evals a full section, which signals that production agent work is not just about prompt quality but also about traces, cost, accuracy, and repeatable evaluation. [src-2026-05-03-003]
