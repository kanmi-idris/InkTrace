# Design Engineer Tools

## Summary
Design Engineer Tools is a curated directory of web-focused design-engineering resources by James Warner. Its value is not deep documentation for one tool, but a broad map of the space: inspiration libraries, AI coding tools, UI components, utility references, motion and interface tools, creative 3D and volumetric tools, and research or workflow software all live in one browsable collection. [src-2026-06-10-011]

## Key Claims
- The site explicitly positions itself as a list of useful tools for web-focused design engineers. [src-2026-06-10-011]
- The homepage presents the collection as a curated directory rather than a product landing page or editorial essay. [src-2026-06-10-011]
- Its visible structure spans both implementation and inspiration layers, including categories for AI code, components, utilities, interface, motion, 3D, audio, research, and organizational tooling. [src-2026-06-10-011]
- The directory’s tool mix suggests a design-engineering worldview that combines frontend production, motion craft, visual experimentation, creative tooling, and knowledge-work support rather than narrowing the role to UI coding alone. [src-2026-06-10-011]
