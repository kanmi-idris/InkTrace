# Expo Demos directory

## Summary
Expo's Demos page is a directory of 30 mobile and web UI demos. It offers filters for patterns such as gestures, navigation, animation, 3D, WebGPU, forms, menus, tabs, and widgets. The page lists demo titles and authors. [src-2026-10-11-008]

## Key Claims
- The page lists 30 demos and provides category filters with visible counts. Categories overlap, so the counts do not represent unique demos. [src-2026-10-11-008]
- Examples include Interactive Newspaper shaders, WebGPU 3D model product viewer, Interactive chess board, liquid-glass bottom tabs, Media Gallery Carousel, Native iOS interface patterns, Android Material tabs and colors, and Expo Router 55 APIs. [src-2026-10-11-008]
- The visible items include author names and links to open demos. The page also displays preview controls. I did not open demos or play preview videos. [src-2026-10-11-008]
