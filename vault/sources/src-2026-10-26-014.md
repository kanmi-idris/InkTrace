# TanStack/redact GitHub repository snapshot

## Summary
The public README describes Redact as a smaller synchronous runtime for React apps. Its detailed runtime-bundle tables identify themselves as Redact 0.1.0 measurements from September 11, 2026. [src-2026-10-26-014]

## Key Claims
- The README describes Redact as an alternative runtime within React, not a replacement for the React project. [src-2026-10-26-014]
- The README quick start gives `pnpm add @tanstack/redact` and provides setup guides for TanStack Start, Vite, Vinext, and Next.js. [src-2026-10-26-014]
- The README labels its detailed runtime-size and microbenchmark comparisons as Redact 0.1.0 with React 19.3.0, recorded 2026-09-11. [src-2026-10-26-014]
- The README states that runtime bundles are not whole applications and reports mixed performance results across workloads. [src-2026-10-26-014]
- The current blog and registry list version 0.2.0. The README's historical 0.1.0 measurements are distinct from the launch blog's framework bundle totals. [src-2026-10-26-012] [src-2026-10-26-015]
