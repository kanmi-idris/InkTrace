# Founder fundraising documents checklist tweet

## Summary
This source is a compact founder fundraising checklist posted on X. Its main value is not deep explanation but the reminder that fundraising readiness is partly document readiness: founder and shareholder agreements, incorporation paperwork, cap table visibility, ESOP setup, confidentiality coverage, IP assignment, and a defined co-founder exit path all reduce friction when investors begin diligence. [src-2026-06-10-015]

## Key Claims
- The post frames eight documents as essential for founders preparing to raise money: founder agreement, incorporation documents, co-founder exit clause, shareholders agreement, cap table, ESOP agreement, NDA, and IP assignment. [src-2026-06-10-015]
- The list is useful as a diligence-readiness checklist, but the public source does not explain jurisdictional details, timing, or which items are universally mandatory versus situational. [src-2026-06-10-015]
