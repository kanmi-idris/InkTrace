# Workers KV Instant: Quicksilver-powered global key-value mode

## Summary
Cloudflare announced Workers KV Instant, a Quicksilver-powered mode for globally available, read-heavy configuration data. It keeps the Workers KV API and targets settings and feature flags that need fast global propagation. [src-2026-10-01-009]

## Key Claims
- Cloudflare reports 1.62 ms p99 reads and 107 ms median write replication for Instant. These are vendor-published measurements, not independently reproduced results. [src-2026-10-01-009]
- Instant has stricter capacity and write limits, higher storage and write costs, and was in private beta at announcement. [src-2026-10-01-009]
