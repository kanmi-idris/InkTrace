# Mobile Dev for Codex: Callstack mobile development plugin

## Summary
Callstack's Mobile Dev plugin adds device streaming and controls, accessibility inspection, logs, annotations, and performance tools to Codex mobile development. The README describes support for Expo, React Native, SwiftUI, and native mobile apps. [src-2026-10-03-002]

## Key Claims
- The prebuilt plugin targets Codex desktop on Apple Silicon. The repository says the app project's tools still build, install, and launch the app. [src-2026-10-03-002]
- The README reports errors, crashes, and aggregate performance to Sentry. It documents an environment-variable opt-out and says it excludes app logs, screenshots, input content, tool payloads, and performance recordings. [src-2026-10-03-002]
