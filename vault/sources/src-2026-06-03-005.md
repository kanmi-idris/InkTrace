# Three React Native hooks that will make your life easier

## Summary
This short note captures three practical React Native hook reminders: use `useKeyboardHandler` for frame-by-frame keyboard height on the UI thread, `useLastNotificationResponse` for notification deep links on cold start, and `useFocusEffect` for screen-focus refetching when navigating back. [src-2026-06-03-005]

## Key Claims
- `useKeyboardHandler` is useful when keyboard height should be tracked frame-by-frame on the UI thread rather than through coarse keyboard show/hide events. [src-2026-06-03-005]
- `useLastNotificationResponse` is useful for handling notification deep links when an app is opened from a cold start. [src-2026-06-03-005]
- `useFocusEffect` is useful when data should refetch whenever a screen regains focus after navigation. [src-2026-06-03-005]
