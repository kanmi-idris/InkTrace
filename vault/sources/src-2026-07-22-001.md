# react-native-screen-transitions — Customizable Screen Transitions for React Native

## Summary
A TypeScript library for customizable screen transitions in React Native, authored by eds2002 (Ed). Supports gesture-driven, shared element, sheet, and fully custom animations. Integrates with Expo Router and React Navigation native stack. v3.9.0 is the latest version, compatible with Reanimated v3/v4 and Gesture Handler v2.

## Key Claims
- Customizable screen transitions for React Native with gesture-driven, shared element, sheet, and fully custom animations. [src-2026-07-22-001]
- Uses a Bounds API for shared element and fullscreen zoom transitions. [src-2026-07-22-001]
- Snap-point sheets with gesture-aware ScrollView and FlatList coordination. [src-2026-07-22-001]
- Transition slots for content, backdrop, surface, and custom tagged elements. [src-2026-07-22-001]
- Integrates with React Navigation blank stack, native stack, and Expo Router. [src-2026-07-22-001]
- Built-in presets for common modal, card, and shared-transition patterns. [src-2026-07-22-001]
- Peer dependencies include Reanimated, Gesture Handler, React Navigation, screens, and safe-area-context. [src-2026-07-22-001]
- Written in TypeScript. [src-2026-07-22-001]
- Licensed MIT, 1,571 stars on GitHub. [src-2026-07-22-001]
- Featured on the React Navigation blog (Apr 27, 2026): "Building custom transitions with react-native-screen-transitions". [src-2026-07-22-001]
