# Blender repository and feature overview

## Summary
Blender is a free and open-source 3D creation suite. Its official feature page lists modeling, rigging, animation, simulation, rendering, compositing, motion tracking, video editing, and Python scripting. [src-2026-11-04-019]

## Notes
The repository's COPYING file points to the GNU GPL. Blender is a full 3D application, not a lightweight rendering dependency. [src-2026-11-04-019]
