# react-native-nitro-vision-kit GitHub repository snapshot

## Summary
The repository exposes background removal, image classification, and OCR through React Native Nitro HybridObjects. It uses Apple Vision on iOS and Google ML Kit on Android. [src-2026-10-15-010]

## Key Claims
- The README documents `removeBackground`, `classifyImage`, `readText`, and `analyzeImage`. [src-2026-10-15-010]
- The README says results stay native until the app exports or disposes them. [src-2026-10-15-010]
- The README requires React Native 0.75+, Nitro Modules 0.36.0+, the New Architecture, and Android API 24+. [src-2026-10-15-010]
- The README lists iOS 17+ for cutouts and iOS 18+ for OCR. It marks Android subject segmentation as beta and says Play Services downloads a model on first use. [src-2026-10-15-010]
- The README says first-use Android model downloads can take up to about two minutes. It says offline first use fails if the model is missing. [src-2026-10-15-010]
- The README lists an MIT license and a published `v0.4.0` release. [src-2026-10-15-010]
