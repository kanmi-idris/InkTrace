# react-native-nano-icons

## Summary
This source captures the supplied repository description for `react-native-nano-icons`, a React Native and Expo icon-rendering library that converts SVG icon sets into optimized fonts at build time and renders them as native glyph stacks at runtime. It is explicitly positioned for repeated small-icon use cases where SVG-renderer overhead becomes noticeable. [src-2026-04-15-001]

## Key Claims
- `react-native-nano-icons` is presented as a high-performance icon-rendering option for React Native and Expo, especially for screens with many repeated small symbols such as row icons, tab bars, buttons, and inline badges. [src-2026-04-15-001]
- The supplied implementation model is build-time SVG-to-font conversion plus glyph-map generation, followed by runtime rendering through native text glyph stacks rather than React-managed SVG component trees. [src-2026-04-15-001]
- The supplied material positions the library against `react-native-svg`, `expo-image`, and `react-native-vector-icons`, arguing that Nano Icons is specifically optimized for custom icon sets rendered many times on screen. [src-2026-04-15-001]
- The described API supports typed icon names derived from SVG filenames, multicolor icons through layered glyphs, Expo config-plugin integration, and a CLI-based generation path for bare React Native or related setups. [src-2026-04-15-001]
- The supplied platform notes list support for React Native 0.74 or newer on the New Architecture, iOS 15.1 or newer, Android API 24 or newer, web, and Expo Go, with Expo Go using a `Text` fallback until a development build is used. [src-2026-04-15-001]
