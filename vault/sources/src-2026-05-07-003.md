# react-native-otp-verify

## Summary
This source captures the public `react-native-otp-verify` repository. It is primarily an Android SMS Retriever and OTP helper library, but it also exposes phone-number hint retrieval through `requestHint()`, which makes it a viable pure React Native CLI path for SIM-based phone-number selection on Android. [src-2026-05-07-003]

## Key Claims
- The library explicitly supports both automatic SMS verification and phone-number retrieval using the Phone Number Hint API on Android. [src-2026-05-07-003]
- The documented `requestHint()` method provides the specific phone-number-hint capability relevant here. [src-2026-05-07-003]
- The library is broader in scope than `expo-phone-number-hint`, since it also includes app hash retrieval, OTP listeners, and hook-based SMS verification flows. [src-2026-05-07-003]
- The README documents both autolinking for modern React Native and manual Android linking steps, which makes it suitable for plain React Native CLI projects. [src-2026-05-07-003]
