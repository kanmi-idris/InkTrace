# LLM Wiki

## Summary
The source proposes a personal knowledge architecture where an LLM incrementally maintains a persistent markdown wiki instead of re-deriving answers from raw documents at query time. [src-2026-04-12-001]

## Key Claims
- A maintained wiki compounds value over time because the LLM continuously integrates new sources into existing pages instead of relying on one-off retrieval. [src-2026-04-12-001]
- The system should separate immutable raw sources from synthesized wiki pages and from the schema that governs maintenance workflows. [src-2026-04-12-001]
- Good query answers can themselves become durable wiki pages so that research work is preserved instead of disappearing into chat history. [src-2026-04-12-001]
