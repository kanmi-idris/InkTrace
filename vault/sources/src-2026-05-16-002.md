# Ennio

## Summary
This source captures a detailed public repository page for `Ennio`. It is best understood as iOS-only E2E infrastructure for modern React Native and Expo apps: a Maestro-compatible YAML runner that combines Hermes-Inspector and JSI-based UI discovery with real HID touch delivery through `idb`, while also using build-time plugin gating to keep instrumentation out of Release builds. [src-2026-05-16-002]

## Key Claims
- Ennio positions itself as a Maestro-compatible React Native iOS E2E runner rather than as a generic cross-platform mobile test tool. [src-2026-05-16-002]
- Its distinctive architectural split is between read-side discovery through Metro’s Hermes Inspector and JSI host functions, and write-side actuation through real simulator HID events delivered by `idb_companion`. [src-2026-05-16-002]
- The project explicitly argues that this approach is more realistic than calling `onPress` directly because it exercises actual recognizers, layout constraints, and touch routing. [src-2026-05-16-002]
- The runner supports a large slice of Maestro YAML, including taps, text input, waits, flows, retries, and native-alert helpers. [src-2026-05-16-002]
- A major production-safety claim is the Expo plugin’s build gating: Ennio code is compiled only into selected debug-style Xcode configurations, with Release builds intended to carry none of the instrumentation. [src-2026-05-16-002]
