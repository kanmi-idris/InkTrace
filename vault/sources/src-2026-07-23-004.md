# Experience Memory Graph: One-Shot Error Correction for Agents

## Summary

EMG reformulates agent failure recovery from an iterative LLM reflection problem into a deterministic graph matching problem. At training time, failed exploration + successful expert trajectories are converted into directed action decision graphs. Graph matching extracts common subgraphs (successful workflows) and shortest graph edit paths (explicit error corrections), stored in a memory graph with intra-task nodes and cross-task edges. At test time, retrieval enables correct one-shot execution without trial-and-error loops.

## Key Claims

1. **Reframe error correction as graph matching.** Converts trajectories (sequences of state→action→observation) into directed action decision graphs where nodes are action tuples and edges carry the preceding observation. Graph edit paths between failed and expert trajectories yield explicit correction instructions (which actions to add, delete, or relabel under specific observations).

2. **Structured memory graph with two levels:**
   - **Node insights (intra-task):** common subgraphs (what worked) + graph edit paths (how to fix errors) for individual tasks, stored as natural-language insights.
   - **Edge insights (cross-task):** graph matching between expert trajectories of similar tasks yields transferable action patterns across environments.

3. **One-shot test-time inference.** No iterative reflection or trial-and-error loops. Retrieved insights guide the agent in a single execution, eliminating the latency and API cost of multi-round self-correction.

4. **Deterministic offline construction.** Memory is built entirely offline on training trajectories. The Fused Gromov-Wasserstein (FGW) optimal transport solver handles graph matching independently of LLM capability, avoiding the brittleness of prompt-based reflection.

5. **State-of-the-art results:**
   - Qwen3-4B + EMG: Seen SR 53.57% / Unseen SR 60.45% on ALFWorld (vs ReAct 29.29/21.64)
   - DeepSeek-V4-Flash + EMG: Seen SR 96.43% / Unseen SR 97.76% on ALFWorld
   - DeepSeek-V4-Flash + EMG: Seen SR 28.87% / Unseen SR 24.17% on ScienceWorld
   - Outperforms Reflexion (5 iterations), ExpeL, CDMem, MemP across all splits

6. **Smaller models benefit disproportionately.** Qwen3-4B + EMG matches or exceeds DeepSeek-V4-Flash on standard baselines in complex tasks, suggesting structured memory can bridge the model scale gap.

7. **Time cost ~1/5 of iterative methods** due to single-pass test-time execution.
