# @ladeologun/react-native-walkthrough

## Summary
`@ladeologun/react-native-walkthrough` is a shape-aware React Native walkthrough component for onboarding, feature education, and spotlight flows. It highlights a measured target, dims the rest of the screen, and renders a tooltip that can auto-place around the target, with controlled or imperative visibility, measurement retries, scroll preparation, theme tokens, and custom render hooks. [src-2026-06-07-001]

## Key Claims
- The package provides `ScreenWalkthrough`, a target spotlight and tooltip overlay for React Native onboarding and feature-education flows. [src-2026-06-07-001]
- It depends on `react-native-reanimated`, `react-native-safe-area-context`, and `react-native-svg`, so apps must already have those native/runtime requirements configured. [src-2026-06-07-001]
- It supports both controlled usage through `visible` and imperative usage through `ScreenWalkthroughRef` methods such as `open`, `close`, `refreshPosition`, and `measureTarget`. [src-2026-06-07-001]
- Target measurement is a first-class concern: targets should be native views that support `measureInWindow`, may need `collapsable={false}`, and can trigger remeasurement through `targetKey`. [src-2026-06-07-001]
- Multi-step walkthroughs are intentionally owned by the app state rather than a built-in step-array manager; the app changes target refs, content, buttons, and callbacks per step. [src-2026-06-07-001]
- `prepareTarget` and `prepareTargetDelayMs` support scroll-then-highlight flows for `ScrollView`, `FlatList`, tabbed/collapsible layouts, or targets that appear after navigation. [src-2026-06-07-001]
- The API exposes significant customization through placement, sizing, offsets, target padding, target radius, overlay and ripple colors, `showPulse`, `showRipple`, theme tokens, style hooks, and `renderHeader`/`renderContent`/`renderFooter`. [src-2026-06-07-001]
