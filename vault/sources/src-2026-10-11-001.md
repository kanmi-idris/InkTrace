# ManimGX: Rust-powered animation engine for agents

## Summary
The ManimGX repository presents a Python-based animation engine for coding agents. It uses a Rust and wgpu renderer and targets Manim Community Edition's API. The repository and linked docs qualify the performance, dependency, license, and compatibility claims. [src-2026-10-11-001] [src-2026-10-11-002] [src-2026-10-11-003] [src-2026-10-11-004]

## Key Claims
- The README says ManimGX supports 2D and 3D scenes, text, equations, plots, sound, browser rendering, and a storyboard/layout-inspection command. These are project claims; I did not test them. [src-2026-10-11-001]
- The README reports 90.6× faster than ManimCE in a five-scene benchmark on an Apple M4 Pro. The benchmark's run counts and scope limit this result. [src-2026-10-11-001] [src-2026-10-11-002]
- The announcement says one pip install and no system dependencies. The agent guide specifies Python 3.13 or 3.14 and describes platform-specific rendering and bundled components. [src-2026-10-11-001] [src-2026-10-11-003]
- The README says ManimGX's own code is MIT-licensed. It says native wheels that include x264 are GPL-3.0-or-later as a whole, with separate third-party notices. [src-2026-10-11-001]
- The compatibility guide says most ManimCE code may run after changing the import, but behavior differs. See `src-2026-10-11-004`. [src-2026-10-11-004]
