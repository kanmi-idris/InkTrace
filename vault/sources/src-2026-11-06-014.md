# Codex design skills workflow: Impeccable, 21st Design, and UX Audit

## Summary
A three-part workflow for better-looking pages built by coding agents: a component reference pass on 21st.dev, design refinement with Impeccable's explicit vocabulary, and a behavioral UX audit that exercises the real journey in a browser.

## Key Claims
- Impeccable provides target commands including polish, bolder, distill, audit, typeset, layout, animate, adapt, and harden, and turns vague wants into concrete design changes. Verified against the Impeccable site, which also lists those commands and a 61-check detector. [src-2026-06-27-001] [src-2026-08-09-002] [src-2026-11-06-014]
- A curated component-reference pass (21st.dev or the team's own library) guides the sections that carry the page. [src-2026-11-06-014]
- A UX audit should click through the real journey, on mobile viewports, rather than judge screenshots. This is a workflow recommendation from the source text with no linked product page. [src-2026-11-06-014]
