# iOS Builder by MobAI: Remote iOS build and simulator CLI

## Summary
MobAI's Builder is a CLI for remote iOS builds through GitHub Actions, Codemagic, or Bitrise. It also offers simulator access through the separate MobAI service. [src-2026-10-04-001]

## Key Claims
- The README says builds upload the current working tree, including uncommitted and untracked files that are not ignored. Review local files before building. [src-2026-10-04-001]
- The README says code-signing secrets can be uploaded to GitHub repository secrets. It says App Store Connect keys stay local for IPA submission. These claims were not tested. [src-2026-10-04-001]
- Remote iOS builds use cloud macOS runners. TestFlight signing requires a paid Apple Developer Program membership. [src-2026-10-04-001]
