# How Does BitTorrent Work?

## Summary
This source captures How-To Geek’s public BitTorrent explainer. It is best understood as a general protocol reference: BitTorrent is framed as a decentralized peer-to-peer distribution system in which swarms exchange pieces directly, trackers coordinate peer discovery without serving the actual file data, and newer trackerless flows use DHT to decentralize discovery further. [src-2026-05-17-001]

## Key Claims
- The article frames BitTorrent as a useful decentralized protocol, not merely as a piracy vehicle. [src-2026-05-17-001]
- A torrent swarm is described as a peer group that both downloads and uploads the same content directly between clients rather than from one central file server. [src-2026-05-17-001]
- Traditional trackers are presented as coordination servers for peer discovery, not as the source of the file payload itself. [src-2026-05-17-001]
- The article explains the roles of seeders and leechers and notes that at least one seeder must initially provide a complete copy of the data. [src-2026-05-17-001]
- It also describes a later trackerless direction through DHT, where peer discovery can happen without relying solely on a central tracker. [src-2026-05-17-001]
