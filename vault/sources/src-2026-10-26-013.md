# TanStack Redact compatibility and measurement docs

## Summary
TanStack documents Redact as an alternative runtime within the React ecosystem. It warns that synchronous rendering changes some behavior and that bundle or microbenchmark results do not prove whole-app speedups. [src-2026-10-26-013]

## Key Claims
- The docs say React's APIs and behavior are the reference for Redact. [src-2026-10-26-013]
- The docs describe API differences around pending transitions, actions, and optimistic state. [src-2026-10-26-013]
- The docs say runtime bundle sizes are not whole-app sizes, and microbenchmarks do not establish whole-app speedups. [src-2026-10-26-013]
- The compatibility guide lists production animation, hidden-tab behavior, broader resource/navigation races, and Safari/Firefox as unverified at capture time. [src-2026-10-26-013]
