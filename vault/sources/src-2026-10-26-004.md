# Legend Spark GitHub repository snapshot

## Summary
The public repository README describes Spark as a React Native and Expo Desktop framework. It documents preview and latest setup channels, a Node 24.19.0 minimum for its quick start, and three runtime types. [src-2026-10-26-004]

## Key Claims
- The README says one `@legendapp/spark` package contains the CLI and implementation modules. It lists APIs such as files, windows, and UI. [src-2026-10-26-004]
- The README gives `npm create @legendapp/spark@next MyApp` for preview and `npm create @legendapp/spark@latest MyApp` for latest, then `npm run macos`. [src-2026-10-26-004]
- The README describes Spark Runner and custom development builds as Metro-served, and standalone apps as embedding JavaScript and running without Metro. [src-2026-10-26-004]
- The README requires Node 24.19.0 or newer for quick start and documents Bun 1.3.14 for repository source development. [src-2026-10-26-004]
- The README labels Windows 11 x64/ARM64 source workflows preview and not yet verified. It says local generation and bundle checks do not prove native compilation, autolinking, Hermes startup, or Fast Refresh. [src-2026-10-26-004]
