# Baguette

## Summary
This source captures detailed public repository pages for `baguette` across two snapshots. It is best understood as headless iOS Simulator and device-farm infrastructure that has quickly expanded into a broader remote-debugging and control surface: a Swift CLI and browser UI for booting simulators, streaming frames, injecting input, inspecting accessibility trees, tailing logs, rotating devices, recording output, and even piping a Mac webcam into simulator camera APIs. [src-2026-05-02-002]

## Key Claims
- The repository positions `baguette` as a headless iOS Simulator manager for iOS 26, with host-side input injection that does not require launching the Simulator.app GUI. [src-2026-05-02-002]
- The tool combines simulator lifecycle actions with frame streaming and gesture injection, including taps, swipes, one- and two-finger interactions, and some hardware-button events. [src-2026-05-02-002]
- A major part of the project is the local web UI: `baguette serve` exposes both a per-device dashboard and a multi-device “device farm” view for observing and controlling booted simulators from a browser. [src-2026-05-02-002]
- The streaming layer supports MJPEG or AVCC/H.264 output over stdout or WebSocket, with runtime tuning of bitrate, fps, and scale. [src-2026-05-02-002]
- The newer README substantially broadens the control surface to include keyboard input, system edge gestures, device orientation, screenshots, accessibility-tree inspection, unified-log streaming, and an injected virtual-camera pipeline. [src-2026-05-02-002]
- The implementation is framed as layered and test-driven across a much wider seam set, and the lower-level notes tie several core features to private iOS 26 SimulatorKit, HID, accessibility, and dylib-injection behavior. [src-2026-05-02-002]

## Notes
- This is closely adjacent to `vphone-cli` in the vault, but the emphasis here is simulator control rather than virtualized full-device research VMs.
- The repo depends on private Apple simulator frameworks, so portability and long-term stability should be treated cautiously.
- The newer snapshot makes `baguette` look less like a narrow simulator manager and more like a full local automation platform for iOS simulator QA, accessibility inspection, and media-input mocking.
