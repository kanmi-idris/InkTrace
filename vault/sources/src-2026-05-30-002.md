# SimDeck

## Summary
This source captures SimDeck’s project site and GitHub README. It is best understood as agent-oriented mobile simulator and emulator infrastructure: a CLI, browser UI, service, inspector, profiling, and testing toolkit for driving iOS Simulators and Android emulators from IDEs, CLIs, and AI-agent workflows. [src-2026-05-30-002]

## Key Claims
- SimDeck is explicitly built for mobile development with agents, exposing simulator and emulator streaming, control, inspection, and token-efficient screen descriptions. [src-2026-05-30-002]
- Its control surface is broad enough for end-to-end mobile work: install apps, launch URLs, tap by coordinates or labels, type text, send hardware-style button events, capture screenshots, record video, inspect accessibility trees, and watch device stats. [src-2026-05-30-002]
- The project goes beyond simple remote viewing by including profiling for CPU, memory, disk writes, network throughput, hang signals, and stack sampling. [src-2026-05-30-002]
- Runtime inspector plugins for NativeScript, React Native, Flutter, UIKit, and SwiftUI make SimDeck useful as a cross-framework mobile debugging surface rather than a NativeScript-only utility. [src-2026-05-30-002]
- The `simdeck/test` API and GitHub Actions integration position it as both a local agent-control tool and a possible hosted PR-session testing layer. [src-2026-05-30-002]
