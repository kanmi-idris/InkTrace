# ConitePay payment-gateway repository README

## Summary
The repository README documents ConitePay as a React and React Native SDK for Paystack, Flutterwave, and Interswitch. It describes backend-based initialization and mandatory server verification. [src-2026-10-28-004]

## Key Claims
- The repository describes a monorepo with shared core, React popup checkout, and React Native WebView checkout packages. [src-2026-10-28-004]
- It says processor API calls go through merchant backend callbacks and that `verify` is required. [src-2026-10-28-004]
- It documents a built-in selector, debug logging, automatic fallback, and a default 20-second initialization timeout. [src-2026-10-28-004]
- It says web popup callback URLs must use the same origin as the web app. React Native WebView callback detection does not need this same-origin setup. [src-2026-10-28-004]
- It says the merchant backend must convert Flutterwave amounts from minor units to major units. [src-2026-10-28-004]
- The README states MIT, while npm package pages display `none` and registry version metadata omit the license field. [src-2026-10-28-002] [src-2026-10-28-003] [src-2026-10-28-004]
