# Arc to Zen Browser Migration Tool

## Summary
This source captures `arc2zen`, a Python utility for migrating browser state from Arc into Zen. Its practical value is not just bookmark export: the repository aims to preserve workspace structure, pinned and open tabs, essential tabs, folder hierarchy, display order, icons, and color themes, then inject that state into Zen's actual session storage so tabs appear as real sidebar items rather than as loose backup metadata. [src-2026-06-13-001]

## Key Claims
- `arc2zen` positions itself as a full browser-migration bridge from Arc spaces to Zen workspaces rather than as a one-off tab exporter. [src-2026-06-13-001]
- The tool's migration surface is unusually detailed: spaces, pinned tabs, essential tabs, open tabs, nested folders, icon emojis, color themes, and display ordering are all part of the intended fidelity model. [src-2026-06-13-001]
- A core technical claim is that Zen 1.18+ support works by writing directly to `zen-sessions.jsonlz4`, which the README frames as the storage file Zen uses to render real sidebar tabs. [src-2026-06-13-001]
- The repo includes explicit safety posture in its public narrative: read-only Arc access, automatic Zen backups, dry-run support, and validation steps before or during changes. [src-2026-06-13-001]
- The project also spans compatibility layers by falling back to legacy Zen SQLite tables (`zen_pins`, `zen_workspaces`) for older Zen versions, which suggests the tool is partly an evolving reverse-engineering adapter across browser storage schemas. [src-2026-06-13-001]
- The included workspace-mapping helper and the session-tab injection step indicate that the hard part is not extracting Arc data alone, but correctly binding Arc's organizational model onto Zen's workspace UUID and session format model. [src-2026-06-13-001]
