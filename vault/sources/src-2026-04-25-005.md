# TypeGPU

## Summary
This source captures the supplied landing-page and documentation text for `TypeGPU`, a TypeScript library that adds a type-safe, declarative resource layer on top of WebGPU. Its main positioning is that it restores structural typing, alignment, and resource consistency on the JavaScript or TypeScript side while also aiming toward end-to-end typed shader authoring and React Native compatibility through `react-native-wgpu`. [src-2026-04-25-005]

## Key Claims
- TypeGPU presents itself as a TypeScript library that enhances WebGPU by making GPU resource management more type-safe and declarative. [src-2026-04-25-005]
- The source says TypeGPU regains structured information that WGSL already has but JavaScript normally loses when working with raw byte buffers, handling byte alignment and padding automatically. [src-2026-04-25-005]
- The documented roadmap includes typed data structures and buffers, bind groups, a linker that combines WGSL with referenced TypeGPU objects, typed function shells, future typed pipelines, and eventually imperative shader code in TypeScript. [src-2026-04-25-005]
- The getting-started flow requires installing `typegpu`, adding `@webgpu/types`, and configuring those types in `tsconfig.json`, with optional tooling such as `unplugin-typegpu`, `tsover`, and a lint plugin for `'use gpu'` functions. [src-2026-04-25-005]
- The project is explicitly positioned as lower-level building blocks rather than a higher-level rendering framework like Three.js or Babylon.js. [src-2026-04-25-005]
- The source says TypeGPU can be used in React Native through `react-native-wgpu`, extending its relevance beyond browsers into mobile GPU workflows. [src-2026-04-25-005]
- The recommended use cases include GPU-accelerated simulations, custom 3D renderers, and proprietary-model AI inference, while simpler website 3D scenarios are said to fit better with a framework like Three.js. [src-2026-04-25-005]
