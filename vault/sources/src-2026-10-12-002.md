# react-native-biometrics package metadata and API guidance

## Summary
The unscoped `react-native-biometrics` package documents device-keystore key pairs and signatures for server verification. Its README says not to use `simplePrompt()` for server login. npm showed v3.0.1, last published four years earlier. [src-2026-10-12-002]

## Key Claims
- The package README says keys are stored in native iOS and Android keystores, then unlocked by biometric authentication for signing. [src-2026-10-12-002]
- The README explicitly says `simplePrompt()` only validates local biometrics and should not be used to log in or authenticate with a server. It directs server flows to `createSignature()`. [src-2026-10-12-002]
- The README documents `allowDeviceCredentials`, which can allow device passcode credentials on supported OS versions. [src-2026-10-12-002]
- npm showed version 3.0.1 and “Published 4 years ago” on inspection. This supports a stale release cadence, but does not prove the full state of repository maintenance. [src-2026-10-12-002]
- The separately scoped package `@sbaiahmed1/react-native-biometrics` is a different package. npm showed version 0.16.1 and “Published a month ago.” [src-2026-10-12-006]
