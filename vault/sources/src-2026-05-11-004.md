# Paneru

## Summary
This source captures the public `paneru` repository page. It is best understood as scrollable tiling and window-management tooling for macOS, with a particularly clear architectural angle: a Rust-based, Bevy ECS-driven system that exposes both interactive workspace behavior and scriptable command control over a Unix socket. [src-2026-05-11-004]

## Key Claims
- Paneru positions itself around a sliding-strip window model in which new windows do not force existing windows to resize. [src-2026-05-11-004]
- It extends that model across monitors and workspaces, including native macOS spaces and experimental virtual workspaces. [src-2026-05-11-004]
- The project is not only a window manager but also an automation surface: `send-cmd` exposes many window and pointer actions that can be driven from scripts or other tools. [src-2026-05-11-004]
- The repository is also notable as a systems-design reference because it documents a layered platform / management / ECS architecture on top of Bevy ECS. [src-2026-05-11-004]
- The README is candid about macOS-specific constraints such as accessibility permissions, off-screen relocation behavior, and multi-display quirks. [src-2026-05-11-004]
