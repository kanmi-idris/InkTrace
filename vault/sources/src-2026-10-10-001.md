# nanoMuse open-source cross-device personal agent

## Summary
The nanoMuse repository presents an open-source personal agent that can run across a phone, desktop, and browser. The README describes local agents connected by an optional relay, task automation, memory, and user approvals. These are project claims, not tested results. [src-2026-10-10-001]

## Key Claims
- The README says the phone app, desktop app, web console, and relay are licensed under GPL-3.0-or-later. It lists Android, iOS beta, macOS, Windows, Linux, browser, and self-hosted options. [src-2026-10-10-001]
- The README says each device runs its own agent and that devices communicate through a relay. It claims files and screenshots stay on their device. The linked privacy policy describes default-on cloud conversation sync for signed-in users. [src-2026-10-10-001] [src-2026-10-10-002]
- The README describes shell, browser, MCP, skills, screen-operation, scheduled tasks, Markdown memory, and chat-app integrations. I did not test these features. [src-2026-10-10-001]
- The README describes user approval tiers and says the agent does not type passwords, verification codes, or card numbers. The privacy policy adds that software installation may run without prior approval. [src-2026-10-10-001] [src-2026-10-10-002]
- The README's top section names release `1.0.1 Ballast`, but its News section mentions `1.0.0 Keel`. The page does not resolve this version difference. [src-2026-10-10-001]
