# Native crash reporting in Expo EAS Observe

## Summary
Expo says EAS Observe now records native crashes with JavaScript errors on Android and iOS. Error reporting is in preview and requires SDK 57 or later. [src-2026-10-07-006]

## Key Claims
- Native crash capture requires `expo-observe` 57.0.21 or later. Native reports are sent on the app's next launch. [src-2026-10-07-006]
- The docs list platform limits. They exclude tvOS, the iOS Simulator, ANRs, and out-of-memory terminations. [src-2026-10-07-006]
- EAS Build can upload source maps without `sourcesContent`. EAS Update source maps and native symbolication uploads are not available yet. [src-2026-10-07-006]
- The docs warn that reported errors go off-device and tell developers to avoid PII in error messages. The "Hand off to AI" feature sends crash context to a coding agent. [src-2026-10-07-006]
