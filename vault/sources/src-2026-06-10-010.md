# Quick: An internal hosting platform for the AI era

## Summary
Shopify’s Quick article describes an internal platform that compresses deployment and backend friction for internal tools: upload a folder of HTML and assets, get an internal URL, and optionally call shared APIs for database operations, file uploads, AI, BigQuery-backed data access, websockets, and identity. The system is intentionally constrained, internal-only, and surprisingly cheap to run, yet Shopify says it now supports more than `50,000` internal sites and has materially changed how teams prototype, share, and operationalize ideas. [src-2026-06-10-010]

## Key Claims
- Quick lets Shopify employees ship an internal site by uploading a folder of static assets, without framework setup, deployment pipelines, or config files. [src-2026-06-10-010]
- The hosting layer is deliberately simple: Google Cloud Storage for site folders, `gcsfuse` to mount bucket contents locally, NGINX wildcard routing, and Identity-Aware Proxy for employee-only access. [src-2026-06-10-010]
- Quick adds a shared zero-config backend surface for common internal-site needs including database access, realtime subscriptions, file uploads, AI, BigQuery data warehouse access, websockets, and identity metadata. [src-2026-06-10-010]
- Shopify explicitly frames Firebase as an inspiration for the simple client-side data model and sync behavior, while noting it eventually chose a shared CloudSQL-plus-server model instead of per-site sqlite. [src-2026-06-10-010]
- The article says Quick launched internally in July 2025, now hosts over `50,000` sites, and has been used by more than half of Shopify employees. [src-2026-06-10-010]
- Quick is designed around trust-boundary and simplicity constraints: all sites are internal, all employees can access them, there is no ownership model, and the platform intentionally avoids expanding into arbitrary custom-backend infrastructure. [src-2026-06-10-010]
- Shopify says the platform still runs on a single VM costing roughly `$200` per month, with rate limiting and a later migration from Node.js to Go helping operational stability. [src-2026-06-10-010]
- The article treats AI not as the original motivation but as a strong adoption multiplier because Quick gives prompt-generated internal sites an immediate place to live and gain basic backend functionality. [src-2026-06-10-010]
