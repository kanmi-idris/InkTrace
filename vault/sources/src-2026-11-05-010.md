# Xenova's LFM3-Omni WebGPU posts

## Summary
The Nov 4 post reports about 80 tokens per second on an iPhone 18 Pro Max in a React Native app. It quotes a separate Oct 29 browser demo, which reports about 280 tokens per second on an M4 Max, 90 ms to the first token, and 140 ms to the first audio. These are author-reported claims. They were not independently tested. [src-2026-11-05-010]
