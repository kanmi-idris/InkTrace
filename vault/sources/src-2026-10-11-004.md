# ManimGX differences from Manim Community Edition

## Summary
The ManimGX migration guide says the project uses ManimCE names and parameters, and that most ManimCE scenes may run after changing the import. It also lists behavior and tooling differences. The API claim does not guarantee identical behavior or drop-in compatibility. [src-2026-10-11-004]

## Key Claims
- The guide says ManimGX supports ManimCE scene, mobject, animation, and constant names and parameters. It says most code may work after changing `import manim` to `import manimgx`. [src-2026-10-11-004]
- ManimCE internal-module imports are not available. The guide says ManimGX converts LaTeX through Typst, but LaTeX packages and `\def` do not convert. [src-2026-10-11-004]
- The guide documents different tall-video framing, exact-time animation and updater behavior, camera behavior, and `.animate` semantics. [src-2026-10-11-004]
- The guide says ManimGX keeps some aliases as deprecated names. It recommends a type checker because unknown keywords may be ignored at runtime. [src-2026-10-11-004]
- The guide says voiceover and slide APIs differ from ManimCE plugins. A migration may need code changes. [src-2026-10-11-004]

- Manim Community Edition (ManimCE)

- `ty` type checker
