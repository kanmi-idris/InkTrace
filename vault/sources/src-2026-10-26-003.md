# Legend Spark status and limitations

## Summary
Legend’s status page says Spark primarily targets macOS 14+ on Apple Silicon. It lists Windows development workflows but says native compilation and runtime behavior still need validation. [src-2026-10-26-003]

## Key Claims
- The page lists Spark Runner, custom builds, and standalone apps for macOS 14+ on Apple Silicon. [src-2026-10-26-003]
- Intel Mac source workflows still need native and signed-distribution validation; the published runner is ARM64 only. [src-2026-10-26-003]
- Windows 11 x64/ARM64 has local source-runner and custom-development workflows, but no hosted runner or production packaging workflow. Native compilation and runtime behavior still need validation. [src-2026-10-26-003]
- Windows production builds, signing, and MSIX packaging are unsupported. Linux and Mac App Store workflows are unsupported. [src-2026-10-26-003]
- iOS, Android, and web use selected shared adapters. Desktop windows, files, menus, and processes are not universal capabilities. [src-2026-10-26-003]
- The page says application JavaScript runs in Hermes. Node built-ins and Electron main-process APIs are unavailable. [src-2026-10-26-003]
- The page says Spark’s SQLite, WebView, audio, and UI contracts expose subsets of their APIs. [src-2026-10-26-003]
