# Harbor — Evaluate & Optimize Agents in Sandboxed Environments

## Summary
Harbor is a framework from the creators of Terminal-Bench for evaluating and optimizing agents and models in container environments. 3.4K★, 1.4K forks, Apache-2.0, v0.20.0. Core concepts: Task, Dataset, Agent, Container environment, Trial, Job. Integrates with 10 cloud sandbox providers for horizontal scaling. Pre-integrates popular CLI agents (Claude Code, OpenHands, Codex CLI). Official harness for Terminal-Bench-2.0. Integrates with SkyRL and GEPA for RL/optimization workflows.

## Key Claims
- Framework for evaluating and optimizing agents and models in sandboxed container environments. [src-2026-07-22-011]
- Core concepts: Task (instruction + container + test), Dataset (collection of tasks), Agent (implements BaseAgent), Container environment (Docker), Trial (single attempt), Job (collection of trials). [src-2026-07-22-011]
- Supports 10 cloud sandbox providers: Daytona, Modal, E2B, Runloop, Tensorlake, LangSmith, Blaxel, Novita Sandbox, EC2, Beam. [src-2026-07-22-011]
- Pre-integrated agents include Claude Code, OpenHands, Codex CLI and all popular CLI agents. [src-2026-07-22-011]
- Official harness for Terminal-Bench-2.0. [src-2026-07-22-011]
- Integrates with SkyRL and GEPA for agent optimization (RL + prompt optimization). [src-2026-07-22-011]
- Install: `uv tool install harbor` or `pip install harbor`. [src-2026-07-22-011]
- Language: Python 93.5%, TypeScript 3.7%. 1,370+ commits, v0.20.0 (Jul 18, 2026). [src-2026-07-22-011]
