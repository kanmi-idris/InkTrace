# expo-media-viewer

## Summary
This source captures the supplied repository summary and README-style documentation for `expo-media-viewer`, a native fullscreen photo and video viewer built as an Expo Module for React Native. Its positioning centers on polished media-viewing interactions such as shared-element transitions, pinch-to-zoom, swipe-to-dismiss, inline video playback, and gallery paging, while still exposing Expo-friendly installation and a web fallback. [src-2026-04-25-003]

## Key Claims
- The library presents itself as a native fullscreen media viewer for React Native and Expo that opens from a tapped thumbnail with shared-element transitions, swipe-to-dismiss, and inline video playback. [src-2026-04-25-003]
- The feature set spans images and videos, including pinch-to-zoom, multi-item gallery swiping, page indicators, text overlays, light and dark theming, and provider-level or per-instance error handling for video playback. [src-2026-04-25-003]
- The supplied documentation says the package is implemented as an Expo Module with native Swift and Kotlin code, requires a development build, and will not work inside Expo Go. [src-2026-04-25-003]
- The Android implementation is described as relying on bundled dependencies such as Media3 ExoPlayer, PhotoView, Glide, and ViewPager2, with no extra consumer setup required beyond compiling the native module. [src-2026-04-25-003]
- The component API is split between a `MediaViewer` provider for gallery-wide configuration and `MediaViewer.Image` wrappers for individual thumbnails, with props for media typing, posters, text overlays, page-indicator visibility, edge-to-edge mode, and video error callbacks. [src-2026-04-25-003]
- A more specialized capability is Android-only GPS extraction through `readGpsFromPhoto()`, which is described as using `MediaStore.setRequireOriginal()` to preserve EXIF GPS access despite Android 10+ scoped-storage stripping behavior. [src-2026-04-25-003]
- The package claims support for both Fabric and Classic React Native architectures, plus a graceful web fallback that renders children without the native viewer on unsupported platforms. [src-2026-04-25-003]
