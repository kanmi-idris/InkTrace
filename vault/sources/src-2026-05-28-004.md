# React Native Bottom Sheet

## Summary
This source captures Software Mansion Labs’ `react-native-bottom-sheet` repository. It is best understood as native bottom-sheet infrastructure for React Native: a component library with inline and modal sheets, content-based sizing, controlled detents, nested-scrollable coordination, programmatic-only snap points, and position tracking for UI coupled to sheet movement. [src-2026-05-28-004]

## Key Claims
- The library positions itself around native implementation rather than a purely JavaScript sheet surface, with Kotlin, Swift, Objective-C++, and C++ present alongside TypeScript. [src-2026-05-28-004]
- Its public component model separates inline `BottomSheet` from overlay-style `ModalBottomSheet`, which makes the package useful for both screen-embedded and modal bottom-sheet patterns. [src-2026-05-28-004]
- The detent model is a central API idea: sheets are controlled through `detents`, `index`, and `onIndexChange`, with support for fixed heights, content-sized detents, dynamic detent changes, and programmatic-only detents. [src-2026-05-28-004]
- The README’s scrollable negotiation and `onPositionChange` APIs indicate that the library is designed for complex sheet interactions, not just static drawer presentation. [src-2026-05-28-004]
