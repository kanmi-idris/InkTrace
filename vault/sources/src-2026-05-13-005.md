# Its Hover Animated Icons

## Summary
This source captures the public `itshover.com/icons` page. It is best understood as a small interface-primitive library: animated icons distributed in a copy-paste and shadcn-registry style, with Motion explicitly part of the implementation model rather than static asset export alone. [src-2026-05-13-005]

## Key Claims
- The page positions the library around animated, high-quality icons intended for direct use in application interfaces. [src-2026-05-13-005]
- The site explicitly frames adoption as copy-paste friendly rather than requiring a heavy package-first workflow. [src-2026-05-13-005]
- A more structured integration path is also visible through shadcn CLI registry installation. [src-2026-05-13-005]
- The public page ties the icon behavior to Motion, which suggests the library is as much about microinteraction feel as about iconography itself. [src-2026-05-13-005]
