# API Anything technical reference

## Summary
The reference describes learning request templates and extracting fields from JSON, HTML, or embedded page data. It uses a three-tier read fallback, from Node HTTP to browser-origin fetch and then browser-triggered reads. [src-2026-11-02-002]

## Key Claims
- A learned operation can extract structured output from JSON, HTML, or embedded JSON. [src-2026-11-02-002]
- Tier 1 uses Node `fetch`; tier 2 fetches from a real Chrome page on the site's origin; tier 3 runs the site's page trigger and reads its matched response. [src-2026-11-02-002]
- The docs say persistent bot challenges are reported as blocked. The caller is told to sign in or clear the challenge. [src-2026-11-02-002]
- The docs do not claim that every CAPTCHA or anti-bot barrier can be bypassed. [src-2026-11-02-002]
- Shared specs use local references for session values rather than sharing their secret values. [src-2026-11-02-001] [src-2026-11-02-002]
