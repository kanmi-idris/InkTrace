# Towards Automating Eval Engineering — LangChain Eval Engineering Skill

## Summary
LangChain's Eval Engineering Skill helps coding agents build evals from repository context and agent traces. The skill inspects agent structure, mines patterns from traces, proposes abilities to test via user interview, and outputs executable Harbor-format evals. Announced July 22, 2026 by Vivek Trivedy (105.3K views on X).

## Key Claims
- The Eval Engineering Skill helps coding agents build evals using context from a repository and agent traces. [src-2026-07-22-004]
- The skill inspects agent surface (prompts, models, tools, skills, hooks) and identifies data/services backing those behaviors. [src-2026-07-22-004]
- Interviewing the user leads to much better eval acceptance than one-shot generation. [src-2026-07-22-004]
- Output is executable evals in Harbor format: task.toml, instruction.md, environment/, tests/. [src-2026-07-22-004]
- First verifier is rarely the final one — inspecting both agent trajectory and verifier trajectory reveals failures. [src-2026-07-22-004]
- Reward hacking risks include overciting irrelevant sources, claiming actions never taken, exploiting exposed answer material, satisfying proxies without completing the task. [src-2026-07-22-004]
- The continual learning loop: mine traces → identify failure → build eval → improve agent → rerun. [src-2026-07-22-004]
- Evals are training data for agents; teams fit agent behavior through harness engineering and fine-tuning. [src-2026-07-22-004]
- Containerized evals allow swapping models/tools/prompts/agent versions and comparing results directly. [src-2026-07-22-004]
- Skill is in `langchain-ai/langchain-skills` repo; installed in Codex or Claude Code. [src-2026-07-22-004]
