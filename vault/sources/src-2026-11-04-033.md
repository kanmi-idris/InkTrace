# Global Hack Map source repository

## Summary
The repository describes a Next.js application that collects and normalizes public security feeds, geolocates and deduplicates incidents, and serves a cached map, lists, and a read-only MCP interface. [src-2026-11-04-033]

## Key Claims
- Listed sources include CISA KEV, CVE.org, CIRCL, NVD, FIRST EPSS, GitHub Advisory Database, OSV, RansomLook, SEC EDGAR, IODA, Wikidata, GeoNames, Natural Earth, NASA GIBS, and Valyu. [src-2026-11-04-033]
- The README requires Node.js 20+ and pnpm for local setup. Public feeds work without a Valyu API key, while some news and AI research features require one. [src-2026-11-04-033]
- The code is MIT-licensed. Included fonts use the SIL Open Font License. [src-2026-11-04-033]
- Public snapshots and feeds use cache intervals. The README warns that upstream delays, timeouts, cached results, and fallback data can make the live view older or incomplete. [src-2026-11-04-033]

## Notes
The site and repository claims were not independently audited. Repository statistics and live counts are point-in-time observations. [src-2026-11-04-033]
