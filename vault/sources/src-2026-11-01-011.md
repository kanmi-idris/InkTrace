# Searchata documentation and connection overview

## Summary
Searchata documents a read-only MCP connection to Google Search Console and optional Bing Webmaster Tools. It requires an active trial or paid plan for most data tools. [src-2026-11-01-011]

## Key Claims
- Searchata says its tools cannot change sites or source settings, submit sitemaps, or request indexing. [src-2026-11-01-011]
- Its docs cover GSC performance and indexing data, Bing crawl data, PageSpeed, Chrome UX Report, and content guidelines. [src-2026-11-01-011]
- Google Analytics 4 is described as coming soon and is not available through MCP. Searchata says it does not provide competitor analysis. [src-2026-11-01-011]
- The remote MCP endpoint is `https://searchata.com/mcp`; setup uses browser OAuth. [src-2026-11-01-011]
- The docs say data tools require an active trial or paid plan. Tool discovery and content-guideline tools are available before the trial. [src-2026-11-01-011]
