# Flipbook

## Summary
This source captures user-supplied product copy for `Flipbook`, an experimental browsing interface described as an infinite visual browser generated on demand in real time. The current record is grounded in pasted text rather than a directly fetched page, so it should be treated as a conservative summary of the supplied copy until a canonical URL is attached later. [src-2026-04-23-001]

## Key Claims
- Flipbook is presented as an infinite visual browser in which each page is an image generated on demand rather than a conventional HTML interface. [src-2026-04-23-001]
- The supplied copy claims that users explore by clicking within generated images, which yields a new image that goes deeper on the clicked subject. [src-2026-04-23-001]
- The source says all visible text is also rendered as pixels by the image model rather than being applied as a text overlay. [src-2026-04-23-001]
- The information shown in Flipbook is described as coming from a combination of agentic web search and the image model's own world knowledge, with an explicit warning that inaccuracies can occur. [src-2026-04-23-001]
- A "live video stream" mode is described as an experimental, resource-intensive feature that animates otherwise static image exploration by combining a custom video model with the image system. [src-2026-04-23-001]
- The source frames Flipbook as an experiment that could eventually incorporate richer real data, stronger interactivity, and action-taking workflows inside the same generated visual surface. [src-2026-04-23-001]
