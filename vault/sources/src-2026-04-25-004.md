# expo-circular-reveal

## Summary
This source captures the supplied repository summary and README-style documentation for `expo-circular-reveal`, an Expo Module that implements Telegram-style circular reveal transitions for theme changes in React Native. Its main positioning is that it hides theme-swap flashes by capturing the current screen, overlaying that snapshot, and revealing the new theme underneath through a circular animation that expands from the user's tap point. [src-2026-04-25-004]

## Key Claims
- The package presents itself as a native React Native or Expo module for circular reveal theme transitions, implemented with Swift on iOS and Kotlin on Android. [src-2026-04-25-004]
- The documented transition flow is: capture the current screen, show it as an overlay, let application code swap the theme underneath, then automatically run the circular reveal animation from a supplied center point. [src-2026-04-25-004]
- The primary API is `triggerTransition(centerX, centerY, durationMs)`, which returns a promise that resolves with `"ready"` once the overlay is visible and it is safe to perform the underlying theme change. [src-2026-04-25-004]
- The supplied notes say the package requires a development build and will not work in Expo Go because it includes compiled native code. [src-2026-04-25-004]
- On iOS, the implementation is described as using `UIGraphicsImageRenderer.drawHierarchy` for capture, `CAShapeLayer` with an even-odd fill rule for masking, and `CABasicAnimation` for the path interpolation. [src-2026-04-25-004]
- On Android, the implementation is described as using `PixelCopy` with a drawing-cache fallback for capture, a custom view with `Canvas.clipPath` and even-odd fill, and `ValueAnimator` with a decelerate interpolator. [src-2026-04-25-004]
- The repository also includes a local example app inside a Bun workspace, with the publishable package under `packages/expo-circular-reveal` and an Expo example app under `example/`. [src-2026-04-25-004]
