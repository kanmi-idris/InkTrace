# NASA Earthdata — Gateway to NASA Earth Observation Data

## Summary
NASA's Earth Science Data Systems (ESDS) Program portal providing open access to 178+ petabytes of Earth science data across 12 DAACs, 10+ science topics, and a suite of data tools (Earthdata Search, Worldview, FIRMS, Giovanni, AppEEARS, VEDA, GUARDIAN). Undergoing Web Unification Project to consolidate all NASA Earth science data sites through end of 2026.

## Key Claims
- ESDS Program provides open access to NASA's archive of Earth science data for any user for any purpose. [src-2026-07-22-003]
- Archive contains 178+ petabytes as of FY2025, projected to exceed 500 petabytes by 2030. [src-2026-07-22-003]
- 10+ million distinct data and service users served; 7.4 billion files distributed. [src-2026-07-22-003]
- 12 Distributed Active Archive Centers (DAACs) manage discipline-specific Earth science data. [src-2026-07-22-003]
- Web Unification Project is migrating all NASA Earth science data sites into Earthdata through end of 2026. [src-2026-07-22-003]
- Data tools include Earthdata Search, Worldview, FIRMS, VEDA, Giovanni, AppEEARS, GUARDIAN, and Earthdata GIS (200+ raster/feature services). [src-2026-07-22-003]
- NISAR L-Band data released Jul 21, 2026 by NASA JPL for observing surface changes. [src-2026-07-22-003]
- ICESat-2 provides reliable satellite-based snow depth estimation. [src-2026-07-22-003]
