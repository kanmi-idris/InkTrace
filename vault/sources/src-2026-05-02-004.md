# Toastiva

## Summary
This source captures the public `toastiva` repository. It is best understood as a React Native interaction-polish library focused on morphing toast notifications, with platform-specific blur behavior and a setup that leans on the modern React Native animation and gesture stack. [src-2026-05-02-004]

## Key Claims
- The repository positions `toastiva` as a morphing toast-notification library for React Native targeting iOS and Android, not web. [src-2026-05-02-004]
- The implementation depends on several common modern React Native UI primitives, including Reanimated, Gesture Handler, Worklets, Safe Area Context, SVG, and `expo-blur`. [src-2026-05-02-004]
- The README says Android blur support depends on React Native `0.76+` plus the New Architecture, while iOS uses `expo-blur` and is unaffected by that specific limitation. [src-2026-05-02-004]
- The public quickstart exposes a provider-based integration model with imperative helpers such as `toastiva.success(...)`. [src-2026-05-02-004]
- The documentation structure suggests the library is not only about triggering a toast, but about styling, animation tuning, and promise-aware toast flows. [src-2026-05-02-004]
