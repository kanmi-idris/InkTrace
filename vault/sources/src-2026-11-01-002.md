# Ooyaa live app and proof page snapshot

## Summary
Ooyaa's live app labels its deployment as Arc mainnet and showed a three-payee hourly demo payroll with a 0.01 USDC tip. The proof page was still scanning chain history during inspection. [src-2026-11-01-002]

## Key Claims
- The homepage showed three payees, 0.01 USDC each, hourly periods, and a 0.01 USDC tip. [src-2026-11-01-002]
- At capture, the homepage displayed 24 paydays waiting and funding for 58 more. These later counters do not directly match the launch post's 72/80 and seven-test report. [src-2026-11-01-002] [src-2026-11-01-001]
- The proof page lists eight chain checks. C1, C2, and C3 showed PASS while it scanned blocks, but no final verdict was observed. [src-2026-11-01-002]
- The page displays project-reported test counts. I did not independently run those tests. [src-2026-11-01-002]

## Notes
This is a timestamped UI snapshot. The post's wallet count and run totals are not confirmed. See repository documentation [src-2026-11-01-003] and the factory explorer record [src-2026-11-01-004].
