# react-native-enriched-markdown

## Summary
This source captures the supplied repository page text for `software-mansion-labs/react-native-enriched-markdown`, a React Native library for native Markdown rendering and rich text input with Markdown output. Its main value is that it combines high-performance native rendering, cross-platform support, and a more ambitious editing model than plain text inputs or WebView-based Markdown components. [src-2026-04-30-001]

## Key Claims
- The library presents itself as two related primitives: `EnrichedMarkdownText` for native Markdown rendering and `EnrichedMarkdownTextInput` for rich text input that emits Markdown. [src-2026-04-30-001]
- The supplied README emphasizes that native rendering does not rely on a WebView and instead uses native text infrastructure on iOS, Android, and macOS, with web support handled separately through `react-native-web` and WebAssembly. [src-2026-04-30-001]
- Feature claims include CommonMark and GFM support, LaTeX math, Markdown streaming, customizable styles, accessibility, spoiler text, link handling, copy support, and full RTL support for the display component. [src-2026-04-30-001]
- The input component is described as supporting an imperative formatting API, native formatting menus, auto-link detection, style-state detection, and smart copy/paste with Markdown preservation. [src-2026-04-30-001]
- Native platforms require the React Native New Architecture and explicit support is listed for React Native 0.81 through 0.84. [src-2026-04-30-001]
- Expo support is documented through `npx expo install` and `npx expo prebuild`, with a clear note that the library does not work in Expo Go because it requires native changes. [src-2026-04-30-001]
- Web support is intentionally narrower: only the rendering component is supported there, while the rich text input remains native-only for now. [src-2026-04-30-001]
