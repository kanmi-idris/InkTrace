# OpenUI homepage: agent-driven interfaces and OpenUI Cloud

## Summary
The homepage presents OpenUI as an open-source framework for agent-driven interfaces. It also presents Gateway and Observability as managed production services. The site says Gateway is optional. The homepage's feature, safety, usage, and performance statements are vendor claims. [src-2026-10-09-003]

## Key Claims
- The FAQ describes OpenUI as free and open source. It says users can use their own models, infrastructure, components, and design system. [src-2026-10-09-003]
- The FAQ says Gateway is not required. It describes Gateway as adding output validation and repair, model routing, and provider fallback through an OpenAI-compatible API. [src-2026-10-09-003]
- The homepage says generated interfaces can query tools and MCP servers at runtime, stream progressively, and render across several web, mobile, and email targets. These are vendor descriptions. [src-2026-10-09-003]
- The homepage claims three-times-faster rendering and 67% fewer tokens than JSON-based formats. See the separate benchmark source for methodology and limits. [src-2026-10-09-003] [src-2026-10-09-004]
- The homepage displayed 10,549 GitHub stars and more than 3 million package downloads at capture time. These counts are time-sensitive and were not independently verified. [src-2026-10-09-003]
