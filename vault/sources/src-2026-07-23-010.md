# Crawlee — Web Scraping & Browser Automation Library for Node.js

## Summary

Node.js/TypeScript web scraping and browser automation framework by Apify. Supports HTTP crawling, headless browsers (Playwright, Puppeteer, Cheerio, JSDOM), proxy rotation, automatic scaling, and persistent queues. 24.9K★.

## Features

**HTTP Crawling:**
- Zero-config HTTP2 support (even for proxies)
- Automatic browser-like headers
- TLS fingerprint replication
- Integrated fast HTML parsers (Cheerio, JSDOM)
- JSON API scraping

**Real Browser Crawling:**
- JavaScript rendering and screenshots
- Headless and headful modes
- Human-like fingerprint generation
- Automatic browser management
- Playwright + Puppeteer with same interface
- Chrome, Firefox, WebKit support

**Platform:**
- Persistent URL queue (breadth & depth first)
- Pluggable storage (tabular data + files)
- Automatic scaling with system resources
- Integrated proxy rotation + session management
- Hook-based lifecycle customization
- Configurable routing, error handling, retries
- Dockerfiles ready to deploy
- CLI for project bootstrapping
- TypeScript with generics

## Quick Start

```bash
npx crawlee create my-crawler
cd my-crawler && npm start
```

Or manually:
```bash
npm install crawlee playwright
```

```typescript
import { PlaywrightCrawler, Dataset } from 'crawlee';

const crawler = new PlaywrightCrawler({
    async requestHandler({ request, page, enqueueLinks, log }) {
        const title = await page.title();
        await Dataset.pushData({ title, url: request.loadedUrl });
        await enqueueLinks();
    },
});

await crawler.run(['https://crawlee.dev']);
```
