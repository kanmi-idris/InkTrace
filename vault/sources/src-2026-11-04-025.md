# FFmpeg multimedia toolkit

## Summary
FFmpeg provides multimedia libraries and command-line tools. `ffmpeg` processes and exports media; `ffprobe` inspects it; `ffplay` plays it. [src-2026-11-04-025]

## Notes
The codebase is mainly LGPL-licensed, with optional GPL components. Codec selection, build options, and distribution can affect license obligations. [src-2026-11-04-025]
