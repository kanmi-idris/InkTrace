# SYSTRAN faster-whisper repository

## Summary
`faster-whisper` is a Whisper implementation built on CTranslate2. Its README reports up to four times faster inference than OpenAI Whisper in a project benchmark. Treat this as a maintainer-reported comparison, not a general guarantee. [src-2026-11-04-020]

## Notes
It requires Python 3.9 or newer. The README says PyAV bundles FFmpeg libraries, so a system FFmpeg install is not required for transcription. NVIDIA GPU execution has CUDA and cuDNN requirements. Transcription still needs caption formatting and visual styling in a video workflow. [src-2026-11-04-020]
