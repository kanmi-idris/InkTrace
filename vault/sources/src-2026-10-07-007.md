# Next.js guide: Optimizing prefetching

## Summary
The Next.js guide explains App Router prefetch stages and how to defer expensive work. It describes `prefetch()` for prefetch or navigation time and `navigation()` for navigation time. [src-2026-10-07-007]

## Key Claims
- A default `<Link>` prefetches the shared App Shell. `<Link prefetch={true}>` can also resolve URL-specific data before navigation. [src-2026-10-07-007]
- `prefetch()` and `navigation()` defer their subtrees to different stages. The guide says Suspense provides fallback UI while deferred work runs. [src-2026-10-07-007]
- Per-link prefetching can cause one server invocation per link. The guide recommends opting in where needed. [src-2026-10-07-007]
- The guide says a cold cache can still delay the first visit. Cached results can make later visits faster. [src-2026-10-07-007]
