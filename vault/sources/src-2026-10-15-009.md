# Desert Ant React Native local AI product page

## Summary
The page presents eight Desert Ant models as tested end to end, with three more packages that build and bind but have not completed end-to-end testing. It lists Clear and Ear at about 9 MB each. [src-2026-10-15-009]

## Key Claims
- The page says Clear, Clips, Uhm, Emo, Ear, Gist, Redact, and Shapes run end to end. [src-2026-10-15-009]
- The page says Voz, Tongue, and Align are in the repository but have not been driven end to end. [src-2026-10-15-009]
- The page describes Clear as verified on an iPhone 16 with iOS 26.3.1 and describes several other model tests as simulator runs. These are publisher-reported tests, not tests I reproduced. [src-2026-10-15-009]
- The page calls the suite eleven model packages. The GitHub README lists twelve, including Title, whose generation it says is unsupported. [src-2026-10-15-009] [src-2026-10-15-008]
- The page calls the suite free, open source, and MIT-licensed. The repository scopes MIT to the SDK code and lists a separate source-available license for model weights. [src-2026-10-15-009] [src-2026-10-15-008]
- The page presents Android support for some models, while the repository says the Android wrappers have not yet been compiled or device-tested. [src-2026-10-15-009] [src-2026-10-15-008]
