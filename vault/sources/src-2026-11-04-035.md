# Claude animation skills repository

## Summary
The repository provides six Claude Code skills for reel-style animations: 3D cartoon explainers, stick figures, route maps, exploded views, count-up graphs, and monochrome line art. [src-2026-11-04-035]

## Key Claims
- The four quick skills create vertical 1080x1920, 30 fps MP4s and a contact sheet with Instagram safe-area markings. [src-2026-11-04-035]
- The two explainer skills use longer, multi-step workflows with scripting, voiceover, caption timing, shots, preview checks, and rendering. [src-2026-11-04-035]
- Local voice uses Kokoro, and word timings use NVIDIA Parakeet via sherpa-onnx. The README says voice models require about 1 GB of downloads and no API key. [src-2026-11-04-035]
- The README describes render times of about 10 seconds for 2D and 1.5 minutes for 3D quick skills. These are project estimates, not universal guarantees. [src-2026-11-04-035]

## Caveats
The repository does not establish that the styles reliably go viral. Safe-area markings support review; they do not prove that a platform will accept every output. [src-2026-11-04-035]

The `/zach-d-films` skill is not affiliated with Zack D. Films. [src-2026-11-04-035]
