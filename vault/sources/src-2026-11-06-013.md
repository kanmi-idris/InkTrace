# LazyJSON async JSON parsing in Nitro

## Summary
A social post describes LazyJSON as a Nitro module type that parses and stringifies JSON on a small background JSI runtime and transfers objects through the new JSI ISerialization interface. This makes JSON.parse-style work effectively async and reduces JS blocking time.

## Key Claims
- LazyJSON moves JSON parsing and stringification to a background JSI runtime. [src-2026-11-06-013]
- The post reports about 33 percent lower JS blocking time for Nitro methods that return or accept JSON. Author-reported; not verified here. [src-2026-11-06-013]
- Hermes upstream documents ISerialization: an efficient opaque binary encoding for JS values passed between runtimes, with optional ownership transfer and zero-copy ArrayBuffer support. [src-2026-11-06-013]
- Hermes' June 2026 stable release notes also describe JSON.parse and JSON.stringify performance improvements. [src-2026-11-06-013]
- The two t.co links in the post remain unresolved. [src-2026-11-06-013]
