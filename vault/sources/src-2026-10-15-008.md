# Desert Ant React Native local AI SDK GitHub repository

## Summary
The repository provides Expo modules for Desert Ant on-device models. Its README lists 12 model packages, including Clear and Ear at about 9 MB each. It also says Android wrappers have not yet been compiled or run on a device. [src-2026-10-15-008]

## Key Claims
- The README describes iOS models using Core ML and Android models using LiteRT, without a server or API key. [src-2026-10-15-008]
- The model table lists Clear and Ear at about 9 MB each. It also lists larger models, including Voz at about 490 MB and Clips at about 288 MB. [src-2026-10-15-008]
- The README lists 12 packages. It says Title's weights download but generation fails with `ERR_UNSUPPORTED_PLATFORM`; it also says the Tongue Swift product is not exported by the upstream package. [src-2026-10-15-008]
- The README says the packages are not on npm. It requires native development builds rather than Expo Go. [src-2026-10-15-008]
- The README says the Android Kotlin wrappers are written but not yet compiled or run on a device. [src-2026-10-15-008]
- The README says the SDK code is MIT, while the model weights use a separate source-available license with attribution, usage, and model-training terms. [src-2026-10-15-008]
