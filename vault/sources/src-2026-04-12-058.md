# expo-pretext

## Summary
This source is a captured public GitHub repository page for `expo-pretext`, positioned as a React Native and Expo text-layout primitive that predicts text height before render and supports obstacle-aware text reflow while keeping normal React Native rendering semantics. [src-2026-04-12-058]

## Key Claims
- The repository describes `expo-pretext` as a way to predict React Native text heights before rendering by combining native measurement with very fast JS layout arithmetic. [src-2026-04-12-058]
- The README explicitly positions the library for FlashList virtualization, streaming AI chat, pinch-to-zoom text, obstacle-aware reflow, Dynamic Type, and Expo Web. [src-2026-04-12-058]
- The installation notes require Expo SDK 52 or newer, React Native 0.76 or newer, and the New Architecture or Fabric, with Expo Go falling back to JS estimates instead of native measurement. [src-2026-04-12-058]
