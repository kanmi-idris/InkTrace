# OpenCut

## Summary
This source captures the public OpenCut website and repository. It is best understood as both open-source creator tooling and a concrete cross-platform media-app architecture reference: a privacy-first CapCut alternative with a Next.js web app today, a desktop app in progress, and a Rust-plus-WASM core increasingly responsible for rendering, effects, masks, and other editing logic. [src-2026-05-18-001]

## Key Claims
- OpenCut publicly positions itself as an open-source CapCut alternative and as a free video editor for web, desktop, and mobile. [src-2026-05-18-001]
- The project’s public framing emphasizes privacy and on-device media handling rather than cloud-first editing. [src-2026-05-18-001]
- The repository structure shows a split between a Next.js web surface, a desktop app built with GPUI, and a Rust core with GPU compositor, effects, masks, and WASM bindings. [src-2026-05-18-001]
- The repository explicitly says business logic is being migrated from TypeScript into the Rust core, which makes the project useful as an architecture reference for browser-plus-native media tooling. [src-2026-05-18-001]
- The visible release and roadmap signals suggest a feature set already moving beyond a toy editor into masks, curve editing, preview control, stickers, and broader timeline functionality. [src-2026-05-18-001]
