# Nate’s react-native-gpui announcement on X

## Summary
Nate announces `react-native-gpui`, an open-source React Native-like renderer for GPUI. The post highlights Mac scrolling, off-thread Reanimated, GPU paint patches, JavaScriptCore startup, and Metal shaders. [src-2026-10-15-003]

## Key Claims
- The post claims AppKit scroll momentum and rubber-banding with Metal scroll-blitting at 120 Hz. [src-2026-10-15-003]
- The post claims a second JavaScript runtime with shared memory, plus in-place GPU opcode patching. [src-2026-10-15-003]
- The post claims that paint patches reduce animation CPU use from 50% to 2%, and that a single binary cold-boots in about 135 ms. These figures were not independently tested. [src-2026-10-15-003]
- The post claims hardware-accelerated Metal shaders for transforms, rounded masks, and shadow clipping. [src-2026-10-15-003]
