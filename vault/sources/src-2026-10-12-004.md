# Apple biometryCurrentSet access-control flag

## Summary
Apple's `biometryCurrentSet` access flag restricts a Keychain item to currently enrolled Touch ID fingers or the current Face ID enrollment. Apple says changes to the enrolled set invalidate the protected item. [src-2026-10-12-004]

## Key Claims
- Apple describes `biometryCurrentSet` as an access constraint for currently enrolled biometrics. [src-2026-10-12-004]
- Apple says adding or removing Touch ID fingers, or re-enrolling Face ID, invalidates the protected item. [src-2026-10-12-004]
- This is local access control. It does not send biometric data or a biometric result to a remote server. [src-2026-10-12-004]
