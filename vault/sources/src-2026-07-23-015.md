# curl-impersonate

## Summary
This source captures the public curl-impersonate repository by lwthiker. It is best understood as scraping-infrastructure and anti-detection tooling: a specially patched build of curl that produces TLS and HTTP/2 handshakes identical to real browsers (Chrome, Edge, Safari, Firefox), bypassing TLS fingerprinting-based anti-bot systems. [src-2026-07-23-015]

## Key Claims
- curl-impersonate patches curl at the TLS library level (BoringSSL for Chrome/Edge/Safari, nss for Firefox) to produce Client Hello messages and HTTP/2 handshakes indistinguishable from real browsers, making it effective against TLS fingerprinting defenses. [src-2026-07-23-015]
- It supports 20+ browser profile targets spanning Chrome 99–116, Firefox 91ESR–117, Edge 99/101, and Safari 15.3/15.5, covering Windows, Android, and macOS platforms. [src-2026-07-23-015]
- The LD_PRELOAD approach (Linux) allows any application using libcurl to gain browser impersonation without source code changes, by setting the `CURL_IMPERSONATE` environment variable. [src-2026-07-23-015]
- The libcurl-impersonate library provides a `curl_easy_impersonate()` API for programmatic use, setting all TLS, HTTP/2, and header options needed for browser-like behavior. [src-2026-07-23-015]
- The project's impact is limited by browser version coverage — profiles only go up to Chrome 116 and Firefox 117 (targeting ~2023 browser versions) — and semi-active maintenance (v0.6.1, Mar 2024). [src-2026-07-23-015]
