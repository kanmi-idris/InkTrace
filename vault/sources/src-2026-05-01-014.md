# expo-mlkit-ocr

## Summary
This source captures a detailed npm package listing for `expo-mlkit-ocr`. It is best understood as a native OCR utility for Expo apps: on-device text recognition, structured recognition output, and an interactive overlay component for selecting or visualizing recognized regions. [src-2026-05-01-014]

## Key Claims
- The package is positioned as a production-ready Expo Module for on-device OCR on iOS and Android using Google ML Kit Text Recognition v2. [src-2026-05-01-014]
- The API returns structured recognition results with full text, blocks, lines, elements, and bounding boxes rather than only a flat text string. [src-2026-05-01-014]
- The package includes `OCRTextOverlay`, a React Native overlay component for rendering selectable OCR bounding boxes over an image, with configurable highlight level and selection behavior. [src-2026-05-01-014]
- Setup is explicitly tied to Expo config-plugin wiring and modern native build flows: the page says `expo-build-properties` is required for iOS deployment target `16.0`, and the module does not work in Expo Go. [src-2026-05-01-014]
- The package also exposes an `iosEngine` choice so iOS builds can prefer ML Kit or Apple Vision depending on runtime and simulator constraints. [src-2026-05-01-014]
