# Rams — Design Quality Engine for Software Teams

## Summary
Rams is a design quality engine that reviews every UI change against your design system before it ships. 258 rules across 9 categories, 8 specialist reviewers. Ships as a free coding agent Skill, an MCP server, and a GitHub App. Scores every PR (0-100, criticals cap at 59). Free on public repos, flat monthly tiers from $39. ~77,938 Skill installs; 6,270 issues caught across 1,164 reviews.

## Key Claims
- "A senior design review on every PR" — design quality engine that reviews UI changes against design system and standards, then scores it. [src-2026-07-22-006]
- 258 review judgments across 9 categories (accessibility, hierarchy, color, type, spacing, components, motion, UX, craft), publicly documented, new rules every week. [src-2026-07-22-006]
- Eight specialist reviewers: accessibility, color, type, spacing, motion, components, UX, craft. [src-2026-07-22-006]
- Scoring: same 258 rules on every review; any critical caps at 59; 60+ always means zero critical issues. [src-2026-07-22-006]
- Three delivery models: free Skill in coding agents (77,938 installs), MCP server (full engine), GitHub App (automated on every PR). [src-2026-07-22-006]
- Re-reviews verify fixes; score climbs as fixes land. [src-2026-07-22-006]
- Prevents: competing CTAs, low contrast/missing labels, hardcoded hex bypassing tokens, generic AI-generated gradients, broken states/duplicate handlers, unguarded motion. [src-2026-07-22-006]
- Pricing: Free (1 public repo, 30/mo), Solo $39/mo (1 private, 50/mo), Basic $179/mo (unlimited repos, 300/mo), Pro $499/mo (750/mo), Enterprise custom. [src-2026-07-22-006]
- Supports React, Next.js, SwiftUI, Vue.js, Svelte, Angular, Tailwind CSS. [src-2026-07-22-006]
- 6,270 UI issues caught before merge across 1,164 reviews. [src-2026-07-22-006]
