# REA: an agent toolkit for app and binary investigation

## Summary
REA is a local CLI and MCP toolkit for app and binary investigation. The repository describes workflows for native applications, app packages, JavaScript, Electron, .NET, and browser evidence. It lists an MIT license. [src-2026-10-06-005]

## Key Claims
- The X post describes decompilation, feature tracing, evidence collection, and feature recreation as use cases. [src-2026-10-06-005]
- The README says analysis runs locally, but an agent or model provider has its own data policy. [src-2026-10-06-005]
- The README says Ghidra operations are read-only and decompilation returns pseudocode, not original source. [src-2026-10-06-005]
- Controlled process capture runs the target with the user's permissions. The README says it is not a security sandbox. [src-2026-10-06-005]
