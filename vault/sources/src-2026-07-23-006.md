# train-llm-from-scratch — End-to-End LLM Training Pipeline

## Summary

Comprehensive from-scratch implementation of the full LLM training pipeline in plain PyTorch — from downloading raw text through tokenization, building a Transformer, pretraining, and five post-training alignment methods (SFT, DPO/ORPO/KTO, PPO, GRPO). All algorithms hand-written without `trl`, `peft`, or `transformers`.

## Pipeline

1. **Data preparation** — 4 streams: pretraining (The Pile), SFT (Alpaca/Dolly/GSM8K), preference pairs (HH-RLHF/UltraFeedback), RL prompts (GSM8K + arithmetic). Uses `r50k_base` tokenizer (tiktoken), stores as HDF5 flat arrays.

2. **Transformer from scratch** — MLP, single-head attention (causal mask), multi-head attention, pre-norm residual blocks, full Transformer with position embeddings. Three configs: 13M / 77M / 406M params.

3. **Pretraining** — DDP across GPUs, bf16 autocast, grad accumulation, cosine LR schedule, gradient clipping. Training throughput ~130K-150K tok/s on 2x L40s. Loss drops from ~11.14 to ~3.76 on The Pile.

4. **SFT (Supervised Fine-Tuning)** — next-token prediction with loss masking (only train on assistant tokens).

5. **Reward model** — linear head on SFT backbone, Bradley-Terry loss. ~0.574 preference accuracy on 7,974 pairs.

6. **DPO / ORPO / KTO** — preference optimization without RL loop. All three in one trainer.

7. **PPO** — classic RLHF loop with GAE, clipped policy + value loss, reward model or verifier as reward source.

8. **GRPO / RLVR** — DeepSeek-R1 style: group-relative advantage (no value network), verifiable reward, per-group normalization. Arithmetic warm-up then GSM8K.

9. **Evaluation** — greedy GSM8K accuracy, table-based comparison across all stages.

10. **Streamlit UI** — control panel for training runs.

## Notable Design

- **Single backbone reuse:** all post-training composes around `forward_hidden()`. No model rewrites between stages.
- **Config system:** JSON base + stage + CLI overrides. Smoke/ variant for fast CPU tests.
- **Loss masking:** chat format uses loss masks to train only on assistant tokens.
- **GRPO group advantage:** group-mean baseline, k3 KL penalty, no critic network.
