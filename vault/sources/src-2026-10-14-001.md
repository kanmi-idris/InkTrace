# One React Native and web framework homepage snapshot

## Summary
The homepage presents One as a full-stack React Native and web framework with shared routing, native APIs, deployment, and build tools. It also makes a comparative speed claim against Metro. [src-2026-10-14-001]

## Key Claims
- The homepage says One supports React Native and web, typed file-system routing, native APIs, OTA updates, loaders, deployment, DevTools, and native build commands. These are publisher claims. [src-2026-10-14-001]
- The homepage lists Vite, React Native ecosystem libraries, and native UI generation through SwiftUI and Jetpack Compose. [src-2026-10-14-001]
- The homepage claims a 3.6-second cold development bundle for One versus 19.5 seconds for Metro, for a production iOS app on the same machine. I did not verify or reproduce this benchmark. [src-2026-10-14-001]
- The homepage displays a link labeled “One v2 is out”; I did not inspect its destination. [src-2026-10-14-001]
