# simdutf-swift: Swift bindings for SIMD-accelerated Unicode operations

## Summary
The repository provides Swift bindings for simdutf Unicode validation, transcoding, and Base64 operations. The associated Margelo post claims up to 71x faster performance than Swift's decoder. That benchmark claim was not independently checked. [src-2026-10-01-001]

## Key Claims
- The repository describes SwiftPM feature traits, counted-buffer conveniences, and a C++17 implementation with runtime CPU dispatch. [src-2026-10-01-001]
- The speed claim comes from Margelo's supplied post. Benchmark conditions were not reviewed. [src-2026-10-01-001]
