# T.J. Żelawski post on Hermes V1 memory regression fix via Worklets Bundle Mode

## Summary
Announcement post on X by T.J. Żelawski (@tjzeldev) sharing his Software Mansion technical blog post on Hermes V1 and Reanimated/Worklets memory consumption, recommending Bundle Mode as the primary fix and giving credit to the Hermes team (especially Aakash) for quick resolution.

## Key Claims
- Reanimated, Worklets, and Hermes V1 suffered high memory consumption due to debug metadata overhead in dynamic code evaluation. [src-2026-07-21-014]
- Worklets Bundle Mode provides an effective solution to avoid the Hermes V1 memory regression. [src-2026-07-21-014]
