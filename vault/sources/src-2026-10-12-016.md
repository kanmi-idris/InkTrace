# Nano Icons official website and FAQ snapshot

## Summary
Software Mansion's Nano Icons website presents a build-time SVG-to-font library for typed, multicolor icons in React Native and Expo. The site recommends it for small UI icons, not all vector art. [src-2026-10-12-016]

## Key Claims
- The site shows `npm i react-native-nano-icons` and describes live font rebuilds, native tab-bar symbols, inline text icons, typed icon names, and static or dynamic font delivery. These are publisher claims; I did not test them. [src-2026-10-12-016]
- The FAQ recommends Nano Icons for simple icon sets. It recommends `expo-image` for detailed vector art and `react-native-svg` for path-level control or animation. [src-2026-10-12-016]
- The FAQ lists iOS, Android, web, and tvOS on React Native's New Architecture. Expo and bare React Native work; Expo Go uses a text fallback. [src-2026-10-12-016]
- The website claims that 2,191 Material Two-tone SVGs total 1 MB, compared with a 461 KB font and 124 KB glyph map; it says Android compresses the font to 236 KB. These figures were not independently tested. [src-2026-10-12-016]
- The website reports a 5.9× UI-thread advantage over `expo-image` for its 1,000-icon test. The linked method and full results are captured separately. [src-2026-10-12-016] [src-2026-10-12-017]
