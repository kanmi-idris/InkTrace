# scrcpy

## Summary
This source captures the public scrcpy repository by Genymobile. It is best understood as a developer-tools and device-casting project: a lightweight, high-performance Android screen mirroring and control tool that works over USB or TCP/IP without root access. It is the most widely used open source tool in its category. [src-2026-07-23-013]

## Key Claims
- Scrcpy delivers 30–120fps screen mirroring with 35–70ms latency and ~1 second startup, which positions it as the fastest tool of its kind without requiring root or a device-side app. [src-2026-07-23-013]
- Audio forwarding, camera mirroring, virtual displays, V4L2 webcam output, HID keyboard/mouse simulation, OTG mode, and gamepad support make it a comprehensive device interaction platform beyond simple screen casting. [src-2026-07-23-013]
- The architecture splits between a C client (SDL2, FFmpeg) and a Java server pushed via ADB at runtime, with nothing permanently installed on the device. This design choice avoids requiring OEM-level access or user-side app installation. [src-2026-07-23-013]
- The project explicitly warns users that the GitHub repo is the only official source, indicating that third-party redistributors have been a problem. [src-2026-07-23-013]
