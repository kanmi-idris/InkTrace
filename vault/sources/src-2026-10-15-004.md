# react-native-gpui GitHub repository snapshot

## Summary
The repository describes a React component renderer that uses GPUI and Metal for macOS desktop windows. It explicitly says it has no mobile host and identifies macOS with Metal as its validated target. [src-2026-10-15-004]

## Key Claims
- The root README describes a typed React Native-like component surface rendered by GPUI through `react-reconciler`. [src-2026-10-15-004]
- The repository identifies macOS arm64 as the current target. The TypeScript package manifest limits the package to `darwin` and `arm64`. [src-2026-10-15-004]
- The current TypeScript README describes a Rust service, JavaScriptCore, a native WebView option, and conformance commands. It calls macOS with Metal the validated target. [src-2026-10-15-004]
- A separate root planning document describes a Fabric C++ shim and a Rust delegate. That architecture differs from the current TypeScript README; I did not resolve the difference. [src-2026-10-15-004]
- The repository shows no published GitHub release or package. This does not establish whether the package exists on npm; see [src-2026-10-15-005].
