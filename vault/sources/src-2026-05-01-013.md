# expo-ruler

## Summary
This source captures `expo-ruler`, an Expo config plugin that wires Spotify’s Android app-size analyzer into Expo prebuild projects. Its value is mainly workflow-oriented: it adapts a Gradle-native size-analysis tool into a form that fits Expo-managed or Expo-prebuilt Android apps more directly. [src-2026-05-01-013]

## Key Claims
- The repository positions `expo-ruler` as an Expo config plugin for configuring Spotify Ruler inside Android projects generated from Expo prebuild. [src-2026-05-01-013]
- The documented workflow is to install the package, register the plugin in `app.json`, then run Ruler’s `analyze<VariantName>Bundle` Gradle tasks from the generated Android project. [src-2026-05-01-013]
- The README says the resulting reports are emitted as both HTML and JSON inside the Android build reports directory. [src-2026-05-01-013]
- The plugin exposes device-targeting and versioning options such as ABI, locale, screen density, SDK version, and underlying Ruler version. [src-2026-05-01-013]
- Compatibility is framed around the modern Android toolchain baseline already expected by newer Expo SDKs: Gradle 8+, Android Gradle Plugin 8+, and JDK 17. [src-2026-05-01-013]
