# PhotoCraft: Rust-based Photoshop-style image editor

## Summary
PhotoCraft is an early-alpha image editor. Its maintainers describe it as a clean-room Photoshop reimplementation in Rust. The README lists desktop and web targets, PSD support, and an MIT OR Apache-2.0 license. [src-2026-10-07-001]

## Key Claims
- The README lists macOS, Windows, Linux, FreeBSD, and Web. It says the desktop app is native and the engine and UI compile to WebAssembly. [src-2026-10-07-001]
- The README describes a shared command engine for the UI, CLI, JSON control channel, and MCP server. It reports more than 500 commands. [src-2026-10-07-001]
- The README reports PSD round-trip results of 307/309 files in one test set and 169/170 in a mixed test set. These are maintainer-reported results. [src-2026-10-07-001]
- The clean-room implementation claim and feature descriptions have not been independently verified. [src-2026-10-07-001]
