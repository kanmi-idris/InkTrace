# react-native-teleport docs: Instagram-like transitions and core guides

## Summary
This source captures the public `react-native-teleport` documentation around Instagram-style transitions plus the library’s core `Portal`, `Teleport`, lifecycle, and Jest-testing guides. It is best understood as React Native motion and native-view-hierarchy infrastructure: the library enables native re-parenting of existing views so components such as videos, animations, or inputs can move between screens and overlay layers without losing internal state. [src-2026-05-20-001]

## Key Claims
- The Instagram-style recipe demonstrates that a seamless feed-to-reels transition can be built with one persistent video instance that is teleported between feed, overlay, and destination screen hosts rather than remounted. [src-2026-05-20-001]
- The docs frame `Portal` as a native-level escape hatch for clipping, stacking, and overlay problems, and `Teleport` as the state-preserving version for moving an existing live view. [src-2026-05-20-001]
- The lifecycle guide makes a strong behavioral guarantee: when hosts appear, disappear, or change, teleported children migrate while preserving component identity and imperative native state. [src-2026-05-20-001]
- The recipe shows a concrete architecture using `zustand`, `react-native-reanimated`, `transparentModal`, `measureInWindow`, and root-level portal hosts to coordinate cross-screen transitions without playback interruption. [src-2026-05-20-001]
- The built-in Jest mock suggests the library is trying to be practical not only for production UI but also for testability. [src-2026-05-20-001]
