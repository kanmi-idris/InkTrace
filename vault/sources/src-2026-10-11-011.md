# Anatomy skill website

## Summary
The Anatomy website describes a Claude Code skill that turns a technical prompt into a detailed, interactive isometric object. It reports 33 examples and gives time estimates and limits. These are the creator's claims, not independent test results. [src-2026-10-11-011]

## Key Claims
- The site says Anatomy builds solid, shaded parts. It does not describe see-through wireframes. [src-2026-10-11-011]
- The site says prompts can add pointer and keyboard interaction, WebGL shaders, true 3D, SVG/HTML, or React/Next.js output. It labels 3D as beta. [src-2026-10-11-011]
- The site lists 33 figures and estimates 30–90 minutes for a Figure, 2–4 hours for a Hero, and at least 6 hours for an Epic. These are project estimates. [src-2026-10-11-011]
- The site says an Epic is not started without user approval. It recommends treating the first figure as a draft and asking for revisions. [src-2026-10-11-011]
- The site says 3D turns one subject at a time and a full audit takes 15–20 minutes. It says reference images guide style, not faithful copying. [src-2026-10-11-011]
