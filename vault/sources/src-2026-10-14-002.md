# One documentation introduction

## Summary
The introduction describes One as a full-stack React framework for shared web and React Native apps. It says the framework uses Vite for web, Rolldown for native, and supports per-route render modes. [src-2026-10-14-002]

## Key Claims
- The page describes shared file-system routing for React Native and web, plus typed routes, loaders, SSG, SSR, SPA, API render modes, preloading, and a production server. [src-2026-10-14-002]
- The page says One runs on Vite for web and Rolldown for native builds. [src-2026-10-14-002]
- The page recommends Zero as its first-class data solution and says the `npx one` starter sets up an early alpha of Zero while an official integration is in progress. This is the page's state at capture time, not a maturity statement about One. [src-2026-10-14-002]
- The page describes One as originating from an experiment to port Expo Router to vxrn. [src-2026-10-14-002]
