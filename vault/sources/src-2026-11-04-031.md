# HyperFrames HTML-to-video framework

## Summary
HyperFrames describes an open-source framework that renders HTML, CSS, media, and seekable animations into deterministic MP4 videos. It supports CLI and agent-skill workflows. [src-2026-11-04-031]

## Notes
The repository also links a Studio and desktop app. “No editor” is therefore a workflow choice, not an absent feature. Its README identifies the license as Apache 2.0. [src-2026-11-04-031]
