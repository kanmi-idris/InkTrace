# CSS tip: remove mobile tap highlight

## Summary
This source captures a short frontend tip about using `-webkit-tap-highlight-color: transparent` on the `html` element to suppress the default tap highlight on mobile browsers. Its value is not architectural but polish-oriented: it is a tiny implementation detail aimed at making interactive elements feel more native during touch interactions. [src-2026-04-30-004]

## Key Claims
- The supplied text says mobile tapping on clickable elements can trigger a visually undesirable highlight effect. [src-2026-04-30-004]
- The recommended CSS is setting `-webkit-tap-highlight-color: transparent` on `html`. [src-2026-04-30-004]
- The intended benefit is a more native-feeling touch interaction aesthetic on mobile websites. [src-2026-04-30-004]
