# munim-maps: 3D MapKit maps for Expo and React Native

## Summary
`munim-maps` is a MapKit-based 3D map library for Expo and React Native. Its README lists an Apache-2.0 license and a Swift Package. [src-2026-10-07-002]

## Key Claims
- The README describes `MunimMapView` and `MapModelLayer`, including an iOS use case with `react-native-maps`. [src-2026-10-07-002]
- It lists 57 built-in 3D models and support for developer-supplied model formats. [src-2026-10-07-002]
- The README describes coordinate anchoring, building occlusion, and terrain-aware model placement. These are project claims, not independently tested. [src-2026-10-07-002]
