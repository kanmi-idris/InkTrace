# React Native clothing rack with WebGPU and Skia Graphite

## Summary
Mehdi showcases a React Native clothing-rack build that he says uses WebGPU with Skia Graphite. The linked Motionary page describes a simulated 3D garment browser built with React Native Skia, React Native, and Expo. [src-2026-10-06-003]

## Key Claims
- The X thread credits @wcandillon and says the work was inspired by @cambreedesigns. [src-2026-10-06-003]
- Motionary lists five drops, a 4.11 MB app, a $32 single-build price, and a $79 lifetime bundle. [src-2026-10-06-003]
- Motionary describes a WGSL renderer and cloth simulation. These are product-page claims, not independent performance tests. [src-2026-10-06-003]
