# Paradee: 8M-parameter single-voice text-to-speech model

## Summary
Paradee is an 8.07M-parameter English TTS model distilled from Kokoro-82M. It has one voice and an int8 ONNX version that runs on CPU. The author-reported evaluation has important limits and a WER discrepancy between the PyTorch and ONNX builds. [src-2026-10-08-001]

## Key Claims
- The model card lists one American-English voice, `af_heart`, 8.07M parameters, and an int8 ONNX file of about 9 MB. [src-2026-10-08-001]
- The paper reports UTMOS 4.41 for Paradee versus 4.52 for Kokoro-82M on 200 held-out sentences. The paper says UTMOS is an automatic predictor and notes that it can miss audible degradations. [src-2026-10-08-001]
- The paper reports 25x real-time speed for PyTorch and 17.8x for the released ONNX file, using one CPU thread on an Apple M4 Pro. [src-2026-10-08-001]
- The Space says WER is 5.7%, but the paper reports 5.7% for PyTorch and 6.0% for ONNX. The model card attributes the difference to text normalization. [src-2026-10-08-001]
- The author reports no formal listening test, only informal listening, and says a faint buzz remains on some voiced sounds. The model supports one English voice only. [src-2026-10-08-001]
- Model and code are marked Apache-2.0. The repository says training sentences from WikiText-103 are CC BY-SA 3.0. [src-2026-10-08-001]
