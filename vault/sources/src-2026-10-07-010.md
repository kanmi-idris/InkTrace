# Telling: Flutter error tracking and analytics

## Summary
Telling is a Flutter telemetry service with a public `telling_logger` SDK for crash reports and analytics. Static review shows that the SDK can send user identifiers, device details, event metadata, and stack traces to its API. [src-2026-10-07-010]

## Key Claims
- The package lists crash reporting, event analytics, device context, sessions, screen tracking, user context, and offline logging. Automatic performance tracking is marked “Coming Soon.” [src-2026-10-07-010]
- Inspected SDK code collects platform, OS/browser version, device model, app version, and build number. It can include user ID, name, email, screen events, metadata, and stack traces in log events. [src-2026-10-07-010]
- The SDK posts log batches to `telling-api.kiishi.space` with an API-key header. It stores unsent logs in `SharedPreferences`; I did not see encryption for this buffer in the inspected file. This was not a full security review. [src-2026-10-07-010]
- Pub.dev lists version `1.4.8` and an MIT license. It labels the package publisher “unverified uploader.” Dart's publishing guidance says this label means no verified publisher is displayed. [src-2026-10-07-010]
- I did not find pricing or privacy and retention terms in the pages inspected. [src-2026-10-07-010]
