# Software Mansion Agentic Engineering Guide

## Summary
This source captures the public Software Mansion Agentic Engineering Guide. It is best understood as operational guidance for professional agent-enabled software development: the guide argues that real agentic engineering depends less on isolated prompting tricks and more on context management, harness engineering, reviewable workflows, quality gates, evaluation pipelines, and the ability to orchestrate multiple agents safely across both new and mature codebases. [src-2026-05-23-003]

## Key Claims
- The guide defines agentic engineering as professional software development with AI agents as active collaborators, explicitly distinguishing it from lower-discipline “vibe coding.” [src-2026-05-23-003]
- It treats context as a scarce and degrading resource, naming knowledge cutoff, context rot, non-determinism, and human-model misalignment as core operational constraints. [src-2026-05-23-003]
- The harness-engineering section makes a strong claim that agent output quality is shaped by the surrounding environment, including `AGENTS.md`, skills, MCP integrations, subagents, and hooks, not just by one prompt. [src-2026-05-23-003]
- The evaluation chapter positions measurement and regression control as essential because LLM outputs are nondeterministic and cannot be validated reliably with naive pass-fail checks alone. [src-2026-05-23-003]
- The guide also pushes toward parallel and organizational scale, describing worktrees, orchestrated multi-agent workflows, scheduled agents, and review queues as a path to real productivity gains. [src-2026-05-23-003]
