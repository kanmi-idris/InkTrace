# react-native-effects

## Summary
This source captures a detailed public repository page for `react-native-effects`. It is best understood as experimental graphics-and-effects infrastructure for React Native: a WebGPU and WGSL-based effects library that pushes rendering onto a separate worklet runtime and exposes both ready-made effect components and a lower-level `ShaderView` primitive. [src-2026-05-16-003]

## Key Claims
- The library positions itself around WebGPU rendering in React Native via `react-native-wgpu`, with off-thread execution through `react-native-worklets` bundle mode. [src-2026-05-16-003]
- Its effect catalog spans both atmospheric or material presets (`Iridescence`, `LiquidChrome`, `Aurora`, `Campfire`, etc.) and gradient primitives. [src-2026-05-16-003]
- The architectural center is `ShaderView`, which the README presents as the reusable host for WGSL fragment shaders, uniforms, and the render loop. [src-2026-05-16-003]
- The project is explicit about its experimental boundary: APIs may change, and the required worklets bundle-mode setup is not enabled by default in ordinary apps. [src-2026-05-16-003]
