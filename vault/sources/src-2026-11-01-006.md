# Daniel Nguyen ports BoltAI and PDF Pals to Windows with Expo

## Summary
Daniel Nguyen says he ported BoltAI and PDF Pals to Windows using Expo, React Native Windows, and Claude Opus working through VMPal. He reports native Windows UI, performance checks, and substantial custom implementation and QA. [src-2026-11-01-006]

## Key Claims
- Nguyen says both apps work on Windows and use Mica and Fluent Design components. [src-2026-11-01-006]
- He says Claude analyzed screenshots, planned the port, built native UI components including a Markdown renderer, and helped test the release build on a Dell laptop. [src-2026-11-01-006]
- He says Claude found React Native Windows bugs and used a C#/WinUI app to verify them. [src-2026-11-01-006]
- In replies, he said most mobile-only APIs did not work as-is, so Claude built stand-ins. He said keyboard shortcuts were easy to fix, while window resizing remained under optimization. [src-2026-11-01-006]
- He reports approximate package sizes of 53 MB for the Mac DMG and 135 MB for the Windows setup executable. [src-2026-11-01-006]
- He describes VMPal plus Claude as helpful, but says the work took more than one prompt and most of his time went to QA. [src-2026-11-01-006]
