# TanStack Redact announcement thread on X

## Summary
TanStack announces Redact as a smaller browser runtime for existing React apps. The thread says Redact works with TanStack Start, Vite, Vinext, and Next.js, and reports starter-app bundle savings. [src-2026-10-26-010]

## Key Claims
- TanStack says Redact can replace browser React through build configuration without changing application code. [src-2026-10-26-010]
- A thread reply reports savings of 47.0 KB for Start, 48.1 KB for Vite, 39.3 KB for Vinext, and 35.7 KB for Next.js. It describes these as emitted client JavaScript and CSS, gzip. [src-2026-10-26-010]
- TanStack says Vinext and Next.js support both App Router and Pages Router, with React on the server and Redact in the browser. [src-2026-10-26-010]
- TanStack says Redact renders synchronously and does not use React's time slicing. [src-2026-10-26-010]
- The thread says Redact started as an internal smaller runtime and TanStack plans to maintain it. [src-2026-10-26-010]

## Notes
The framework bundle figures are publisher claims. The official blog says the totals include lazy chunks and are not a promise about one page's download.
