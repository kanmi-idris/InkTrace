# scrcpy 5.0 release

## Summary
scrcpy 5.0 is the latest release listed on the official Genymobile GitHub page. Its notes list hardware decoding, improved buffering, broader audio capture, and Windows ARM64 builds. [src-2026-10-06-011]

## Key Claims
- Hardware decoding is enabled by default when possible. The release notes say scrcpy falls back to software decoding when needed. They list VideoToolbox for macOS. [src-2026-10-06-011]
- The release notes claim hardware decoding can reduce CPU use by 10× and lower power use. I did not test this claim. [src-2026-10-06-011]
- Other changes include broader audio playback capture, Windows ARM64 builds, video buffering improvements, and dependency updates. [src-2026-10-06-011]
