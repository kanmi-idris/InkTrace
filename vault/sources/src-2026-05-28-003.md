# NativeScript Expo

## Summary
This source captures `DjDeveloperr/nativescript-expo`. It is best understood as experimental bridge architecture between Expo/React Native and NativeScript: a project demonstrating NativeScript as a TurboModule or JSI-backed integration path for exposing deep iOS SDK APIs directly in TypeScript inside an Expo app. [src-2026-05-28-003]

## Key Claims
- The repository is not a general app template; it is a focused proof that NativeScript can be embedded into an Expo/React Native project as a native-access layer. [src-2026-05-28-003]
- Its core architectural claim is that NativeScript runtime work around Node-API and JSI can make NativeScript compile as a module usable from React Native apps. [src-2026-05-28-003]
- The practical appeal is direct TypeScript access to current iOS SDK APIs, with the README calling out hot-reload of native components without recompiling the full React Native project. [src-2026-05-28-003]
- The demo features are intentionally native-heavy: PassKit Wallet passes, VisionKit document scanning, PDFKit rendering, native tabs, and Metal/CoreMotion effects. [src-2026-05-28-003]
- Because the repository is small and experimental, it is stronger as direction-setting evidence than as a production-readiness claim. [src-2026-05-28-003]
