# Refero MCP and DESIGN.md workflow

## Summary
This source captures the supplied product copy and official public pages for Refero’s MCP and design skill workflow. Its main value is as an AI-design tooling pattern: instead of asking an agent to jump straight from prompt to UI, it uses reference search plus structured `DESIGN.md` outputs to give the agent explicit information about typography, color, spacing, layout, and component patterns before implementation begins. [src-2026-05-01-001]

## Key Claims
- The supplied positioning frames Refero as a tool that can generate a semantic `DESIGN.md` from a website URL, covering areas such as color relationships, typography, spacing logic, and component patterns. [src-2026-05-01-001]
- The official styles page says users can search curated references by brand, mood, color, typography, or URL, and inspect a design’s colors, type, spacing, components, and an agent-usable `DESIGN.md`. [src-2026-05-01-001]
- The Refero Design Skill README argues that agents should “design with data, not defaults,” using real-time design research before generating interfaces. [src-2026-05-01-001]
- The same README claims that the skill gives access to a large design-reference corpus with screen metadata, user-flow breakdowns, and craft guides for typography, color, motion, icons, and anti-generic-design rules. [src-2026-05-01-001]
- Installation of the skill is shown via `npx skills add`, while the repository also states that full functionality requires Refero MCP access through `https://api.refero.design/v1/mcp` with bearer-token authentication. [src-2026-05-01-001]
- The overall workflow is explicitly methodology-driven: discovery questions, research, pattern extraction, craft rules, and quality gates all come before final implementation. [src-2026-05-01-001]
