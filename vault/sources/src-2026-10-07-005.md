# React Native OTA Debug Screens for Expo

## Summary
`react-native-ota-debug-screens` is an MIT-licensed Expo tool for inspecting OTA updates and switching among configured channels. The README requires Expo SDK 56+, `expo-updates`, and an EAS build. [src-2026-10-07-005]

## Key Claims
- The screens can show bundle and channel details, check and load updates, switch configured channels, and trigger an intentional crash test. [src-2026-10-07-005]
- The README says channel switching requires a channel already set in the EAS build profile. `allowCustomChannel` is off by default; it allows any channel name when enabled. [src-2026-10-07-005]
- The README says the package requires native modules and a new build when those modules are added. It does not support bare React Native without Expo. [src-2026-10-07-005]
- At inspection, GitHub showed no releases or GitHub packages. I did not check the npm registry. [src-2026-10-07-005]
