# Monid: pay-per-use tool gateway for AI agents

## Summary
Monid is a pay-per-use gateway that lets AI agents discover, inspect, and run third-party data tools. The hosted service brokers provider credentials and charges calls through a wallet. [src-2026-10-08-002]

## Key Claims
- The homepage advertises 2,442 tools. The repository README says 2,000+ tools across 72+ providers. These are vendor counts and differ by page. [src-2026-10-08-002]
- The FAQ says Monid holds provider keys, charges a 10% fee over provider prices, offers $1 in free credit, and does not charge for failed requests. I did not test billing. [src-2026-10-08-002]
- The skill setup requires a Monid API key, which docs say is shown once. The MCP setup uses account login and connection authorization. [src-2026-10-08-002]
- I did not find privacy, retention, or maximum-spend terms in the pages inspected. Review endpoint inputs and prices before enabling tool runs. [src-2026-10-08-002]
- The public MIT repository describes itself as the connector layer for the hosted service, not the full service. [src-2026-10-08-002]
