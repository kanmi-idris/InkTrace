# react-native-capture-view

## Summary
This source is a captured public GitHub repository page for `react-native-capture-view`, a React Native screenshot and view-capture library positioned for the New Architecture. It targets three capture modes: a specific rendered view subtree, the visible screen, and the full content of a plain `ScrollView`. [src-2026-04-16-001]

## Key Claims
- The README presents `react-native-capture-view` as a library for capturing React Native views, screens, or plain `ScrollView` content as images on iOS and Android. [src-2026-04-16-001]
- The documented API centers on `CaptureView`, `CaptureScrollView`, and `captureScreen()`, with ref-based capture methods for view and scroll-content capture. [src-2026-04-16-001]
- The stated requirements are React Native 0.82 or newer, the New Architecture enabled, iOS and Android support, and Expo compatibility through development or EAS builds rather than Expo Go. [src-2026-04-16-001]
- The documented output options include PNG or JPG formats and either temp-file or base64 output, with explicit error codes for common failure modes. [src-2026-04-16-001]
- The README calls out several important limitations, including blank or black output risks for `SurfaceView`, maps, `WKWebView` or `WebView`, off-hierarchy overlays, and virtualized list content beyond mounted items. [src-2026-04-16-001]
