# React Navigation 8.x Native Stack header item documentation

## Summary
The official 8.x docs describe header item priority and secondary descriptions for action and submenu items. [src-2026-10-15-016]

## Key Claims
- `visibilityPriority` is supported on iOS 27 and later. Lower-priority right-side header items move to the overflow menu first when space is limited. [src-2026-10-15-016]
- Supported priority values are `low`, `default`, and `high`. [src-2026-10-15-016]
- Action and submenu items can use `description` as secondary text beside the label. [src-2026-10-15-016]
