# GeekNative quick-start guide

## Summary
The quick start requires platform toolchains and says the setup command installs npm dependencies and creates a Git commit by default. It documents flags to skip both actions. No setup command was run. [src-2026-11-06-008]

## Flag details
`--no-install` skips npm dependency installation. `--no-git` skips the initial Git commit. The two flags skip separate actions. [src-2026-11-06-008]
