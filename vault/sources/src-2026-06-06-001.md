# React Native Detour docs and repository

## Summary
React Native Detour is Software Mansion Labs’ SDK for deferred deep links in React Native. The current docs and repository clarify that Detour handles deferred links, Universal Links, Android App Links, and custom scheme links through one API, with concrete integrations for Expo Router and React Navigation, explicit auth-gated routing guidance, link-source filtering, persistent storage customization, iOS clipboard caveats, Android install-referrer behavior, and built-in analytics. [src-2026-06-06-001]

## Key Claims
- Detour’s main React Native value is deferred deep linking: a user can tap a link before installing the app and still land on the intended screen after App Store or Play Store install and first launch. [src-2026-06-06-001]
- The SDK unifies deferred links, Universal/App links, and custom scheme links, while `linkProcessingMode` lets teams restrict handling to `"all"`, `"web-only"`, or `"deferred-only"` depending on what the app’s navigation layer already owns. [src-2026-06-06-001]
- Expo Router integration uses a root `DetourProvider` plus `useDetourContext`, and apps using `+native-intent.tsx` should set `"deferred-only"` to avoid double-processing Universal/App links. [src-2026-06-06-001]
- React Navigation integration in version 2.3.0 and later can pass Detour’s linking adapter to `NavigationContainer`, using `Detour.getInitialURL()` and `Detour.addEventListener("url", ...)` so React Navigation handles routing automatically. [src-2026-06-06-001]
- Auth-gated apps are handled by letting React Navigation remember pending deep links until the target route becomes reachable after sign-in or onboarding, with `UNSTABLE_routeNamesChangeBehavior="lastUnhandled"` shown in the README. [src-2026-06-06-001]
- The context API exposes `isLinkProcessed`, `link`, and `clearLink`; `clearLink()` should be called after handling redirects to avoid repeated navigation when returning to an entry screen. [src-2026-06-06-001]
- The SDK depends on Expo and React Native utilities including localization, clipboard, constants, application info, AsyncStorage, and either `expo-device` or `react-native-device-info`, while allowing custom storage through config. [src-2026-06-06-001]
- Platform behavior is explicit: Expo Web is a no-op, iOS clipboard matching is optional and may show a permission alert, and Android uses install referrer matching rather than clipboard access. [src-2026-06-06-001]
- Detour also includes analytics support through automatic app-open retention tracking and custom events via `DetourAnalytics` and `DetourEventNames`. [src-2026-06-06-001]
