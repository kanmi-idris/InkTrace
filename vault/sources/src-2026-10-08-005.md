# Liquid Glass for React, web, and Electron

## Summary
Glass-HQ's MIT package provides experimental WebGPU glass materials for React, the web, and Electron. It refracts live DOM content and includes glass controls and surfaces. Browser parity is not established. [src-2026-10-08-005]

## Key Claims
- The package offers Clear and Regular materials, light and dark appearances, and components for surfaces, buttons, toolbars, tabs, menus, sliders, switches, and progressive blur. [src-2026-10-08-005]
- React components require React 19+. Rendering requires HTTPS or localhost and an available WebGPU adapter. [src-2026-10-08-005]
- The README documents known Safari rendering issues. It says the initial release showed blank tab-example content in Safari. Its list of Chromium, Firefox, Safari, and Electron describes acceptance targets, not proven parity. [src-2026-10-08-005]
- The supplied post says desktop Chromium works well and Safari and mobile remain rough. I did not test these environments. [src-2026-10-08-005]
- The quick start uses `@glass-sdk/liquid-glass@~0.0.1`. The repository is MIT licensed and had no GitHub releases visible at capture time. [src-2026-10-08-005]
- This is an independent web implementation, not an Apple SDK. It is distinct from the previously captured Liquid DOM and Expo adaptive-glass projects. [src-2026-10-08-005]
