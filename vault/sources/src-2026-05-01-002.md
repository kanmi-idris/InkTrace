# CSS tip: scope hover states to hover-capable devices

## Summary
This source captures a short frontend tip about wrapping hover styles in `@media (hover: hover)` so they only apply on devices that genuinely support hover interactions. Its value is practical and mobile-focused: it helps avoid sticky or misleading hover states on touch devices where tap interactions can otherwise leave elements in a visually awkward state. [src-2026-05-01-002]

## Key Claims
- The supplied text says some hover states can degrade mobile UX because hover styling may remain after a tap. [src-2026-05-01-002]
- The recommended solution is to place hover selectors inside `@media (hover: hover)`. [src-2026-05-01-002]
- The intended benefit is that hover transitions are limited to devices that actually support hovering, improving behavior on touch-first devices. [src-2026-05-01-002]
