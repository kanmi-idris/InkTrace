# Natural Language Search guide | Typesense

## Summary
Typesense documents Natural Language Search as LLM-based conversion of free-form text into structured search parameters. The feature is built in from v29.0 and requires LLM API keys. [src-2026-10-08-004]

## Key Claims
- The guide maps natural-language input to Typesense parameters such as `filter_by`, `sort_by`, and `q`. [src-2026-10-08-004]
- Typesense says built-in Natural Language Search is available from v29.0 and requires LLM API keys. Its guide example uses Gemini. [src-2026-10-08-004]
- The guide warns that LLMs can misunderstand queries or return invalid Typesense syntax. It recommends prompt refinement or fallback handling. [src-2026-10-08-004]
- The guide was last updated on July 30, 2026. [src-2026-10-08-004]
