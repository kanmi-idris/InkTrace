# RuView

## Summary
This source captures the public `RuView` repository page. It is best understood as ambitious open-source WiFi sensing and edge-perception infrastructure built around CSI, ESP32-class hardware, and local inference, with the unusually important caveat that the README itself marks the project as beta and discloses limited currently published pose-estimation accuracy. [src-2026-05-13-001]

## Key Claims
- RuView positions itself as a camera-free WiFi sensing platform that uses radio-signal disturbances to infer presence, movement, vital signs, sleep patterns, and room-level changes. [src-2026-05-13-001]
- The repository frames ESP32-based CSI capture as the core sensing substrate and presents the system as edge-first, local, and not dependent on cloud processing. [src-2026-05-13-001]
- The README also claims a pose-estimation path via a WiFlow-based architecture using 17 COCO keypoints. [src-2026-05-13-001]
- At the same time, the repo is explicit that this is beta software, that some low-end ESP32 variants are unsupported, and that single-node deployments have limited spatial resolution. [src-2026-05-13-001]
- Most importantly, the same README undermines any overly strong viral interpretation: it reports only about `PCK@20 ≈ 2.5%` for current camera-free proxy-label pose accuracy and says the better camera-supervised evaluation target is still pending rather than published. [src-2026-05-13-001]
