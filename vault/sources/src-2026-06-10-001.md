# Software Mansion hook trio tweet

## Summary
This short Software Mansion post highlights three practical React Native or Expo hook patterns as convenience primitives: `usePreventRemove` for guarding against accidental navigation loss while editing, `useKeepAwake` for preventing the screen from sleeping during active use, and `useMMKVString` for state-like string persistence that restores from disk without explicit async flow in component code. [src-2026-06-10-001]

## Key Claims
- `usePreventRemove` is presented as a way to stop users from accidentally losing form data. [src-2026-06-10-001]
- `useKeepAwake` is presented as a way to keep the device screen from turning off. [src-2026-06-10-001]
- `useMMKVString` is presented as a `useState`-like string hook that persists and restores from disk without async handling in the calling component. [src-2026-06-10-001]
