# expo-glass-tabs — Floating Liquid-Glass Tab Bar for Expo Router

## Summary

A pure TypeScript Expo package that rebuilds the iOS 26 Revolut-style liquid-glass tab bar on top of Expo Router's headless tabs. Features real UIGlassEffect materials, minimize-on-scroll, sliding highlight, finger scrubbing with haptics, and progressive edge blur — all running on the UI thread via Reanimated worklets.

## Key Claims

1. **Real iOS 26 liquid glass** — uses `UIGlassEffect` via `expo-glass-effect` for true squircle corners, rim refraction, content lensing. Solid fallback on older iOS and Android.

2. **Minimize on scroll** — pill shrinks in both dimensions while labels collapse; every icon stays visible. Critically-damped springs with rubber-band overscroll filtering.

3. **Sliding highlight** — active-tab pill travels between tabs on an interruptible, transform-only spring (GPU-composited, no layout work per frame).

4. **Finger scrubbing** — drag along bar: 1:1 tracking, icons light up as finger passes, haptic ticks at each boundary, navigation on release. Screens never jump mid-drag.

5. **Progressive edge blur** — content dissolves gradually behind the bar with no hard blur line. Also works for top bars via standalone `ProgressiveBlur` export.

6. **UI-thread everything** — all animation in Reanimated worklets with native gesture recognizers; blocked JS thread doesn't drop a frame.

7. **Native corner geometry** — rendered by the glass view's native corner configuration, not an RN clipping mask, preserving true squircle and rim lighting through the entire minimize animation.

8. **Pure TypeScript, no custom native code** — works in Expo Go and any dev build.
