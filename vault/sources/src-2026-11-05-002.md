# React Native SplashMotion

## Summary
SplashMotion is a React Native library for native Lottie and dotLottie launch animations. The repository says the animation runs while JavaScript loads, then `hide()` can finish a loop, play an outro, and fade out. [src-2026-11-05-002]

## Requirements
- The README requires the New Architecture, Nitro Modules, iOS 15+, or Android 7 / API 24+. Expo requires a development build, not Expo Go. [src-2026-11-05-002]
- NPM lists version 0.1.0 as latest. The package metadata declares MIT and `react-native-nitro-modules` as a peer dependency. [src-2026-11-05-002]

## Caveats
- The OS launch screen is static before app startup. A supplied `--still` PNG is needed to show the first animation frame there. [src-2026-11-05-002]
- Automatic still-image extraction is on the roadmap. Android also clips the system splash to a centered 192 dp circle. [src-2026-11-05-002]
- The README says Expo users must remove `expo-splash-screen`; Expo Go is unsupported. The package and demo claims were not independently tested. [src-2026-11-05-002]
