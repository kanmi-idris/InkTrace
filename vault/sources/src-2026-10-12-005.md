# Android biometric prompts and cryptographic keys

## Summary
Android's official guide supports biometric-gated cryptographic operations through `BiometricPrompt.CryptoObject`. It documents per-use keys for high-value actions and device-credential fallback options. [src-2026-10-12-005]

## Key Claims
- Android lists `Signature`, `Cipher`, `Mac`, and `KeyAgreement` as cryptographic objects for biometric workflows. The app can perform the operation after successful authentication. [src-2026-10-12-005]
- Android describes auth-per-use keys as suitable for actions such as large payments or health-record updates. [src-2026-10-12-005]
- Android documents `setInvalidatedByBiometricEnrollment(true)` to invalidate a key when a new biometric is enrolled. The guide says the option is true by default and is available from API level 24. [src-2026-10-12-005]
- Android permits device PIN, pattern, or password as authentication types when the app configures them. [src-2026-10-12-005]
