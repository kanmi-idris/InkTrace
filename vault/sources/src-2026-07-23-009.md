# browser-use — Make Websites Accessible for AI Agents

## Summary

Python library that lets AI agents control a web browser — open pages, click, type, fill forms, extract data. 106K★, #1 on Odysseys leaderboard (87.4%). Built on Playwright.

## Features

**Agent Capabilities:**
- Fill forms (job applications, etc.)
- Extract structured data (followers → CSV)
- QA automation (test local websites, report bugs)
- Any browser interaction an AI can describe

**LLM Integration:**
- ChatBrowserUse — unified provider abstraction (accepts `openai/gpt-5.5`, `anthropic/claude-sonnet-4-6`, `google/gemini-3-pro`, custom `bu-*` models)
- Default optimized model: `bu-2.0` (3-5x faster, SOTA accuracy)
- Open-source preview model: `browser-use/bu-30b-a3b-preview`
- Custom tools support via `@tools.action` decorator
- Custom system prompts and tool extensions

**Deployment:**
- CLI for agent-to-browser tasks (one-off through Claude Code, Codex, Cursor, etc.)
- Python library for repeatable automation
- Cloud API for production (scalable browsers, proxy rotation, CAPTCHA solving, stealth fingerprints, 1000+ integrations)
- Docker support

**Skill System:**
- `browser-use skill install` registers browser control skill with external agents
- Agent self-setup via single-paste prompt

**Authentication:**
- Reuse existing Chrome profiles (persistent sessions)
- AgentMail for temporary accounts
- Auth sync with remote browser via `profile.sh`
