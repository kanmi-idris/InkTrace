# web-ai-sdk

## Summary
This source captures the public `web-ai-sdk` site. It is best understood as browser-native AI tooling and abstraction infrastructure: a set of lightweight TypeScript wrappers around the web’s built-in on-device AI APIs for prompting, summarization, translation, language detection, and browser tool-calling, with explicit attention to feature detection, session caching, streaming, AbortSignals, and optional React hooks. [src-2026-05-21-003]

## Key Claims
- `web-ai-sdk` positions itself as a composable lifecycle layer over browser-built-in AI APIs rather than as a heavyweight framework or hosted service. [src-2026-05-21-003]
- The package surface spans prompting, summarization, translation, language detection, and WebMCP-style tool registration, all framed as 100% on-device where the underlying browser supports it. [src-2026-05-21-003]
- The project’s main value proposition is handling the awkward parts of built-in AI APIs: capability checks, model downloads, session lifetime, abortable streams, hot-reload safety, and React integration. [src-2026-05-21-003]
- The site is unusually explicit about browser support and failure modes, including stable, flag-gated, origin-trial, partial, and no-op-fallback states across Chrome, Edge, Safari, and Firefox. [src-2026-05-21-003]
- `@web-ai-sdk/webmcp` is an especially notable piece because it wraps tool registration over browser model context, pushing the project beyond simple text generation into browser-native agent tooling. [src-2026-05-21-003]
