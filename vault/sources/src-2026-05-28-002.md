# NativeScript

## Summary
This source captures the NativeScript project site and companion snippets site. It is best understood as cross-platform native mobile tooling: a JavaScript and TypeScript framework that renders native platform UI, exposes direct native API access, and can be used standalone or through integrations such as Angular, React, Solid, Svelte, and Vue. [src-2026-05-28-002]

## Key Claims
- NativeScript positions itself around native UI rather than WebView rendering, with shared components mapping to platform-native UI building blocks. [src-2026-05-28-002]
- The framework’s architectural hook is direct access to native APIs from JavaScript or TypeScript, with documentation emphasizing typed platform API access. [src-2026-05-28-002]
- Its ecosystem is framework-flexible: developers can use NativeScript directly or pair it with Angular, React, Solid, Svelte, or Vue depending on team preference. [src-2026-05-28-002]
- The snippets site strengthens the source by showing NativeScript as a practical native-integration toolbox, including examples for Android package metadata and JavaScript-to-Kotlin bridging. [src-2026-05-28-002]
