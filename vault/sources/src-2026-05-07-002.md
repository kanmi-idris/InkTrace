# expo-phone-number-hint

## Summary
This source captures the public `expo-phone-number-hint` repository. It is best understood as an Expo-native wrapper around Android’s Phone Number Hint API: a small module for prompting the user with SIM-based phone-number suggestions during onboarding or verification flows. [src-2026-05-07-002]

## Key Claims
- The repository positions the module as a frictionless way to show SIM-based phone numbers as hints, powered by Google’s Phone Number Hint API. [src-2026-05-07-002]
- The API surface is intentionally small, centered on availability checking and launching the picker. [src-2026-05-07-002]
- The returned value is described as an E.164-formatted phone number or `null` if the user dismisses the picker. [src-2026-05-07-002]
- Although the package has iOS files in the repo, the documented `ERR_UNAVAILABLE` behavior makes clear that the picker is effectively Android-only from the public API perspective. [src-2026-05-07-002]
