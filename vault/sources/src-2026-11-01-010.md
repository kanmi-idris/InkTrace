# Searchata homepage

## Summary
Searchata markets an MCP service that connects an AI assistant to Google Search Console and Bing Webmaster Tools data. [src-2026-11-01-010]

## Key Claims
- The homepage describes Searchata as a way to ask an AI assistant questions about connected Search Console properties. [src-2026-11-01-010]
- It lists performance reports, comparisons, search opportunities, URL inspection, sitemaps, and Bing crawl health. [src-2026-11-01-010]
- The homepage says it does not store search data. Its security and privacy pages say it stores encrypted credentials and short-lived encrypted source-response caches. The wording is therefore not equivalent to “stores no data.” [src-2026-11-01-010] [src-2026-11-01-012]
