# Redraw Introduction

## Summary
This source captures the public introduction page for `Redraw`. It is best understood as experimental 2D graphics infrastructure built on WebGPU, with a programming model that mixes TypeScript-authored GPU functions, path-aware rendering logic, and analytical single-pass effects such as vector feathering and blur-like backdrop treatments. [src-2026-05-12-001]

## Key Claims
- Redraw is positioned as a 2D graphics library on top of WebGPU rather than a traditional canvas or raster-first rendering layer. [src-2026-05-12-001]
- The docs emphasize geometry-aware GPU functions, where stroke width and color can vary continuously along a path using values like `ctx.t`. [src-2026-05-12-001]
- Vector feathering is a central differentiator: the page claims fast blur-style effects without a rasterization step. [src-2026-05-12-001]
- The rendering model is also framed as analytically layered, with backdrop-style effects evaluated inside a single render pass instead of requiring extra offscreen surfaces. [src-2026-05-12-001]
- The docs are explicit that the project is still a technical preview with an unstable API. [src-2026-05-12-001]
