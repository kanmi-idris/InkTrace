# MarkItDown — Python Tool for Converting Files to Markdown

## Summary

Microsoft's lightweight Python utility for converting various file formats to Markdown for LLM consumption. 168K★. Supports PDF, Office docs, images, audio, HTML, and more. Plugin-extensible with Azure AI integrations.

## Key Details

- **Author:** Microsoft AutoGen Team
- **Stars:** 168,000 | **Forks:** 12,100 | **License:** MIT
- **Language:** Python (99.7%)
- **Commits:** 312
- **Latest release:** v0.1.6 (May 26, 2026)
- **Requires:** Python 3.10+

## Supported Formats

- PDF, PowerPoint, Word, Excel
- Images (EXIF metadata + OCR)
- Audio (EXIF metadata + speech transcription)
- HTML
- CSV, JSON, XML
- ZIP files (iterates contents)
- YouTube URLs (transcription)
- EPUB
- Outlook messages

## Features

- **CLI:** `markitdown path-to-file.pdf > document.md`
- **Python API:** `MarkItDown().convert("test.xlsx")`
- **Docker:** `docker run --rm markitdown:latest`
- **Plugin system:** 3rd-party plugins via `#markitdown-plugin`
- **LLM image descriptions:** OpenAI-compatible client for pptx/image files
- **Azure Document Intelligence:** Cloud-based layout analysis for PDFs
- **Azure Content Understanding:** Multi-modal cloud conversion (documents, images, audio, video) with structured field extraction as YAML front matter

## Plugin: markitdown-ocr

Adds OCR to PDF, DOCX, PPTX, XLSX using LLM Vision (e.g., GPT-4o). No new ML libraries needed.
