# react-native-nano-icons current GitHub README snapshot

## Summary
The current README describes Nano Icons as a build-time SVG-to-font pipeline for React Native icon rendering. It lists newer platform requirements and documents native symbols, dynamic font delivery, and font-integrity checks. [src-2026-10-12-015]

## Key Claims
- The README currently lists React Native 0.81+ on the New Architecture, iOS 15.1+, Android API 24+, web, Expo Go, and tvOS 15.1+. [src-2026-10-12-015]
- The README describes converting SVGs to TTF fonts and glyph maps at build time, then rendering glyph stacks. [src-2026-10-12-015]
- The README documents native tab-bar symbols, static or dynamic font linking, OTA update use, multicolor glyph layers, and font-integrity APIs. These are repository claims; I did not test them. [src-2026-10-12-015]
- The README describes a benchmark of 1,000 different multicolor icons in an iOS release-build ScrollView. The linked method was later captured in [src-2026-10-12-017]. I did not reproduce the benchmark. [src-2026-10-12-015] [src-2026-10-12-017]
- The README lists unsupported SVG elements and embedded raster images. It also says only top-level `.svg` files are read. [src-2026-10-12-015]
- The README states that the project is MIT licensed. [src-2026-10-12-015]
- The current minimum React Native version is 0.81+, while the April capture listed 0.74+. The April source is historical; see [src-2026-04-15-001]. [src-2026-10-12-015]
