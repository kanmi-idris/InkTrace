# @rbayuokt/expo-infinite-media npm package

## Summary
A native paged media feed for Expo and React Native CLI: mixed video and image pages with a small native player pool, predictive preloading, and bounded LRU-style caching, controlled on the native side from scroll state.

## Key Claims
- Version 0.1.0, MIT licensed; AVFoundation on iOS and Media3 on Android per the repository README. [src-2026-11-06-015]
- Requirements: Expo SDK 55, React Native 0.83 with New Architecture, iOS 15.1+, Android API 24+. Web and Expo Go are not supported; a development build is required. [src-2026-11-06-015]
- Default cache budgets in the README: 500 MB for video, 200 MB for images, with LRU-style eviction and playback priority over speculative preloading. [src-2026-11-06-015]
- The README's 1,200-post stress-test results (OPPO Reno5 F, iPhone 11 Pro) are project-published and not independently verified. [src-2026-11-06-015]
- At capture, npm's dependents page was unreachable and no external GitHub code references were discoverable; the dependents count stays unknown rather than zero. [src-2026-11-06-015]
