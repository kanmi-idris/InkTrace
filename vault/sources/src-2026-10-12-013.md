# SnapCN GitHub repository README and license

## Summary
The public repository presents SnapCN as a MIT-licensed React/Remotion component registry for product-demo videos. The README lists 21 components and describes shadcn CLI installation, browser editing, and an agent skill. [src-2026-10-12-013]

## Key Claims
- The README lists 21 components across AI chat input, screens and devices, text and titles, captions, scenes, logos, social proof, and effects. [src-2026-10-12-013]
- The README gives `npx shadcn@latest add @snapcn/text-reveal`; it says component source and dependencies are copied into the user's project, with no SnapCN runtime package. [src-2026-10-12-013]
- The README says the browser editor can compose a video and export MP4 without installation. A user's own project needs Remotion. These are publisher claims; no product behavior was tested. [src-2026-10-12-013]
- The repository includes an MIT license. [src-2026-10-12-013]
- The README's 21-component count differs from the product site's 46 free and 51 Pro counts. The inspected sources do not explain the difference. [src-2026-10-12-013] [src-2026-10-12-014]
