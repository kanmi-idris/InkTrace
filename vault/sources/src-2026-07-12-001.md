# Atomic Task Graph (ATG): Unified Framework for Agentic Planning and Execution

## Summary
ATG is a training-free control framework that uses explicit DAGs for agentic planning — recursive decomposition, parallel execution, failure localization + subgraph repair. 7B-8B models outperform GPT-4+ReAct on complex benchmarks.

## Key Claims
- ATG (8B Llama) scores 63.65 on ALFWorld vs GPT-4+ReAct 41.24 [src-2026-07-12-001]
- Hallucinated actions drop from 43% (ReAct) to 12% (ATG) on household tasks [src-2026-07-12-001]
- Training-free, prompt-based control, no fine-tuning required [src-2026-07-12-001]
