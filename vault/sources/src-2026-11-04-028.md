# Three.js 3D library

## Summary
Three.js is a general-purpose JavaScript 3D library. Its repository lists WebGL and WebGPU renderers, with SVG and CSS3D renderers available as add-ons. [src-2026-11-04-028]

## Notes
It supports browser-based 3D scenes. It is not a full 3D authoring suite by itself. [src-2026-11-04-028]
