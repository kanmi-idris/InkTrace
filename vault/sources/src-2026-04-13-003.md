# expo-app-blocker

## Summary
This source captures the supplied positioning for `expo-app-blocker`, a GitHub-hosted Expo plugin intended to abstract native app-blocking setup across iOS and Android. The current record is grounded in the user-provided feature summary and repository URL rather than in a direct repository fetch. [src-2026-04-13-003]

## Key Claims
- `expo-app-blocker` is presented as an Expo plugin that handles iOS Screen Time-related setup, iOS extension targets, entitlements, Android overlays, and Android manifest wiring for app-blocking use cases. [src-2026-04-13-003]
- The supplied feature list includes an inline system app picker, a customizable shield screen, temporary unlock with auto-relock, three auto-generated iOS extensions at prebuild, Android foreground service plus overlay support, and a full TypeScript API. [src-2026-04-13-003]
- The stated value proposition is zero manual Xcode setup and no direct AndroidManifest editing because the config plugin performs the native project configuration. [src-2026-04-13-003]
