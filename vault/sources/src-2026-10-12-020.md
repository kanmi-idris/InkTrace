# Plexo download manager website and release snapshot

## Summary
The Plexo site presents a free, open-source pre-release download manager. It says Plexo can split downloads across separate active network routes, including direct files and torrents, then reassemble each file. [src-2026-10-12-020]

## Key Claims
- The FAQ says Plexo combines connections only for downloads started inside the app. It is not a VPN and does not route other apps' traffic. Each selected connection needs a separate route to the internet. [src-2026-10-12-020]
- The site displayed release `v1.0.0-rc.15`. It listed macOS Apple silicon 141 MB and Intel 147 MB DMGs, a 246 MB Windows installer, and Linux x86_64 and ARM64 AppImage, DEB, and RPM packages. [src-2026-10-12-020]
- The site says the Chrome extension supports Chromium browsers such as Edge, Brave, and Arc. Firefox is marked coming soon. [src-2026-10-12-020]
- The FAQ calls Plexo a pre-release and warns that bugs or rough edges may remain. [src-2026-10-12-020]
- The FAQ says the Windows installer is not code-signed and may trigger a security warning. It says the Mac app is signed with an Apple Developer ID provided by Dhananjay Bhosale and notarized by Apple. I did not verify signatures or notarization. [src-2026-10-12-020]
- The homepage's throughput values are part of a product demo. I did not treat them as measured download results. [src-2026-10-12-020]
