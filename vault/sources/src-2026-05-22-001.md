# delphitools

## Summary
This source captures the public `delphitools` site. It is best understood as a privacy-first browser-utility hub: a broad collection of small tools for images, typography, print, color, text, regex, encoding, calculators, and social-media workflows, with an explicit claim that processing happens locally in the browser and does not require accounts or tracking. [src-2026-05-22-001]

## Key Claims
- The site frames itself as a collection of many small focused utilities rather than a single flagship application. [src-2026-05-22-001]
- Its strongest positioning is privacy-first and local-first: no logins, no registration, no data collection, and browser-local processing. [src-2026-05-22-001]
- The utility surface spans both developer-oriented tools like regex testing, encoding helpers, and meta-tag generation, and design or production tools like palette generation, PDF preflight, print imposition, and font exploration. [src-2026-05-22-001]
- The implementation note that it is built with Next.js, Tailwind CSS, and shadcn/ui makes it mildly useful as a lightweight product-stack reference as well. [src-2026-05-22-001]
