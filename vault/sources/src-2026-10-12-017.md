# Nano Icons official benchmark methodology

## Summary
Software Mansion's benchmark document reports per-thread timing for 1,000 icons in a ScrollView on an iPhone 15 Pro, using React Native 0.84.0 and 20 runs per library. [src-2026-10-12-017]

## Key Claims
- The setup lists iPhone 15 Pro, iOS 18, Release build, New Architecture (Fabric), React Native 0.84.0, 1,000 icons, and 20 runs per library. [src-2026-10-12-017]
- The reported results are: react-native-svg 192.03 ms JS / 292.15 ms main / no hang; expo-image 78.07 / 922.03 / 415.32; @expo/vector-icons (IcoMoon) 119.51 / 370.41 / 277.58; react-native-nano-icons 74.97 / 155.04 / no hang. [src-2026-10-12-017]
- The document says the tests used Xcode Instruments and that absolute times include shared screen-navigation overhead. [src-2026-10-12-017]
- The website's 5.9× UI-thread claim matches the reported 922.03 ms for expo-image and 155.04 ms for Nano Icons. This describes the stated test setup only. [src-2026-10-12-016] [src-2026-10-12-017]
