# DigUp announcement on Reddit

## Summary
u/A-Rahim presents DigUp as a free local Mac search app built around EmbeddingGemma 2. The post claims multimodal search, low memory use, and Apple Silicon support. These are the author's claims; the linked README and release metadata add details and limits. [src-2026-10-11-005] [src-2026-10-11-006] [src-2026-10-11-007]

## Key Claims
- The author says DigUp searches text, images, audio, and video by meaning, with optional code search and examples including video moments, podcast moments, PDF pages, photos, and cross-language search. [src-2026-10-11-005]
- The post says the app uses a Q8_0 GGUF of EmbeddingGemma 2 (865 MB) with llama.cpp and Metal in a native Swift app. [src-2026-10-11-005]
- The author claims about 0.1-second search response, indexing under 2 GB, and a roughly 250 MB text encoder loaded during search. The README lists a 310 MB text model component and does not confirm the claimed indexing peak. The sources do not reconcile these size figures. [src-2026-10-11-005] [src-2026-10-11-006]
- The post claims local file processing, with network access only for model download and an optional update check. The README expands on its privacy claims. [src-2026-10-11-005] [src-2026-10-11-006]
- The post lists Apple Silicon and macOS 14 or later. It labels the download signed and notarized; I did not verify the binary's signature or notarization. [src-2026-10-11-005] [src-2026-10-11-007]
