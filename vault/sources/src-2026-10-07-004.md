# OpenQodex: AI code review before push

## Summary
OpenQodex is an Apache-2.0 code-review tool for Claude Code and Codex. It combines scanners with a separate AI reviewer. The repository says it is pre-1.0 and only the newest release gets security fixes. [src-2026-10-07-004]

## Key Claims
- The README says review covers changed lines and checks each scanner finding. It also states that no review finds everything. [src-2026-10-07-004]
- The security guide says the reviewer sends its brief and read files to the model provider used by the user's Claude Code or Codex login. Web access is on by default. [src-2026-10-07-004]
- The docs say built-in scanners do not send source code. The dependency scanner sends package names and versions to `osv.dev`; Semgrep fetches rules from its registry. [src-2026-10-07-004]
- Custom scanners run as arbitrary commands and need explicit approval. The README says the pre-push gate warns by default and blocks only when configured. [src-2026-10-07-004]
- Local use requires Node 22+, Git, and Claude Code or Codex. The README lists macOS and Linux; Windows requires WSL. [src-2026-10-07-004]
