# ConitePay React Native package on npm

## Summary
The npm page listed `@conitepay/react-native` version `0.1.5` at capture time. Its README documents WebView checkout, three processor adapters, backend callbacks, and selector UI. [src-2026-10-28-003]

## Key Claims
- The README describes one `pay()` API for Paystack, Flutterwave, and Interswitch. [src-2026-10-28-003]
- It documents a required `verify` callback and backend `initialize` callback. [src-2026-10-28-003]
- The README requires React `>=18.0.0`, React Native `>=0.72.0`, and `react-native-webview >=13.0.0`. [src-2026-10-28-003]
- It says React Native checkout uses a WebView and supports class components through `withPaymentGateway`. [src-2026-10-28-003]
- The npm README says MIT, but npm's package sidebar displayed `none`, and the registry version metadata had no `license` property. This is an unresolved metadata difference. [src-2026-10-28-003]
