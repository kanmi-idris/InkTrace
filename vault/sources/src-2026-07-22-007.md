# Firecrawl Most Accurate Search — Custom Relevance Model

## Summary
Firecrawl released a custom relevance model for /search that returns query-answering excerpts instead of full pages. Achieves 94.7% on SimpleQA (state-of-the-art), uses 10x fewer tokens than full-page processing. No code changes needed. Evaluated against Exa, Claude native search, and other providers using GPT-5.4 agent with 4,326 SimpleQA questions.

## Key Claims
- Firecrawl /search now uses a custom relevance model that scores every paragraph, list, and table against the query and returns only the excerpts that answer it. [src-2026-07-22-007]
- Achieves 94.7% on SimpleQA (OpenAI's factuality benchmark), higher than any other provider tested. [src-2026-07-22-007]
- Uses 10x fewer tokens than processing full pages. [src-2026-07-22-007]
- Zero code changes required — existing API calls automatically return more relevant context. [src-2026-07-22-007]
- Evaluation: GPT-5.4 agent with high reasoning effort, up to 20 tool calls, compared against Exa Contents and Claude Sonnet 4.6 native search. [src-2026-07-22-007]
- Baseline GPT-5.4 with no search tools scores 43.8% on SimpleQA under same judge. [src-2026-07-22-007]
- Live for every user across API, SDKs, CLI, and MCP. [src-2026-07-22-007]
