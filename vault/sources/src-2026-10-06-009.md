# Leviathan: a Rust indexer for agent search over large datasets

## Summary
Leviathan is an Apache-2.0 Rust tool that indexes structured records for agent search. Its repository documents a CLI, an optional MCP server, and a benchmark on a synthetic maintenance dataset. [src-2026-10-06-009]

## Key Claims
- The README lists JSONL, JSON, CSV/TSV, SQLite, and database CLI output as input sources. It stores the full-text index in SQLite. [src-2026-10-06-009]
- The benchmark reports 436 median tokens and 99.0% hit@5 at one million synthetic records. It reports 107,122 median tokens for its grep comparison. [src-2026-10-06-009]
- The benchmark uses one synthetic dataset and measures retrieval, not a model's final answer. The exact entity key is given to grep. The repository warns that accuracy figures are an upper bound. [src-2026-10-06-009]
- A later author post asks whether people would pay $10 per month for a hosted version. It does not announce a live service. [src-2026-10-06-009]
