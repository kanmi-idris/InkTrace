# React Native Deploy: EAS-compatible builds on GitHub Actions

## Summary
React Native Deploy (`rnd`) aims to provide EAS-compatible build and submit commands on GitHub Actions. It uses the app's `eas.json` and supports QR-code preview distribution and TestFlight submission. [src-2026-10-03-003]

## Key Claims
- The product runs workflows in the user's GitHub repository. The docs require a GitHub token with `repo` and `workflow` scopes. [src-2026-10-03-003]
- The docs list major gaps. The tool is not a full EAS replacement. Android store submission is not wired up, local builds are refused, and some EAS features and flags are unsupported or no-op. [src-2026-10-03-003]
- The website says standard public-repository runner use is free. Private builds use GitHub runner minutes. I did not verify actual billing or run a build. [src-2026-10-03-003]
