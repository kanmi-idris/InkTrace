# VMPal description of AI agent control in virtual machines

## Summary
VMPal describes giving a coding agent screen, keyboard, mouse, and administrator access inside a virtual machine. It says this avoids granting those permissions on the host Mac. [src-2026-11-01-007]

## Key Claims
- VMPal says an agent can operate apps and install software inside a controlled VM. [src-2026-11-01-007]
- VMPal says users approve the connection and configure the machine's files, network, and accounts. It also describes snapshots and rollback. [src-2026-11-01-007]
- These statements explain the product's design. They do not independently confirm the port author's setup or guarantee isolation in every configuration. [src-2026-11-01-007]
