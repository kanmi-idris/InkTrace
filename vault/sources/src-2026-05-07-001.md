# Space

## Summary
This source captures the public landing page for `Space` by Skyglass. It is best understood as file-system and storage-virtualization infrastructure with an AI-context angle: a macOS-first layer that mounts heterogeneous storage into a unified local-looking volume, streams only the byte ranges apps need, and pitches that same file graph as shared context for agents. [src-2026-05-07-001]

## Key Claims
- The product positions itself as letting users search, browse, open, and edit files across many connected storage systems without fully downloading them first. [src-2026-05-07-001]
- It claims Finder-level integration through `/Volumes/Space`, which frames the system as file-system infrastructure rather than just a web dashboard. [src-2026-05-07-001]
- The media-workflow angle is central: large creative files are supposed to open in native applications while only required byte ranges are streamed and cached locally. [src-2026-05-07-001]
- The supported-backend list spans cloud storage, S3-compatible object stores, NAS, and external drives, which makes the unification story more important than any single storage vendor integration. [src-2026-05-07-001]
- The landing page also makes an agent-systems claim: instead of custom MCP or bespoke RAG setups, agents can work against the same traversable file system humans use. [src-2026-05-07-001]
