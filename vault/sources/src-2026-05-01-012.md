# Ruler

## Summary
This source captures Spotify’s public `ruler` repository. It is best understood as Android build-analysis tooling: a Gradle plugin that attributes app size across modules, dependencies, files, and optionally teams, with both report generation and threshold-based verification. [src-2026-05-01-012]

## Key Claims
- Ruler is positioned as a Gradle plugin that helps analyze Android app size and identify what contributes to that size. [src-2026-05-01-012]
- The README frames app size as both technically measurable and commercially important, especially because install size correlates with install-conversion outcomes. [src-2026-05-01-012]
- The plugin supports App Bundle analysis by letting the build specify device assumptions such as ABI, locale, density, and SDK version. [src-2026-05-01-012]
- Ruler can also enforce maximum download-size or install-size thresholds as part of build verification. [src-2026-05-01-012]
- The tool produces HTML and JSON reports, and can further break size down by team ownership through a YAML-based ownership file. [src-2026-05-01-012]
