# Scrapling

## Summary
This source captures the public Scrapling repository. It is best understood as scraping-infrastructure and agent-tooling material: an adaptive Python web-scraping framework that combines parser-level resilience to site changes, multiple fetching modes including stealth and dynamic browser-backed fetchers, a Scrapy-like spider layer for large crawls, and an MCP server for AI-assisted extraction workflows. [src-2026-05-23-002]

## Key Claims
- Scrapling positions itself as a unified framework that spans single-page extraction through full-scale crawling rather than only one piece of the scraping workflow. [src-2026-05-23-002]
- A major differentiator is adaptive element relocation after site structure changes, which the README frames as a built-in resilience feature for long-lived scrapers. [src-2026-05-23-002]
- The fetching layer is intentionally broad, covering plain HTTP, stealth or anti-bot-aware requests, and dynamic browser-backed fetching, plus proxy rotation and DNS-leak mitigation. [src-2026-05-23-002]
- The spiders layer includes production-style crawl concerns such as concurrency, throttling, checkpointed pause-resume behavior, blocked-request handling, and optional `robots.txt` compliance. [src-2026-05-23-002]
- The built-in MCP server is an important modern angle because it lets the framework participate directly in AI-assisted extraction workflows instead of only traditional scripts and spiders. [src-2026-05-23-002]
