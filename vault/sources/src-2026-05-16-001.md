# TablePlus

## Summary
This source captures the public `tableplus.com` landing page. It is best understood as native database-management tooling: a multi-platform GUI client for relational databases that emphasizes native performance, careful editing workflows, query productivity features, and a broader operational surface that includes dashboards and plugin extensibility. [src-2026-05-16-001]

## Key Claims
- TablePlus positions itself as a modern native GUI tool for relational database management across engines such as MySQL, PostgreSQL, SQLite, and others. [src-2026-05-16-001]
- The product story is not limited to query execution; it also highlights inline editing, advanced filtering, change review, production-safe editing modes, import/export flows, and multi-tab or multi-window work. [src-2026-05-16-001]
- A substantial part of the value proposition is the SQL editor itself, which the site frames around autocomplete, syntax highlighting, split panes, reformatting, history, and streaming results. [src-2026-05-16-001]
- The public page also expands the scope slightly beyond database browsing by advertising a `Metrics Board` for quickly building internal dashboards. [src-2026-05-16-001]
- Plugin extensibility is present but still marked as beta, suggesting a growing platform layer on top of the core database client. [src-2026-05-16-001]
- The related GitHub repository adds an important nuance: `TablePlus/TablePlus` is explicitly the official macOS issue tracker rather than the main product source code, so GitHub presence here should be read primarily as a support surface. [src-2026-05-16-001]
- That repository also sharpens the public database-engine list with explicit mention of Microsoft SQL Server, RedShift, MariaDB, Cassandra, and MongoDB alongside the more common relational engines. [src-2026-05-16-001]
