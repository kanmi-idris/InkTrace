# Tweet: Expo dark mode white-flash fix — sync native + JS theme (Patryk Zatorski)

## Summary
Patryk Zatorski points out a critical gotcha when building dark mode in Expo where native components briefly flash white (especially Liquid Glass on iOS). This happens when the native theme is out of sync with the JS-level theme. In React Native 0.82+, the correct solution is using `Appearance.setColorScheme('unspecified')` to reset and follow system settings, avoiding the deprecated passing of `null`/`undefined` which triggers native crashes (NullPointerException on Android).

## Key Claims
- If native components (especially Liquid Glass on iOS) briefly flash white in dark mode, the native theme is out of sync with the JS theme. [src-2026-07-18-003]
- Syncing both themes so they flip together resolves the white-flash issues. [src-2026-07-18-003]
- In React Native 0.82+, `Appearance.setColorScheme` requires `'unspecified'` to reset and follow system appearance. Passing `null` or `undefined` is no longer supported and causes a NullPointerException crash on Android. [src-2026-07-18-003]

- The accompanying image snippet was retrieved via Tesseract OCR on `https://pbs.twimg.com/media/HNdIJvdXkAA2smf.jpg`, confirming the following implementation pattern:
  ```typescript
  // ThemeProvider.tsx
  useEffect(() => {
    if (appTheme === "system") {
      Appearance.setColorScheme("unspecified");
    } else {
      Appearance.setColorScheme(colorScheme);
    }
  }, [appTheme, colorScheme])
  ```
