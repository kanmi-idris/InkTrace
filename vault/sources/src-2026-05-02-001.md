# vphone-cli

## Summary
This source captures a detailed public repository page for `vphone-cli`. Its most relevant angle for the vault is not the firmware-patching depth by itself, but the broader idea of host-controlled iPhone virtualization: a macOS-hosted virtual iPhone environment with programmatic interaction hooks that can support automation, testing, and research workflows. [src-2026-05-02-001]

## Key Claims
- The repository positions `vphone-cli` as a way to boot a virtual iPhone environment via Apple’s virtualization stack on supported macOS hosts. [src-2026-05-02-001]
- The project includes extensive VM lifecycle tooling around setup, firmware preparation, restore, custom-firmware installation, boot, and switching between saved VM states. [src-2026-05-02-001]
- A particularly relevant feature for agent workflows is the documented host control socket, which the README says supports screenshots, touch injection, gestures, hardware keys, and clipboard operations. [src-2026-05-02-001]
- The page explicitly connects that control surface to AI-driven end-to-end testing and references a separate `vphone-mcp` wrapper for higher-level interaction tooling. [src-2026-05-02-001]
- The repository also spans more security-sensitive territory, including patch variants and jailbreak-oriented flows, so it should not be treated as only a generic mobile-testing tool. [src-2026-05-02-001]
