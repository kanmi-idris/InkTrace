# Pulsar

## Summary
This source captures the public GitHub repository page for `software-mansion/pulsar`, a cross-platform haptics SDK spanning iOS, Android, and React Native. Its main value is as a richer haptic primitive than the default system feedback helpers: it exposes presets, custom pattern composition, realtime gesture-driven haptic control, and React Native worklet compatibility through a dedicated Turbo Module. [src-2026-04-26-001]

## Key Claims
- Pulsar presents itself as a haptic feedback SDK for iOS, Android, and React Native rather than as a platform-specific wrapper for only one mobile stack. [src-2026-04-26-001]
- The feature set described in the README includes built-in haptic presets, system feedback styles, a pattern composer for custom sequences, and a realtime composer for live amplitude and frequency control. [src-2026-04-26-001]
- The React Native package is positioned as worklet-compatible, with all preset functions and hook methods said to work inside Reanimated worklets. [src-2026-04-26-001]
- The repository structure shows separate native SDKs for Swift and Kotlin, a React Native Turbo Module, an Expo showcase app, and a documentation site, which suggests a multi-surface SDK strategy rather than a thin binding. [src-2026-04-26-001]
- The React Native quick-start example on the captured page installs `react-native-pulsar` together with `react-native-worklets`, reinforcing the worklet-driven interaction model. [src-2026-04-26-001]
- The README also advertises companion apps on the App Store and Google Play so developers can try the haptic presets directly on device. [src-2026-04-26-001]
