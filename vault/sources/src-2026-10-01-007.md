# e2e: Open-source agentic testing framework for web and mobile apps

## Summary
TesterArmy's `e2e` is a TypeScript test framework that mixes deterministic checks with natural-language agent actions. Its built-in engines cover Playwright web tests and iOS/Android simulators or emulators. [src-2026-10-01-007]

## Key Claims
- The README says verified agent action steps can replay from cache without another model call until the app changes. Other agent operations still call the model. [src-2026-10-01-007]
- The repository lists an Apache-2.0 license and says the project is in active development before 1.0. I did not install or run it. [src-2026-10-01-007]
