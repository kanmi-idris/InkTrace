# GSAP animation platform

## Summary
GSAP is a JavaScript animation library for web properties, including CSS, SVG, canvas, and React interfaces. It is not a video renderer. [src-2026-11-04-022]

## Notes
The standard license permits commercial use without charge. It restricts use in competing visual animation-builder products without prior written consent. [src-2026-11-04-022]
