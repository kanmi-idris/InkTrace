# React Navigation 8.x Bottom Tab Navigator documentation

## Summary
The 8.x docs describe `tabBarRole`, search-tab behavior, and native-tab platform limits. [src-2026-10-15-014]

## Key Claims
- `tabBarRole: 'prominent'` can produce prominent styling on iOS 27 and later. Only one tab can use that role. [src-2026-10-15-014]
- `tabBarRole: 'search'` selects the system search tab. On iOS 27, prominent styling also requires `tabBarSearchAutoFocus` and no other prominent tab. [src-2026-10-15-014]
- `tabBarSearchAutoFocus` requires a nested native stack with `headerSearchBarOptions`. [src-2026-10-15-014]
- `tabBarSidebarPreferredPlacement` is supported with native tabs on iOS 27 and later. `tabBarVisibilityAnimationEnabled` is supported with native tabs on iOS 18 and later. [src-2026-10-15-014]
