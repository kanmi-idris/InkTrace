# Buzz — Block's Open-Source Team Chat with AI Agents

## Summary

Jack Dorsey's Block launched Buzz (July 21, 2026), an open-source group chat platform that merges team chat, Git hosting, and AI agents into one Nostr-signed workspace. Each human and AI agent gets a cryptographic identity with permissions. v0.4.21, Apache 2.0, desktop app for macOS/Windows/Linux.

## Key Claims

1. **Buzz collapses chat + Git + AI agents** into one event log where humans and agents share the same identity structure (Nostr key pairs, channel memberships, audit trails).

2. **Nostr-based architecture:** every action is a cryptographically signed event, giving both humans and agents accountable identities with audit trails.

3. **Model-agnostic, decentralized, self-sovereign, open source** — not tied to one AI model or central hosting; teams can self-host and customize.

4. **Category signal:** Buzz, Centaur (Paradigm), and Anthropic hiring Zulip leadership suggest "team-context tooling for AI agents" is becoming its own category, separate from agent harnesses (Claude Code, Codex, Goose).

5. **Open problem:** multiplayer agent permission model — what an agent can say across channels it has access to but a given human doesn't — is unsolved in Buzz and everywhere else.
