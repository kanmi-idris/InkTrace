# Codex Slides — Open-Source AI Slide Studio Inside Codex

## Summary
An open-source AI slide studio that lives inside Codex (OpenAI's coding agent). 45 curated deck templates + 73 community styles + 24 guided scenarios. Fast mode renders 10+ slides in ~4-5 minutes. Exports PPTX and PDF. Browser-first, zero extra API keys. MIT license, 180 stars.

## Key Claims
- Open-source AI slide studio inside Codex; turn prompts, repos, or files into presentation decks. [src-2026-07-22-005]
- Fast mode renders every page in parallel — 10+ slides in ~4-5 minutes. [src-2026-07-22-005]
- 45 curated deck templates across 15 professional categories + 73 community styles across 12 groups + 24 guided scenarios in 6 groups. [src-2026-07-22-005]
- Exports real PPTX and PDF with speaker notes preserved. [src-2026-07-22-005]
- Browser-first: operates in Codex's in-app Browser, zero separate API keys. [src-2026-07-22-005]
- Durable projects saved to disk; cross-surface synchronization. [src-2026-07-22-005]
- 38 typed MCP tools + portable CLI + Codex plugin + Skill. [src-2026-07-22-005]
- Stack: Next.js 14, TypeScript, pnpm workspace. [src-2026-07-22-005]
- Features: deep research, Gen-UI clarification, Design Files, Brand & Design System, version history, mark editing, presenter mode, queued follow-ups. [src-2026-07-22-005]
- Positioned as open-source alternative to Gamma and Tome; image-native (full-slide images in PPTX, not editable shapes). [src-2026-07-22-005]
- English / Simplified Chinese / Japanese UI. [src-2026-07-22-005]
