# baraa-rasheed/react-native-skia-chart repository

## Summary
`react-native-skia-chart` is a Skia-based chart component library for React Native and Expo, with Reanimated animation and gesture support. The maintainer positions it as a successor to Rainbow's animated charts. [src-2026-11-04-014]

## Key Claims
- The README advertises 15+ chart types and 18 components, including line, area, bar, pie, scatter, radar, candlestick, heatmap, gauge, and ring charts. [src-2026-11-04-014]
- The project documents touch scrubbing, selection, zoom, gradients, filters, and shader effects. [src-2026-11-04-014]
- The library requires a development build and does not run in Expo Go. [src-2026-11-04-014] [src-2026-11-04-015]
- GitHub displayed release 0.3.0 and 12 stars at capture. Its latest visible main-branch check showed failure. [src-2026-11-04-014]
- The package is MIT-licensed. [src-2026-11-04-014] [src-2026-11-04-016]

## Notes
The release, popularity, and check status are point-in-time repository observations. The “successor” description is the maintainer's positioning. [src-2026-11-04-014]
