# API Anything live feasibility probes

## Summary
A project research note dated 2026-09-27 reports limited read-only probes across X, Instagram, Hacker News, Google Flights, and Reddit. It shows that useful website data can be HTML or embedded payloads, and that bot challenges can remain blocking. [src-2026-11-02-003]

## Key Claims
- The note says X, Instagram, and Google Flights served relevant page data through HTML or embedded payloads in some hard-load cases. [src-2026-11-02-003]
- Hacker News used an HTML document in the tested flow; no JSON API was observed. [src-2026-11-02-003]
- Reddit remained behind a reCAPTCHA page in the tested contexts; result data was not verified. [src-2026-11-02-003]
- Google Flights BotGuard enforcement was inconsistent in the small test set, and token lifetime was unknown. [src-2026-11-02-003]
- Some sites returned HTTP 200 while serving HTML challenges or application-level errors. The note recommends checking content and extracted fields, not status alone. [src-2026-11-02-003]

## Notes
This is a limited, dated, project-authored experiment. It does not demonstrate general bot bypass or guaranteed access. General architecture is in [src-2026-11-02-001] and [src-2026-11-02-002].
