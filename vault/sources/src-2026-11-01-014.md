# Searchata MCP tool reference

## Summary
Searchata's tool reference describes 20 read-only tools for search, analytics, performance, and backlink research. Data tools require an active trial or paid plan. [src-2026-11-01-014]

## Key Claims
- The tool reference describes 20 read-only tools. [src-2026-11-01-014]
- Tool groups include Search Console and Bing data, performance reporting, URL inspection, content guidelines, PageSpeed, Chrome UX Report, and backlink research. [src-2026-11-01-014]
- Searchata says backlink lookup can query a public target domain without a connected property. [src-2026-11-01-014]
- The docs describe rate limits, concurrency limits, source-provider limits, quotas, report caching, and crawl credits. [src-2026-11-01-014]

## Notes
These are vendor-published tool descriptions and limits. No MCP tools were called. See product scope in [src-2026-11-01-011] and plan details in [src-2026-11-01-013].
