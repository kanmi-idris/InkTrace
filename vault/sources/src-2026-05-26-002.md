# Orval documentation

## Summary
This source captures the official Orval documentation entry point. It is best understood as OpenAPI-driven frontend code-generation infrastructure: a primary reference for generating typed API clients and adjacent data-layer integrations from backend schemas instead of hand-maintaining repetitive request and query boilerplate. [src-2026-05-26-002]

## Key Claims
- Orval’s main architectural value is not a runtime abstraction but a generation step that derives frontend API-access code from OpenAPI contracts. [src-2026-05-26-002]
- In the current catalog context, its strongest use case is generating schema-aligned CRUD and query layers for frontend apps so backend changes can be propagated by regeneration instead of manual rewriting. [src-2026-05-26-002]
- The tool is therefore useful as a drift-reduction mechanism between backend contracts and frontend request, type, and query definitions. [src-2026-05-26-002]
