# Claude animation skills installer scripts

## Summary
The inspected installer creates or updates skill symlinks under `~/.claude/skills/` and runs a setup script. The default setup downloads dependencies and a Chromium build. [src-2026-11-04-036]

## Key Claims
- The default script installs npm dependencies, Playwright Chromium, GSAP, and HyperFrames. [src-2026-11-04-036]
- Voice setup is optional. `--voice` or `--stick` creates a Python environment, installs packages, and downloads about 1 GB of Kokoro and Parakeet model files. [src-2026-11-04-036]
- The command in the user's post omits `--voice`, so it does not request the voice-model setup. [src-2026-11-04-036]
