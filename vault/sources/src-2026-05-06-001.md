# Introducing deepsec

## Summary
This source captures Vercel’s announcement of `deepsec`, an open-source security harness for codebase vulnerability research powered by coding agents. Its main value is as a concrete pattern for agent-assisted AppSec: start with cheap candidate discovery, let agents investigate and trace data flow, run a second validation pass, enrich the findings with ownership context, and export them as actionable remediation work. [src-2026-05-06-001]

## Key Claims
- deepsec is positioned as a self-hostable or user-controlled security harness that can scan privileged codebases without requiring a separate cloud service to hold the source. [src-2026-05-06-001]
- The workflow is explicitly multi-stage: scan, investigate, revalidate, enrich, and export rather than a single-pass “AI scan.” [src-2026-05-06-001]
- The article frames the system as using agent reasoning after a regex-only candidate scan, with a second agent pass used to cut false positives and refine severity. [src-2026-05-06-001]
- It also emphasizes scale and customization: optional fanout to Vercel Sandboxes for large jobs, plus plugin-based custom scanners tuned to local auth or data-layer conventions. [src-2026-05-06-001]
- The post reports a false-positive rate in the 10–20% range and says the tool works best for applications and services rather than general-purpose libraries. [src-2026-05-06-001]
