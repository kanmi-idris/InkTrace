# Ooyaa repository and security documentation

## Summary
Ooyaa's public repository documents a mainnet payroll factory and demo payroll, permissionless payday execution, and an eight-check proof page. It says the project has not received an external audit. [src-2026-11-01-003]

## Key Claims
- The README lists Arc mainnet chain ID 5042, a PaydayFactory, a demo payroll, and the Arc USDC contract address. [src-2026-11-01-003]
- It documents any-wallet `run()` calls, sequential exactly-once periods, and a USDC tip to the runner. [src-2026-11-01-003]
- It reports 89 unit/fuzz/invariant tests, six real-USDC fork tests, and 228 app tests as of 2026-10-31. These results are project-reported. [src-2026-11-01-003]
- The README and threat model say there has been no external audit. [src-2026-11-01-003]
- The threat model says Circle can blocklist an address and Arc validators can delay or censor transactions. [src-2026-11-01-003]
