# Sand3D Hugging Face datasets and Explorer

## Summary
The five dataset-server configs contain 106,094 rows in total. The Explorer reports 103,797 objects and lists 2,297 AutoMate parts separately from its 872 AutoMate objects. The counts support 100,000+ cataloged items, but no cross-dataset deduplication was performed. [src-2026-11-05-007]

## License and rebuild caveats
The dataset cards show CC BY 4.0. Rows include source-license and attribution fields, with visible source licenses that vary. The Explorer says programs were rerun in fresh processes and retained only when they rebuilt the stored object; this report was not independently reproduced. [src-2026-11-05-007]
