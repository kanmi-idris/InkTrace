# Appduct: Secure Function Calls into Running React Native, iOS, and Android Apps

## Summary
Appduct is a MIT-licensed tool for terminals, tests, and AI agents to call explicitly registered functions in running mobile apps. Its documentation describes CLI and MCP access, build-time exclusion by default for release builds, and key-pinned connections. [src-2026-09-23-004]

## Key Claims
- The app exposes only functions its developers register. Appduct does not add a hidden debug menu or arbitrary code execution. [src-2026-09-23-004]
- The repository describes React Native, native iOS, and native Android integrations. Tools can be called through the CLI, tests, or an MCP client. [src-2026-09-23-004]
- Debug builds include Appduct by default. Release builds exclude it by default. Internal builds can opt in through build configuration. [src-2026-09-23-004]
- Security documentation describes encrypted connections, key-based host identity, short-lived single-use bootstrap links, and stronger pinned trust for distributed builds. [src-2026-09-23-004]
- The docs state that a compromised operator machine, a same-user process, or a destructive registered tool can act within its access. [src-2026-09-23-004]
