# Watercolor: browser painting app with spectral pigments

## Summary
Watercolor is a browser painting app. Its README describes spectral pigment mixing, wet and dry paint behavior, SVG tracing, wash fill, and several brush tools. The hosted app loaded during inspection. [src-2026-10-06-010]

- The live Text tool showed 58 font options. The README describes the lettering as single-line plotter fonts. [src-2026-10-06-010]
- The README lists 14 brushes, 10 paper types, SVG tracing, wash fill, history, and image export. [src-2026-10-06-010]
- The project uses TypeScript, WebGL2, and Preact. The README says the hosted app needs no install. [src-2026-10-06-010]
