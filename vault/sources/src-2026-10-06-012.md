# Agent Memory Repo: open spec for Git-based agent memory

## Summary
Agent Memory Repo is an MIT-licensed open spec for Git-based agent memory. It uses a short `MEMORY.md` index, linked files, and a loop for agents to read and update memory across sessions. [src-2026-10-06-012]

## Key Claims
- Memory can use Markdown, scripts, SQL, and other files. Entries can include source links and dates. [src-2026-10-06-012]
- The spec describes periodic cleanup that can merge duplicates, remove stale entries, and check sources for contradictions. [src-2026-10-06-012]
- The documentation describes separate, opt-in memory repositories for shared sessions. [src-2026-10-06-012]
- The Cognition page says to push after each edit. The GitHub README says to commit after each edit. [src-2026-10-06-012]
