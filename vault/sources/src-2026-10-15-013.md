# React Navigation 8.x icon documentation

## Summary
The official 8.x icon docs describe SF Symbols, Material Symbols, asset-catalog icons, and React Native Nano Icons integration for native tabs. [src-2026-10-15-013]

## Key Claims
- The docs support custom SF Symbol names from the app asset catalog and TypeScript module augmentation through `SFSymbolNames`. [src-2026-10-15-013]
- The docs list `monochrome`, `hierarchical`, `palette`, and `multicolor` as SF Symbol rendering modes. [src-2026-10-15-013]
- The docs describe `nativeNanoSymbol` as returning an SF Symbol name on iOS and a vector-drawable-backed image resource on Android. [src-2026-10-15-013]
- The docs say Nano symbol names are added to `SFSymbolNames` automatically. [src-2026-10-15-013]
- Material Symbols support configurable variants, weights, and filled glyphs. [src-2026-10-15-013]
