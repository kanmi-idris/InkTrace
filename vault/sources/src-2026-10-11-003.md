# ManimGX agent setup and rendering guide

## Summary
The ManimGX `llms.txt` gives coding agents setup and rendering steps. It specifies Python 3.13 or 3.14, then instructs an agent to install, write a Python scene, inspect it, render an MP4, and open the file. I read these instructions but did not execute them. [src-2026-10-11-003]

## Key Claims
- The guide recommends `uv tool install --python 3.14 manimgx`. It says pip works in a virtual environment with Python 3.13 or 3.14. [src-2026-10-11-003]
- The guide says FFmpeg and LaTeX do not need separate installation. It says Linux wheels include Mesa lavapipe for CPU rendering when no suitable GPU is available. [src-2026-10-11-003]
- The guide says the default render is 1920×1080 at 60 fps. It recommends `manimgx inspect` before `manimgx render`. [src-2026-10-11-003]
- The guide says 3D scenes get storyboards and timelines, but skip 2D layout checks. The inspection checks only sampled moments. [src-2026-10-11-003]
- The guide tells an agent to request approval before running outside a GPU-restricted sandbox. I did not follow this instruction or run the animation prompt. [src-2026-10-11-003]
