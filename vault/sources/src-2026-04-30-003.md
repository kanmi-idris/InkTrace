# Quran Database

## Summary
This source captures the supplied repository page text for `AbdullahGhanem/quran-database`, a MySQL dump and schema for Quran text, translations, editions, and related metadata. Its main value is as a structured reference dataset that could support search, reading applications, APIs, and downstream scholarly or product work without starting from raw text extraction. [src-2026-04-30-003]

## Key Claims
- The repository presents itself as a comprehensive MySQL database containing the complete Quran text together with multiple translations and editions. [src-2026-04-30-003]
- The documented schema separates surah metadata, original Arabic ayah text, edition-specific or translation-specific ayah text, and additional scholar or metadata fields into distinct tables. [src-2026-04-30-003]
- The setup path is deliberately simple: extract the SQL dump and import it directly into MySQL. [src-2026-04-30-003]
- The roadmap frames the project as a possible foundation for richer religious-reference infrastructure, including normalized divisions such as juz and hizb, word-level morphology, tafsir, recitation references, and linked hadith or revelation metadata. [src-2026-04-30-003]
- The project also explicitly points toward backend and product layers such as REST or GraphQL APIs, Arabic full-text search, authentication, pagination, Docker deployment, and browsing applications. [src-2026-04-30-003]
- The README states that the Quran text is in the public domain, which matters for reuse and downstream packaging. [src-2026-04-30-003]
