# expo-native-variants: Expo config plugin for native build variants

## Summary
The repository describes an Expo config plugin that generates development, preview, and production native variants through one prebuild. It configures Xcode schemes and Android flavors, with separate identifiers, names, URL schemes, and icons. [src-2026-10-01-004]

## Key Claims
- The README says existing variants can be selected without another prebuild. Native dependency or configuration changes require another prebuild. [src-2026-10-01-004]
- The repository describes the package as an early release targeting Expo SDK 57. I did not install or validate it. [src-2026-10-01-004]
