# Kotlin Multiplatform vs React Native (2026 Benchmark) by Software Mansion

## Summary

Software Mansion built the same SpaceX launch list app in KMP (Compose Multiplatform) and React Native (Expo) to produce measured performance data. Five benchmark rounds across 6 devices (3 Android, 3 iOS) covering app size, startup time, RAM, CPU, and Flashlight scoring.

## Key Claims

- KMP Android APK (arm64) is ~2.0 MB download / 3.9 MB installed vs RN's 15.8 MB / 33.8 MB — roughly 8x smaller due to no JS bundle and effective R8 pruning. [src-2026-07-03-004]
- iOS app sizes near tie: KMP 11.2 MB download vs RN 9.9 MB download. [src-2026-07-03-004]
- KMP reaches first frame 2-4x faster than RN on Android cold start (e.g., Pixel 7: KMP 158ms vs RN 410ms TTID). [src-2026-07-03-004]
- On modern iOS (iPhone 16/17), startup times are nearly identical (20-28ms TTID difference). [src-2026-07-03-004]
- KMP uses ~half the PSS RAM of RN on Android (e.g., Pixel 7: KMP 120.5 MB vs RN 232.2 MB avg PSS). [src-2026-07-03-004]
- RN uses 3-4x less memory than KMP on iOS (e.g., iPhone 16: RN 56.4 MB vs KMP 230.2 MB avg). [src-2026-07-03-004]
- CPU results inconclusive — heavily sensitive to test execution details. [src-2026-07-03-004]
- Flashlight scores near identical on Android (97-99 across both frameworks); RAM figures align with manual measurement. [src-2026-07-03-004]
