# LangChain Eval Engineering Skill — Official SKILL.md

## Summary
The official LangChain eval-engineering skill in the langchain-skills repo (934★, 79 forks). Implements a 6-step iterative workflow: map agent → choose direction → approve runtime → build Harbor task → test/run/audit → review with user. Includes 5 reference documents (harbor, task-design, environment-building, trace-sourcing, verifier-design). One capability per Harbor task, no production writes, LLM judges for semantic success.

## Key Claims
- 6-step eval engineering workflow: inspect agent and interview user → propose directions → user chooses → approve runtime and environment → build, run, audit → review and repeat. [src-2026-07-22-010]
- Agent mapping captures: runtime, actions, backing data, state, purpose, evidence. Read-only; no services/credentials started before user approval. [src-2026-07-22-010]
- Two runtime modes: active entrypoint (recommended) vs reconstruction (when active entrypoint can't run in controlled eval). [src-2026-07-22-010]
- One capability per Harbor task under `evals/<task-id>/` with structure: task.toml, instruction.md, environment/, tests/. [src-2026-07-22-010]
- Adapters may translate I/O and inject dependencies but must not make target decisions or contain answers. [src-2026-07-22-010]
- LLM judge for semantic success, deterministic checks for execution/parsing/files/state. One primary reward. [src-2026-07-22-010]
- Invariants: no production writes, keep hidden truth from target, treat infrastructure errors as infrastructure errors. [src-2026-07-22-010]
- 5 reference documents: harbor.md, task-design.md, environment-building.md, trace-sourcing.md, verifier-design.md. [src-2026-07-22-010]
