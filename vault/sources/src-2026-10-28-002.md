# ConitePay React package on npm

## Summary
The npm page listed `@conitepay/react` version `0.1.5` at capture time. Its README documents popup checkout, three processor adapters, backend callbacks, and a built-in selector. [src-2026-10-28-002]

## Key Claims
- The README describes one `pay()` API for Paystack, Flutterwave, and Interswitch. [src-2026-10-28-002]
- It documents a required `verify` callback and `initialize` callback that delegates processor API calls to the merchant backend. [src-2026-10-28-002]
- It documents debug logging and a default 20-second initialization timeout. [src-2026-10-28-002]
- It says the default processor can launch automatically; otherwise, the SDK shows a selector UI. [src-2026-10-28-002]
- The README says the web modal shell cannot be restyled through its selector props. A branded or full-screen shell needs a fully custom selector. [src-2026-10-28-002]
- The README requires a same-origin callback URL for web popup completion detection. [src-2026-10-28-002]
- The npm README says MIT, but npm's package sidebar displayed `none`, and the registry version metadata had no `license` property. This is an unresolved metadata difference. [src-2026-10-28-002]
