# Davyd NRB’s React Native direct-imports announcement on X

## Summary
Davyd NRB announces a Babel plugin that rewrites React Native barrel imports to direct module requires. The thread reports a 711 KB to 10.6 KB example and a separate best-case change from 505 to 9 modules. These are author-reported figures, not independently reproduced. [src-2026-10-20-017]

## Key Claims
- The opening post reports a change from 711 KB to 10.6 KB for an app importing one API. [src-2026-10-20-017]
- A thread reply reports a best-case change from 505 to 9 modules and from 448 to 1 React Native file. It says savings depend on app usage. [src-2026-10-20-017]
- The thread says the plugin supports stable React Native releases from 0.70, Metro, Expo, re-exports, compiled CommonJS, and `Platform.OS` / `Platform.select` inlining. [src-2026-10-20-017]
- The author describes the plugin as early-stage and asks users to report issues. [src-2026-10-20-017]
