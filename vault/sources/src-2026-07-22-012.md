# "Don't Train the Model, Evolve the Harness" / Meta-Harness

## Summary
Joel Niklaus (HF ML Engineer) interactive demo of Meta-Harness on Harvey's Legal Agent Benchmark. DeepSeek-V4-Pro with frozen weights scores 3.5%–80.1% across 5 harnesses (76-point gap). After ~22 auto-iterations: 80.1%, matching Claude Sonnet 4.6 at 1/7 cost. Meta-Harness paper (Lee et al., Stanford/KRAFTON/MIT) gives proposer filesystem access to full traces (10M tok/step vs ≤26K prior methods). Results: #1 Haiku 4.5 on TB2 (37.6%), #2 Opus 4.6 (76.4%), +7.7pp text classification, +4.7pp math reasoning.

## Key Claims
- Same frozen model scores 3.5% to 80.1% across 5 different agent harnesses — a 76-point gap entirely from the harness, not the model. [src-2026-07-22-012]
- After ~22 automatic iteration rounds: pooled score 63.4% → 80.1%, all-pass rate 0% → 5.0%. [src-2026-07-22-012]
- Optimized DeepSeek-V4-Pro harness matches Claude Sonnet 4.6 at 1/7 the operating cost. [src-2026-07-22-012]
- Same optimized harness migrated to V4-Flash: +14.4 point improvement — harness engineering transfers across models better than prompt tuning. [src-2026-07-22-012]
- Meta-Harness provides filesystem with full source code, scores, and execution traces of all prior candidates — up to 10M tokens per step vs ≤26K for all prior optimization methods surveyed. [src-2026-07-22-012]
- Meta-Harness on TerminalBench-2: #1 among all Claude Haiku 4.5 agents (37.6%, next best Goose 35.5%), #2 among all Claude Opus 4.6 agents (76.4%, best ForgeCode 81.8%). [src-2026-07-22-012]
- Text classification: 48.6% vs ACE's 40.9% (+7.7pp, 4× fewer tokens); LawBench (215 classes): +16pp. [src-2026-07-22-012]
- Math reasoning: +4.7pp average across 5 held-out models on 200 IMO-level problems (34.1% → 38.8%). [src-2026-07-22-012]
- Andrej Karpathy's AutoResearch: 700 automatic iterations found 20 code improvements overlooked by humans. Shopify CEO: 19% quality improvement, half model size. [src-2026-07-22-012]
- Paper: Meta-Harness: End-to-End Optimization of Model Harnesses, arXiv 2603.28052. [src-2026-07-22-012]
