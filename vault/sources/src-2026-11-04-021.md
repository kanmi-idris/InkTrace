# Resemble AI Chatterbox repository

## Summary
Chatterbox is a family of open-source text-to-speech models. The repository lists multilingual, Turbo, and Nano variants. [src-2026-11-04-021]

## Notes
The Turbo voice-cloning example uses a reference audio clip. Some variants support CPU or MPS, while examples also use CUDA. The README points to a separate paid hosted TTS service. Local model availability does not remove compute costs or grant rights to clone a person's voice. [src-2026-11-04-021]
