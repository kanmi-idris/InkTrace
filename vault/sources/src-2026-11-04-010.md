# react-native-tgfx official documentation

## Summary
react-native-tgfx is a declarative GPU 2D canvas for React Native, backed by Tencent's tgfx and built with Nitro Modules. The documentation labels it alpha. [src-2026-11-04-010]

## Key Claims
- The project documents shapes, paths, text, images, paint effects, shaders, animation, headless rendering, camera frames, and PDF/SVG export. [src-2026-11-04-010]
- The docs say Android uses Vulkan by default, with OpenGL ES as an option; iOS uses Metal. [src-2026-11-04-010]
- The installation page uses `react-native-tgfx@alpha` and `react-native-nitro-modules`. Camera and video paths need Reanimated and Worklets. [src-2026-11-04-010]
- The repository states React Native 0.78+ with the New Architecture, Xcode 16.4+, Android NDK 27+, and compileSdk 34+. [src-2026-11-04-010] [src-2026-11-04-011]

## Notes
UI-thread animation and backend performance statements are project claims. See the limited benchmark conditions in [src-2026-11-04-012].
