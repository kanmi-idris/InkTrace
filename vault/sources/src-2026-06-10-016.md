# The Agency: AI Specialists Ready to Transform Your Workflow

## Summary
This source captures a large open repository of installable agent personas. Its core proposition is that useful AI-agent work can be packaged as role-specific, personality-rich markdown agents with explicit workflows, deliverables, and tool-specific installation paths, spanning not just Claude Code but also Copilot, Cursor, Codex, Gemini CLI, Aider, Windsurf, and others. [src-2026-06-10-016]

## Key Claims
- The repository positions its agents as specialized experts with personality, process, and deliverable orientation rather than as generic prompt snippets. [src-2026-06-10-016]
- The project supports both direct installation and conversion workflows across multiple coding-agent tools, which makes it more of an agent-distribution layer than a single-tool prompt pack. [src-2026-06-10-016]
- The roster is organized into divisions and includes many narrowly scoped roles such as frontend developer, incident response commander, prompt engineer, multi-agent systems architect, UX researcher, and paid-media specialists. [src-2026-06-10-016]
- The installer allows selective installation by team or individual agent, which implies a workflow where users assemble a task-specific agent roster rather than always loading the full catalog. [src-2026-06-10-016]
