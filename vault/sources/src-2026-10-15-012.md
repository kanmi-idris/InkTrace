# React Navigation 8 alpha: icons and iOS 27 updates

## Summary
React Navigation's October 14 X article describes icon updates and iOS 27 features for React Navigation 8 alpha. It covers custom SF Symbols, Material Symbols, native bottom-tab roles, and native-stack header items. [src-2026-10-15-012]

## Key Claims
- The article says custom SF Symbols from an app asset catalog can be used in bottom tabs and the `SFSymbol` component. It shows a TypeScript `SFSymbolNames` augmentation. [src-2026-10-15-012]
- The article says icon `renderingMode` supports monochrome and multicolor, and says Android native tab icons can disable tint. [src-2026-10-15-012]
- The article says React Native Nano Icons can turn SVGs into icons for native tabs. [src-2026-10-15-012]
- The article reports filled Material Symbols, RTL mirroring, and smaller bundled fonts. It gives before-and-after size figures. These size figures are publisher-reported; I did not measure them. [src-2026-10-15-012]
- The article describes `tabBarRole` values for prominent and search tabs, plus new Bottom Tabs and Native Stack options. The current docs are captured in [src-2026-10-15-014] and [src-2026-10-15-016].
