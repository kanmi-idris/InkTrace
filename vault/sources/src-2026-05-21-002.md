# react-native-nitro-biometrics

## Summary
This source captures the public `react-native-nitro-biometrics` subproject inside `frankudoags/nitro-modules`. It is best understood as a focused React Native native-module utility: a simple Nitro Modules-based biometrics wrapper for iOS and Android with Expo config-plugin support, manual bare-app permission guidance, and explicit lineage from `expo-local-authentication`. [src-2026-05-21-002]

## Key Claims
- The package positions itself as a simple Nitro-based biometrics authentication module for iOS and Android. [src-2026-05-21-002]
- It depends on `react-native-nitro-modules`, which makes it relevant to the newer Nitro Modules ecosystem rather than only to classic bridge-based packages. [src-2026-05-21-002]
- The package includes an Expo config plugin for Face ID permission setup, making it usable in Expo prebuild-style workflows in addition to bare React Native apps. [src-2026-05-21-002]
- The repository structure shows platform folders, generated nitrogen bindings, plugin wiring, and a podspec, which together make it a concrete implementation reference for small Nitro-based native modules. [src-2026-05-21-002]
- The README’s credit section is an important nuance: the package is partly derived from `expo-local-authentication` rather than being an entirely original biometrics implementation. [src-2026-05-21-002]
