# ISO-GLOW: Claude skill for interactive isometric figures

## Summary
ISO-GLOW is an MIT-licensed Claude skill for creating interactive, single-file isometric illustrations. The inspected ZIP contains a self-contained HTML template and two JavaScript examples. [src-2026-10-07-008]

## Key Claims
- The site says the skill produces figures from plain-language descriptions. It offers Claude Code, Claude.ai, and manual ZIP paths. [src-2026-10-07-008]
- The ZIP contains five files. The license credits April Zhu and Tolga Cohce. [src-2026-10-07-008]
- Static inspection found one external Google Fonts stylesheet and local storage for the palette. It found no external script imports or common network and dynamic-code APIs in the template and examples. [src-2026-10-07-008]
