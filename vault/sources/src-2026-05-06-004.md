# Coolify

## Summary
This source captures the public Coolify product page. It is best understood as self-hosted PaaS and deployment infrastructure: an open-source platform that tries to give teams a Vercel/Heroku/Netlify/Railway-style deployment experience while keeping apps, databases, settings, and operational control on servers they own. [src-2026-05-06-004]

## Key Claims
- Coolify positions itself as an open-source and self-hostable alternative to major hosted deployment platforms. [src-2026-05-06-004]
- The page emphasizes breadth rather than a narrow framework niche: many languages, many server types, many use cases, and many Docker-compatible services. [src-2026-05-06-004]
- Its workflow features map closely to mainstream platform expectations, including push-to-deploy, SSL automation, PR deployments, monitoring, notifications, webhooks, and API automation. [src-2026-05-06-004]
- The self-hosting angle is central to the value proposition: no vendor lock-in, control over settings and data, and the ability to deploy to arbitrary SSH-reachable infrastructure. [src-2026-05-06-004]
- The platform also exposes operator-facing control surfaces such as a CLI and a browser-based real-time terminal, which broadens it from simple app deployment into day-two infrastructure management. [src-2026-05-06-004]
