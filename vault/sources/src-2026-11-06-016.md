# react-native-nitro-rolling-number

## Summary
A native rolling-digit component for React Native built with Nitro Modules. Digit animations run in shared C++ engines on iOS and Android, and value updates cross JSI, so animation continues while the JS thread is busy.

## Key Claims
- Targets React Native 0.78+ with New Architecture and Nitro Modules 0.37+. [src-2026-11-06-016]
- Features include fraction digits, grouping and currency formatting, zero padding, negative values, easing and spring and jackpot modes, VoiceOver, TalkBack, Reduce Motion, Fabric recycling, and imperative move APIs. [src-2026-11-06-016]
- README release-build benchmarks with 24 components updating each frame report 120 fps and zero dropped frames on iPhone 13 Pro Max, and 60 fps with zero dropped frames on Pixel 10. Project-published claims; BENCHMARKS.md was not inspected at capture. [src-2026-11-06-016]
- The same repository publishes react-native-nitro-input and WebAssembly builds of the engines for browser demos. [src-2026-11-06-016]
