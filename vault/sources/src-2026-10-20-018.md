# babel-plugin-react-native-direct-imports GitHub repository snapshot

## Summary
The public repository documents a Babel plugin that rewrites React Native barrel imports to direct requires of React Native internals. It calls itself early-stage and warns of rough edges and breaking changes. [src-2026-10-20-018]

## Key Claims
- The README says the plugin replaces `react-native` imports with direct `require()` calls, to include only used APIs in the bundle. [src-2026-10-20-018]
- The README says to set the exact installed `reactNativeVersion`. It lists maps for stable releases from 0.70.0 and requires a Metro cache reset after setup. [src-2026-10-20-018]
- The README says re-exports and compiled CommonJS code are rewritten. It says namespace imports and `module.exports = require('react-native')` cause build errors. [src-2026-10-20-018]
- The README says `Platform.OS` and `Platform.select` inlining remains supported. [src-2026-10-20-018]
- The README warns against use with `react-native-worklets` bundle mode. It lists an MIT license. [src-2026-10-20-018]
