# WebPerf Snippets and Agent SKILLs: deterministic audits with Chrome DevTools MCP

## Summary
This source argues for a deterministic agent-tooling pattern in which executable audit scripts live as separate files inside a SKILL and are invoked through Chrome DevTools MCP rather than being pasted inline into markdown instructions. The claimed benefits are measurement consistency, lower token usage, and better workflow automation for web-performance analysis. [src-2026-04-13-005]

## Key Claims
- Keeping JavaScript inline inside a text-only SKILL wastes tokens and leaves room for an LLM to reinterpret or alter the measurement code, which is undesirable for performance diagnostics. [src-2026-04-13-005]
- Storing the executable audit logic in `.js` files inside the SKILL scope lets the agent load only the script it needs and execute validated code deterministically. [src-2026-04-13-005]
- The article describes Chrome DevTools MCP as the execution layer that lets the agent navigate, run scripts with `evaluate_script`, capture output, compare results against thresholds, and trigger decision-tree workflows such as deeper TTFB analysis. [src-2026-04-13-005]
- The broader claim is that agents become more autonomous and reliable when they orchestrate tested scripts and workflows instead of improvising ad hoc code from prose instructions. [src-2026-04-13-005]
