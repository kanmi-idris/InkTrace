# cinematic-shot GitHub repository and agent skill

## Summary
The repository contains an agent skill for directing short product-launch films. Its README says the skill defines visual direction and editing, while leaving the rendering stack to the agent. [src-2026-10-15-002]

## Key Claims
- The README describes cinematic hero shots of real product UI, with a black stage, oblique close-ups, shallow focus, motivated camera drift, and hard cuts. [src-2026-10-15-002]
- The skill recommends a 45–55 second film with 8–10 UI shots, followed by product copy and a logo. [src-2026-10-15-002]
- The repository includes `SKILL.md`, `references/look.md`, and `references/shot-list-example.md`. The example is a 52-second film with nine timed UI shots. [src-2026-10-15-002]
- The README provides `npx skills add 1weiho/cinematic-shot`. The repository showed no published releases or packages at inspection. [src-2026-10-15-002]
