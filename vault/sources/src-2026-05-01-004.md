# mapcn

## Summary
This source captures the public GitHub repository page and docs site for `mapcn`, a React mapping toolkit built around copy-paste MapLibre components styled with Tailwind and aligned with `shadcn/ui` conventions. Its main value is that it tries to make maps feel like normal design-system primitives instead of opaque SDK wrappers: easy to start with, easy to theme, and still close to raw map APIs when deeper control is needed. [src-2026-05-01-004]

## Key Claims
- `mapcn` presents itself as a collection of free, open-source, customizable React map components with zero-config setup. [src-2026-05-01-004]
- The project is explicitly built on MapLibre GL and designed to fit into Tailwind and `shadcn/ui` workflows rather than forcing a separate visual or architectural style. [src-2026-05-01-004]
- The docs say the project follows the `shadcn` copy-paste ownership model, meaning teams can bring the components directly into their codebase and customize them without lock-in. [src-2026-05-01-004]
- The stated design goal is to avoid black-box map wrappers by staying close to native MapLibre APIs and allowing escape hatches to the underlying map instance. [src-2026-05-01-004]
- The documented feature set includes theme-aware styling, markers, popups, routes, controls, arcs, clusters, TypeScript support, and compatibility with any MapLibre-style tile provider. [src-2026-05-01-004]
- The docs also claim that the default setup can work without API keys, while the README notes that tile-provider licensing still matters depending on which basemap source is chosen. [src-2026-05-01-004]
