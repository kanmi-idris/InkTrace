## Architecture

- **Spiders** — user-defined classes that define how to crawl and parse
- **Engine** — controls the data flow between components
- **Scheduler** — receives requests from engine and schedules them
- **Downloader** — fetches web pages
- **Item Pipeline** — processes scraped data (cleaning, validation, storage)
- **Middlewares** — hooks into request/response processing
- **Selectors** — CSS/XPath extraction (built on parsel/lxml)
- **Item Loaders** — populate items with processed data

## Features

- Async/await support (Twisted event loop)
- CSS and XPath selectors
- Automatic retries, redirects, and error handling
- Built-in support for exporting to JSON, CSV, XML, etc.
- Extensible middleware architecture
- Telnet console for debugging
- Built-in HTTP caching
- FTP and S3 file export support
- Robots.txt compliance
- Stats collection
- Shell for interactive debugging
- Extensive documentation
