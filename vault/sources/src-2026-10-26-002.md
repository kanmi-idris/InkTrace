# Legend Spark official product and getting-started page

## Summary
Legend’s product page describes Spark as an experimental React Native desktop framework. It documents a prebuilt runner, custom development builds, and standalone Mac app packaging. [src-2026-10-26-002]

## Key Claims
- The page labels Spark “Experimental — not for production.” [src-2026-10-26-002]
- The page lists desktop capabilities including windows, menus, files, settings, secure storage, clipboard, drag and drop, notifications, tray, SQLite, WebView, and updates. [src-2026-10-26-002]
- The page describes a prebuilt Spark Runner with Fast Refresh, custom builds for extra native requirements, and standalone `.app` packaging. [src-2026-10-26-002]
- The page says screens use React Native’s native renderer and JavaScript runs in Hermes. It names macOS 14+ on Apple Silicon as the primary target. [src-2026-10-26-002]
- The page says Intel Mac and Windows builds still need native validation. [src-2026-10-26-002]
