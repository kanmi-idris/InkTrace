# react-native-skia-chart official documentation

## Summary
The docs describe Skia Graphite rendering with Metal on iOS and Vulkan on Android, with Reanimated worklets for animations and gestures. They also describe CPU work in the chart pipeline. [src-2026-11-04-015]

## Key Claims
- The project says chart frames use Skia Graphite through React Native Skia 3.8. [src-2026-11-04-015]
- The docs say shared values update Skia props without a React re-render per frame. [src-2026-11-04-015]
- The docs identify data scaling, path building, text shaping, and gestures as CPU work. GPU rendering does not mean all chart computation is GPU work. [src-2026-11-04-015]
- The docs require an Expo development build, Android minSdk 26 with Vulkan 1.1, and iOS 15.1+. [src-2026-11-04-015]

## Notes
These are project explanations, not independently benchmarked results. [src-2026-11-04-015]
