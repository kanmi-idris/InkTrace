# react-native-transformer-text-input

## Summary
This source captures the supplied repository summary and README-style documentation for `react-native-transformer-text-input`, a New Architecture React Native `TextInput` wrapper that applies synchronous text transforms through a worklet on the UI thread. Its main positioning is that it avoids the lag and cursor flicker associated with controlled-input round trips while still allowing arbitrary transformation logic. [src-2026-04-25-001]

## Key Claims
- The library positions itself as a `TextInput` component that transforms text synchronously with a worklet rather than by waiting for a native-to-JS controlled-input loop. [src-2026-04-25-001]
- The stated motivation is that pattern-based masking is too limited for conditional or context-dependent transforms, while classic controlled inputs can feel sluggish because of asynchronous correction, lag, and cursor flicker. [src-2026-04-25-001]
- The core API combines a `Transformer` worklet wrapper with `TransformerTextInput`, which accepts a transformer instance and exposes imperative methods such as `getValue()`, `update()`, and `clear()` through a ref. [src-2026-04-25-001]
- The transform worklet receives current and previous values plus current and previous selection state, and it can return updated text, updated selection, or no change. [src-2026-04-25-001]
- The library explicitly supports selection control so transforms that insert or remove characters can keep the caret stable or move it deterministically after each edit. [src-2026-04-25-001]
- The supplied notes say the transformer must be a worklet, transformer instances should preferably be created at module scope, and the library supports the New Architecture only. [src-2026-04-25-001]
- The package also includes experimental built-in transformers for declarative pattern formatting and phone-number formatting, with a note that breaking changes may occur in minor versions. [src-2026-04-25-001]
