# Reducing Eye Movement While Reading Code

## Summary
This source refines readability by focusing on eye movement: code becomes harder to understand when the reader must repeatedly jump between distant definitions, nested expressions, or indirection layers just to follow a simple behavior. [src-2026-04-14-005]

## Key Claims
- Readability improves when code can be understood from top to bottom with fewer context shifts across helpers, constants, or distant branches. [src-2026-04-14-005]
- For simple logic, direct conditions inside a component may be clearer than an extra layer of policy abstraction that forces the reader to bounce between multiple symbols. [src-2026-04-14-005]
- Nested ternary operators often obscure branching structure, and rewriting them into `if`-based control flow can make the logic easier to scan and reason about. [src-2026-04-14-005]
- Range checks become easier to read when written in a left-to-right order that mirrors mathematical comparison patterns. [src-2026-04-14-005]
