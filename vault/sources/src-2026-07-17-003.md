# react-native-nitro-vision-kit: On-device background removal & classification (React Native Rewind)

## Summary
The React Native Rewind promotes Sagar Khanal's `react-native-nitro-vision-kit` as an on-device React Native library for background removal and image classification. The post says it uses Apple Vision on iOS and Google ML Kit on Android, with native results and no inference server. [src-2026-07-17-003]

## Key Claims
- The post says the library removes a background with a soft alpha matte and returns masked pixels through a native object. [src-2026-07-17-003]
- The post says image classification returns ranked labels with confidence scores. [src-2026-07-17-003]
- The post describes zero-copy pixel access through a native Nitro HybridObject. It says data stays native until explicitly exported. [src-2026-07-17-003]
- The post's `$0.03 per image` comparison and its claim that every other React Native background-removal feature requires a server call are promotional statements. I did not independently verify them. [src-2026-07-17-003]
- The current repository adds OCR and a combined `analyzeImage` call. Its platform and first-use download limits are recorded as [src-2026-10-15-010].
