# Firecrawl — Web Data API for AI Agents

## Summary

Firecrawl is an open-source (AGPL-3.0) API for searching, scraping, and interacting with the web at scale. Provides clean Markdown/structured JSON output for LLM consumption, with SDKs in 9 languages, CLI, MCP server, and agent skills. 155K★ on GitHub.

## Core Endpoints

| Endpoint | Description |
|----------|-------------|
| **Search** | Search the web and get full page content from results |
| **Scrape** | Convert any URL to markdown, HTML, screenshots, or structured JSON |
| **Interact** | Click, scroll, write, wait, press before extracting (Amazon workflow example) |
| **Agent** | Autonomous data gathering — describe what you need, no URLs required |
| **Crawl** | Scrape all URLs of a website (up to 100 limit default) |
| **Map** | Discover all URLs on a website instantly |
| **Batch Scrape** | Scrape thousands of URLs asynchronously |

## SDKs

Python, Node.js, Go, Java, Elixir, Rust, Ruby, .NET, PHP

## Key Claims

1. **Industry-leading reliability** — 96% web coverage, including JS-heavy pages. P95 latency 3.4s across millions of pages.
2. **LLM-ready output** — clean Markdown, structured JSON, screenshots. Reduced token consumption.
3. **Agent ready** — CLI skill (`firecrawl-cli init --all --browser`), MCP server, works with Claude Code, OpenCode, Antigravity.
4. **Agent endpoint** — evolution of `/extract`; takes a prompt (no URLs required), navigates, searches, retrieves. Optional structured output via Pydantic schema. Spark model: `spark-1-mini` (60% cheaper) or `spark-1-pro` (complex research).
5. **Self-hostable** — AGPL-3.0, Docker Compose, self-hosting guide. Cloud version adds features.
6. **Respects robots.txt** by default. End users responsible for website policies.
