# Crawl4AI — Open-Source LLM-Friendly Web Crawler & Scraper

## Summary

Python-native open-source web crawler that turns web pages into clean, LLM-ready Markdown for RAG, agents, and data pipelines. 74.3K★, #1 trending web crawler on GitHub. Built by unclecode in "turbo anger mode" after being charged $16 for a web-to-markdown tool.

## Features

**Markdown Generation:**
- Clean Markdown with accurate formatting
- Fit Markdown — heuristic-based noise removal for AI processing
- Citations and numbered reference lists
- BM25-based content filtering

**Structured Data Extraction:**
- LLM-driven extraction (all LLMs, open-source and proprietary)
- Chunking strategies (topic-based, regex, sentence-level)
- Cosine similarity for relevant content chunk retrieval
- CSS-based extraction via XPath/CSS selectors and JSON schema

**Browser Integration:**
- Managed browser (user-owned, anti-bot)
- Remote browser control (Chrome DevTools Protocol)
- Browser profiler with persistent profiles, cookies, auth
- Session management for multi-step crawling
- Multi-browser: Chromium, Firefox, WebKit
- Dynamic viewport adjustment

**Crawling:**
- Dynamic JS execution, lazy load handling, full-page scanning
- Screenshots, media extraction (images, audio, video)
- Raw HTML and local file crawling
- Customizable hooks at every step
- Caching, IFrame extraction, metadata extraction
- Anti-bot detection with proxy escalation (3-tier)

**Deployment:**
- Docker with monitoring dashboard, browser pooling, playground, MCP integration
- JWT authentication
- Multi-architecture (AMD64/ARM64)
- Cloud-ready

## Docker Architecture

- Real-time monitoring dashboard with live system metrics
- 3-tier browser pool: permanent/hot/cold
- WebSocket streaming (every 2s)
- Janitor system for resource cleanup
- Prometheus integration
- MCP integration for Claude Code and AI tools
