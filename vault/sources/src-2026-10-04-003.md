# Oil UI: Open-source design skill and mobile app examples

## Summary
Oil UI is an MIT-licensed skill for coding agents. It guides design exploration, side-by-side comparison, and screenshot review. Its gallery includes a three-screen language-learning app demo. [src-2026-10-04-003]

## Key Claims
- The Pip demo shows a learning path, a correct-answer state, and a lesson-completion screen with XP, accuracy, streak, and daily-goal progress. [src-2026-10-04-003]
- The README says the skill checks a public version list and can auto-update. I did not install it or test this behavior. [src-2026-10-04-003]
- Oil UI Pro is listed at $9.99 one time with lifetime updates. [src-2026-10-04-003]

This is a design workflow and example gallery, not a dedicated education-app library. The Pip screens are useful for learning-flow and gamification reference. See the raw capture for the three screen contents and update behavior.
