# overflow-anchor Chat Scroller Tip

## Summary
This source captures a concise CSS trick for keeping a chat or feed scroller pinned near the bottom using `overflow-anchor`. Its value is in replacing manual scroll bookkeeping with native browser anchoring behavior: disable anchoring on normal children, re-enable it on a tiny terminal anchor, and let the browser keep the viewport following appended content. [src-2026-05-12-002]

## Key Claims
- The technique uses browser scroll anchoring behavior instead of `MutationObserver` or imperative `scrollTo()` logic. [src-2026-05-12-002]
- The core mechanism is to disable `overflow-anchor` on the scroller’s content and enable it only on a 1px anchor element at the end. [src-2026-05-12-002]
- This makes the browser treat the end anchor as the scroll reference point, which is useful for chat-style “stick to latest message” behavior. [src-2026-05-12-002]
