# Traffic Source

## Summary
This source captures the public GitHub repository page and README for `traffic-source`. It is best understood as a self-hosted web analytics and attribution tool that combines pageview analytics, conversion tracking, affiliate attribution, and multi-site management in a deploy-it-yourself package. [src-2026-05-01-010]

## Key Claims
- The project is positioned as open-source, self-hosted web analytics with conversion tracking and affiliate management, emphasizing data ownership and low-cost deployment. [src-2026-05-01-010]
- The README claims support for real-time analytics, traffic-source and UTM reporting, geo tracking, device and browser breakdowns, Google Search Console integration, and visitor-journey views. [src-2026-05-01-010]
- Conversion tracking is framed around Stripe integration that polls for payment data rather than relying on webhooks. [src-2026-05-01-010]
- The project also includes an affiliate system with referral links, commission-rate controls, and public dashboards. [src-2026-05-01-010]
- The public README positions the product as privacy-first and cookie-free while keeping collected data on infrastructure controlled by the operator. [src-2026-05-01-010]
- The implementation is presented as a modern JavaScript web app built with Next.js, React, SQLite, JWT-based auth, and a lightweight tracking script. [src-2026-05-01-010]
