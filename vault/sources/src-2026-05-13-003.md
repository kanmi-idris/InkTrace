# React Doctor

## Summary
This source captures the public `react-doctor` repository page. It is best understood as React code-quality and agent-governance infrastructure: a scanner that scores codebases, surfaces diagnostics across multiple concern areas, integrates into CI and lint engines, and can also install agent-specific guidance so future AI edits are shaped by the same rule set. [src-2026-05-13-003]

## Key Claims
- React Doctor positions itself as a one-command React health scanner that outputs a `0` to `100` score plus actionable diagnostics. [src-2026-05-13-003]
- The project explicitly spans Next.js, Vite, and React Native rather than being limited to one React environment. [src-2026-05-13-003]
- It presents itself not only as a CLI but also as a GitHub Action, JSON-producing automation surface, ESLint/Oxlint plugin, and programmatic API. [src-2026-05-13-003]
- A distinctive angle is agent integration: the install flow claims to write repository-local instruction files for many coding agents so the rules shape future generated code rather than only reviewing existing code after the fact. [src-2026-05-13-003]
- The scoring model is framed around unique triggered rules rather than total instances, which makes it more of a breadth-of-problems indicator than a raw violation counter. [src-2026-05-13-003]
