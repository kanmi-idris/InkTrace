# mini-AGI: Byte-level continual-learning language model

## Summary
The repository describes a byte-level model that trains from scratch on one 8 GB VRAM GPU, pages expert weights from disk, and continues learning from a text stream. It labels the model toy-level and says its main weights are not yet published. [src-2026-10-01-006]

## Key Claims
- The README describes a PG19 forgetting experiment with 1,048,576 consecutive characters at batch size 1. The results are repository-reported and were not independently reproduced. [src-2026-10-01-006]
- The supplied description mentions an M2 Max, children's stories, and Tarantino screenplays. The inspected README does not confirm that test. [src-2026-10-01-006]
