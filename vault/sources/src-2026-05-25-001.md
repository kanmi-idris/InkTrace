# Android logcat attach command with PID filter and color output

## Summary
This source captures a small Android debugging workflow tip: use `adb shell pidof` to resolve a running app’s PID, then attach `adb logcat` directly to that process with colorized output, avoiding Android Studio when the goal is only targeted log inspection. [src-2026-05-25-001]

## Key Claims
- The command provides a CLI-first way to attach logcat to one Android app process by package name rather than reading the full device log stream. [src-2026-05-25-001]
- Using `-v color` makes the output easier to scan in terminal sessions that support ANSI colors. [src-2026-05-25-001]
- The practical value is reduced setup time during debugging because the workflow avoids opening Android Studio just to view logs. [src-2026-05-25-001]
