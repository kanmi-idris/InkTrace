# API Anything GitHub README

## Summary
API Anything describes learning reusable website operations from the site's own requests, then calling them through MCP, CLI, or TypeScript and returning JSON. [src-2026-11-02-001]

## Key Claims
- The README says two example inputs help identify request parameters and build a template without an LLM. [src-2026-11-02-001]
- Calls try plain Node HTTP first, then a fetch inside a browser page, then a page-triggered read fallback. [src-2026-11-02-001]
- The README says the shared catalog stores operation specs and reports, while calls run on each user's own machine and network. [src-2026-11-02-001]
- It says secret values are not included in shared specs. Specs refer to local cookie or session values. [src-2026-11-02-001]
- It says requests that cannot be repaired return errors, not data from a different query. [src-2026-11-02-001]
