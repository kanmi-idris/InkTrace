# Expo vector-icons deprecation tweet

## Summary
Expo announced that `expo/vector-icons` is moving to deprecated status, stating that the upstream `react-native-vector-icons` packages now integrate directly with `expo-font` and work across Expo Go and development builds. The public capture does not include the full migration details, but it is enough to treat this as a concrete ecosystem shift away from the Expo wrapper and toward direct upstream package usage. [src-2026-06-10-006]

## Key Claims
- Expo says `expo/vector-icons` is moving to deprecated status. [src-2026-06-10-006]
- Expo says the `react-native-vector-icons` packages now integrate directly with `expo-font`. [src-2026-06-10-006]
- Expo says those packages now work in Expo Go and dev builds, implying the compatibility gap that justified the Expo wrapper has narrowed or disappeared. [src-2026-06-10-006]
- Expo signals that the migration will require some effort, but the publicly captured text is truncated before the concrete migration guidance appears. [src-2026-06-10-006]
