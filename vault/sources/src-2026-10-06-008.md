# Morphlet: a morphing floating tray for React Native

## Summary
Morphlet is an MIT-licensed React Native component library for a native floating tray. It supports morphing transitions and multiple views. The README lists New Architecture and Android API 24+ requirements. [src-2026-10-06-008]

## Key Claims
- The repository documents morph, slide, fade, and scale transitions, plus named views and animation presets. [src-2026-10-06-008]
- Expo projects need a development build. The README provides an npm installation command and iOS pod-install step. [src-2026-10-06-008]
- The X post announces v0.1.2 and links Android preview videos. I did not inspect the videos or verify the release version. [src-2026-10-06-008]
