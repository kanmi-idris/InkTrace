# Graph Engineering with Claude: 14-Step Roadmap

## Summary
Codez/Lev Deviatkin's viral course on transitioning from linear agent prompting to graph-based architectures using Claude Code's dynamic workflows. 14 steps covering: node/edge foundations, schema contracts, fan-out/fan-in, code-based routing, verification subgraphs, model tiering, pipeline streaming, and self-routing graphs. 1.3M+ views. Core insight: 9/10 multi-step agents are needlessly sequential.

## Key Claims
- 9/10 multi-step agents are needlessly linear — half the steps never needed to wait. [src-2026-07-22-013]
- A node is a unit of work (one agent, one bounded job). An edge is a data dependency — if no variable crosses, there is no edge, and the wait is wasted. [src-2026-07-22-013]
- Every node must return validated structured data (JSON Schema) so the next node can trust the shape without parsing free text. [src-2026-07-22-013]
- Claude Code's dynamic workflows: Claude writes plain JavaScript orchestration scripts and spawns coordinated subagent fleets — coordination costs zero model tokens because it's code, not a conversation. [src-2026-07-22-013]
- Fan-out: given N independent sources, spawn N agents in parallel. Fan-in at a barrier node that collects all results. [src-2026-07-22-013]
- Route with code, not prompts: classifier node returns {severity} → if/else in orchestration code keeps routing deterministic and cheap. [src-2026-07-22-013]
- Verification as a subgraph: separate producer and verifier nodes. Verifier can itself be a parallel fan-out across lenses (correctness, security, reproducibility). [src-2026-07-22-013]
- Idempotent nodes: same input → same output. Enables retry-after-failure without side effects. [src-2026-07-22-013]
- Tier models across nodes: bounded/repetitive nodes use cheap models, judgment nodes get frontier models. [src-2026-07-22-013]
- Dynamic workflows (self-routing): describe the objective, Claude writes the orchestration script. Entry points: "workflow" in prompt, saved scripts (/deep-research), or ultracode. [src-2026-07-22-013]
- /deep-research graph pattern: scope → parallel search → fetch → adversarial verify → synthesize. [src-2026-07-22-013]
