# Iterate on UI with Live Mode - Impeccable

## Source overview
This tutorial describes using /impeccable live to iterate on a single UI element with AI-generated variants written back to source code.

## Workflow
1. Start live mode on a running dev server or static HTML page.
2. Pick an element with the canvas-style picker.
3. Add a command, freeform direction, comment pin, or drawing stroke.
4. Generate three different variants.
5. Accept one variant and write it back to the real source file.
6. Stop live mode and remove the helper script.

## Design principles
The tutorial emphasizes genuinely different variants, source-level edits, brand context from PRODUCT.md and DESIGN.md, and reversible development-only CSP changes.
