# 10 Open-Source GitHub Repos (Curated List)

## Source
Tweet by @exploraX_

## List

1. **recordly** — Open-source screen studio. Auto-zoom, smooth cursor, webcam overlay, styled backgrounds, polished demos without an editor. (AGPL-3.0)
   https://github.com/webadderallorg/Recordly

2. **Stirling-PDF** — Self-hosted PDF toolkit. Merge, split, sign, redact, OCR, convert, compress, 50+ tools, runs locally. (MIT)
   https://github.com/Stirling-Tools/Stirling-PDF

3. **PhotoGIMP** — Turns GIMP into Photoshop. Photoshop shortcuts, layout, and splash screen patched on GIMP 3+. 
   https://github.com/Diolinux/PhotoGIMP

4. **Open Notebook** — Self-hosted NotebookLM. Drop PDFs, URLs, YouTube links — chat, summarize, generate podcasts. 18+ model providers. (MIT)
   https://github.com/lfnovo/open-notebook

5. **Odysseus** — PewDiePie's self-hosted AI workspace. Chat, agents, deep research, docs, email, memory — local-first. (MIT)
   https://github.com/pewdiepie-archdaemon/odysseus

6. **FreeDomain** — Free domain names. Register a domain, point at Cloudflare or any DNS, ship without paying for the name. (AGPL-3.0)
   https://github.com/DigitalPlatDev/FreeDomain

7. **HyperFrames** — Write HTML, render video. HeyGen's engine that turns HTML/CSS + animations into deterministic MP4s. Built for AI agents. (Apache-2.0)
   https://github.com/heygen-com/hyperframes

8. **Web-to-App** — Turn any website into an Android app, on-device. Configurable webview, APK signing, Node/PHP/Python runtimes, no remote build.
   https://github.com/shiaho777/web-to-app

9. **Reclip** — Self-hosted video + audio downloader. Paste a link from YouTube, TikTok, X, IG — 1000+ sites — grab as MP4 or MP3. Powered by yt-dlp.
   https://github.com/averygan/reclip

10. **Excalidraw** — Infinite whiteboard. Hand-drawn diagrams, wireframes, real-time collab, end-to-end encrypted. 120k+ stars. (MIT)
    https://github.com/excalidraw/excalidraw
