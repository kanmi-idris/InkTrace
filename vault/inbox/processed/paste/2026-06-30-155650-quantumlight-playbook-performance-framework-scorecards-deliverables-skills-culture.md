# QuantumLight Playbook — Performance Framework: Scorecards, Deliverables, Skills, Culture

QuantumLight/Revolut performance framework. Performance articulated over 3 dimensions:

1. Deliverables — ability to complete tasks. Sub-dimensions: Speed (meeting deadlines), Quality (iterations required), Complexity (degree of precedent). Score formula: [Speed + Quality] * Complexity.

2. Skills — technical competencies required for the role. Defined by "functional leaders" (e.g. CTO owns engineer skills). Employees use as roadmap for growth; recruitment uses to test abilities.

3. Culture — alignment with company values. Values broken into expected behaviours with actionable examples. Made part of performance reviews.

Standardization via scorecards: true/false statements about employee behaviour, consistent 5-level scale (Poor, Basic, Intermediate, Advanced, Exceptional). Observable behaviours approach reduces manager bias. Once a "No" is reached, level is determined. Google Sheets template available.

Scorecard design principles:
- Consistent scoring across all scorecards (same 5-level scale)
- Observable behaviours — precise behaviours for managers to track
- Poor = red flag behaviors (no one should exhibit)
- Exceptional = only the very best
