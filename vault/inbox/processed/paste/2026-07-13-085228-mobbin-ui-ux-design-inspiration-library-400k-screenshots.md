# Mobbin — UI & UX Design Inspiration Library (400K+ Screenshots)

## Mobbin

Source: https://mobbin.com/
Author: Jiho (founder) + Mobbin team

### What it is
Library of 400,000+ fully searchable mobile & web app screenshots for UI/UX design research. 1,000+ iOS & Web apps, 200+ sites. New content weekly.

### Scale
- 1,428 apps
- 621,500+ screens
- 323,900 flows

### Features
- **Search by pattern** — screens, UI elements, flows, text in screenshots
- **Flow viewing** — video (micro-interactions, animations) + prototype (interactive hotspots)
- **Figma plugin** — copy designs straight into Figma
- **Collections** — save favorites + upload own screenshots
- **Comments** — annotate with context notes
- **Glossary, Colors, Blog, Changelog**
- **MCP endpoint** — AI agent access to the library
