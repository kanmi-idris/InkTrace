### What it is
A Codex skill by Kappaemme that tests landing pages through five evidence-based simulated customer personas, analyzing why each would convert, hesitate, or leave.

### Key Features
- Tests live URLs, localhost apps, screenshots, prototypes, or pasted copy
- Simulates five distinct customer decision journeys
- Analyzes clarity, relevance, trust, friction, and CTA problems
- Separates observed evidence from inference and unknowns
- Produces persona scorecard + ranked improvements (impact, effort, confidence)
- Creates polished standalone HTML report in workspace outputs/
- Supports multiple modes: quick, deep, mobile, before-after, copy

### Modes
- **quick**: primary-page verdict, scorecard, top fixes
- **deep**: desktop + mobile + pricing + interactions + CTA destinations
- **mobile**: small-screen conversion journey
- **before-after**: compare two versions with same five personas
- **copy**: positioning, objections, hero, and CTA language
