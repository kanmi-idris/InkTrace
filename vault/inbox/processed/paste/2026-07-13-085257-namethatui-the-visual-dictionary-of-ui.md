# NameThatUI — The Visual Dictionary of UI

## NameThatUI

Source: https://namethatui.com/

### What it is
A visual dictionary of UI — describe a UI element in plain language and it tells you the accurate technical name. Designed to help designers and developers prompt coding agents with precision.

### Features
- **Search by description** — describe what you see ("pale background behind a menu bar icon", "the dark see-through layer behind a popup"), get the real name
- **Double-press any word** — plain-English definition inline
- **Command palette** (⌘K) — quick search

### Guides
- **AppKit vs SwiftUI** — same Mac element has two names depending on framework
- **Swift vs Electron** — native vs web vocabulary fork
- **The Translation Table** — 60+ elements mapped: plain name → AppKit → SwiftUI, searchable
