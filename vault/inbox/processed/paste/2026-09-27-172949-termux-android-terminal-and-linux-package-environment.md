# Termux: Android Terminal and Linux Package Environment

Source checked: 2026-09-27.

## Scope
- Termux combines Android terminal emulation with a Linux package collection.
- The F-Droid page lists shell use, text editors, SSH access, native compilation, Python, Git, and other command-line workflows.
- Packages are installed inside the Termux environment through its package manager.

## Distribution and provenance
- The F-Droid listing identifies the project as GPL-3.0-only and links its website, issue tracker, source repository, changelog, and reproducibility status.
- The page lists Android 7.0 or newer for the displayed builds and provides architecture-specific packages.
- F-Droid warns that direct APK downloads do not provide update notifications and recommends the F-Droid client.

## Evidence and limits
- This is a general-purpose terminal environment, not a single-purpose penetration-testing application.
- The listing describes available environment capabilities. It does not prove that every external security tool will work on every Android device.
- No package was installed or executed.
