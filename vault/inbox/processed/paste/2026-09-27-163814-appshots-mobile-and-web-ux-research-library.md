# Appshots: Mobile and Web UX Research Library

Source checked: 2026-09-27.

## Scope
- Appshots is a mobile and web design research library built around real product examples.
- The homepage describes more than 1,000 design flows from more than 400 apps and more than 120,000 screens.
- The site organizes research around app collections, UX flows, and detailed edge cases.

## Research features
- App exploration supports broad visual reference across mobile and web products.
- Flow references help study complete journeys rather than isolated screens.
- The edge-case section is positioned as a way to inspect less common states and interaction details.
- Flow access is marked as a Pro feature, while the site offers a free starting path and an upgrade path for deeper access.

## Evidence and limits
- The site also claims large designer adoption and strong use by design-forward companies. These are promotional claims.
- Library counts, growth claims, testimonials, and access rules can change.
- Use the examples as reference material, then validate decisions with the target platform, product constraints, accessibility needs, and user research.
