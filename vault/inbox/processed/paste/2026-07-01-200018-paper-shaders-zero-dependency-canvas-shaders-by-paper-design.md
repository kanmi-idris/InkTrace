# Paper Shaders — Zero-Dependency Canvas Shaders by Paper Design

Paper Shaders — ultra-fast zero-dependency WebGL canvas shaders, from Paper Design / Lost Coast Labs. Apache 2.0, 2.2k stars.

Install: npm i @paper-design/shaders-react (React) or @paper-design/shaders (vanilla JS)

Shaders catalog:

Image Filters (6): paper texture, fluted glass, water, image dithering, halftone dots, halftone CMYK

Logo Animations (3): heatmap, liquid metal, gem smoke

Effects (18): mesh gradient, static mesh gradient, static radial gradient, dithering, grain gradient, dot orbit, dot grid, warp, spiral, swirl, waves, neuro noise, perlin, simplex noise, voronoi, pulsing border, metaballs, color panels, smoke ring, god rays

Dual workflow: shaders can be used programmatically via React/Vanilla npm packages, or visually designed in Paper app (paper.design). Settings configurable in code or via Paper visual editor. What you design exports directly as lightweight code.

Goals: give designers a visual way to use common shaders; what you make is directly exportable as lightweight code.

Values: lightweight, maximum performance, visual quality, easy abstractions, wide browser/device support.

Framework support: Vanilla JS (primary), React (primary), Vue/others (community PRs welcome in future).

Build: bun monorepo. Pin dependency — breaking changes shipped under 0.0.x.
