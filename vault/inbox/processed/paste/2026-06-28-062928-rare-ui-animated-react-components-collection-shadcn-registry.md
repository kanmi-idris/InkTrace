# Rare UI — Animated React Components Collection (shadcn Registry)

Rare UI by Swami Malode (@swamimalode) — a collection of rare, animated React components distributed via shadcn CLI registry.

Install: npx shadcn@latest add swamimalode07/rare-ui/[component]

Current components:
- Folder component: animated folder whose cards fan out on hover and lift open on click, with 3D-tilted flap. Supports color (black/white/blue) and size (sm/md/lg) props. Dependencies: motion.

Built with shadcn CLI and Motion. Desktop-only view.
