# Shodan.io App: Independent Mobile Client for Shodan Data

Source checked: 2026-09-27.

## Scope
- Shodan.io App is an independent Google Play client for browsing publicly available Shodan data.
- The listing says users provide their own Shodan API key and can inspect hosts, services, ports, banners, maps, saved searches, and bookmarked hosts.
- The listing reports 100K+ downloads and an update dated March 2, 2026.

## Provenance and safety limits
- The listing clearly states that the application is not affiliated with, endorsed by, or sponsored by Shodan.
- It is a mobile interface to an external data service, not a replacement for authorization when investigating systems.
- Public exposure data can still contain sensitive information. Use it for defensive research and authorized asset review.
- No API key was entered and no application was installed or executed.
