# Responsive Viewer — Chrome Extension for Multi-Screen Responsive Testing

Responsive Viewer — Chrome extension for viewing multiple screen dimensions in one view.

Product Hunt product page (launched 2019, 408 upvotes, #1 day rank, #3 week rank):
- Creator: Solaiman Kmail
- Chrome extension that shows multiple screens in one view for responsive web development testing
- Uses user-agent based rendering (same rendering engine as Chrome DevTools, not actual device rendering)
- Open source on GitHub
- Key features: side-by-side multi-viewport comparison, screenshot download of all screens at once, custom user agent creation
- Early bug: custom screens not persisting across tabs (creator said would fix)
- Compared to Sizzy ($7/mo) as a free alternative
- Compared to Chrome's native DevTools responsive mode — main difference is ability to show multiple screens simultaneously
