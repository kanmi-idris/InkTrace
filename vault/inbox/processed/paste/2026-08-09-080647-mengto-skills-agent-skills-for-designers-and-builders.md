# MengTo Skills: Agent Skills for Designers and Builders

## Source overview
A curated collection of portable agent skills for Codex, Claude, Cursor, and other AI coding agents. The library covers design systems, landing pages, WebGL, games, media capture, UI prompting, and repeatable agent workflows.

## Key points
- Skills are procedural playbooks with triggers, steps, defaults, pitfalls, and acceptance checks.
- Flagship workflows include video-to-superprompt, HTML-to-interaction-prompts, stitched full-page capture, and daily UI inspiration capture.
- The repository groups skills into Codex workflows, media, UI, game development, and web design.
- The repository describes 123 skills in the captured snapshot.
- The project treats prompts, screenshots, references, and workflows as reusable versioned assets.

## Repository structure
Skills use folders such as agent-skills/<category>/<skill-name>/ with SKILL.md, optional references, articles, assets, scripts, and demos.
