# GeoLibre v2.3.0 Release

https://github.com/opengeos/GeoLibre/releases/tag/v2.3.0 — GeoLibre v2.3.0 release (Jul 25, 2026). Open-source GIS/mapping application built on MapLibre GL. By giswqs/opengeos. 1.9k stars, 258 forks.

Key features in v2.3.0:
- Search: jump to typed lat/lon in place-search box
- Add data: delimited text layers in any CRS
- Layers: copy/paste layer styles between layers
- Time slider: mosaic (STAC/MosaicJSON) sources with GPU/WASM engine
- Random extract vector tool (processing)
- Android build Google Play-ready; iOS Tauri scaffold
- GeoLens catalog browser plugin
- Layers-panel symbology swatches + auto on-map legend
- Pick which GeoPackage layers to load
- Multi-profile support for AI assistant providers
- Raster CRS and pixel size in metadata dialog
- i18n: complete catalog coverage
- Emerging Hot Spot Analysis (space-time cube)
- Deep-link Whitebox tools via ?tool= URL param
- Auto-enable terrain when Terrain control is turned on
- Print layout: point markers in legend
- Logos submenu (MapLibre + Maptoolkit)

Deps: maplibre-gl-raster 0.12.0, maplibre-gl-planetary-computer 0.4.0, maplibre-gl-time-slider 1.6.0, geolibre-wasm 1.2.0
