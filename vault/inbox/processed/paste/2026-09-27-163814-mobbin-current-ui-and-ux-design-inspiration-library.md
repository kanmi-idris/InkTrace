# Mobbin: Current UI and UX Design Inspiration Library

Source checked: 2026-09-27.

## Relationship to existing records
- This is a current homepage supplement to src-2026-07-13-002, which is an earlier thin Mobbin placeholder.

## Scope
- Mobbin presents a searchable reference library covering more than 1,000 iOS and web apps and more than 200 sites, with new content added weekly.
- The homepage counters currently show 1,428 apps, more than 621,500 screens, and more than 323,900 flows. These values are site-reported snapshots.

## Research features
- Search can target screens, UI elements, complete flows, and text found inside screenshots.
- Flow references include video recordings with micro-interactions and animations, plus interactive prototypes with screen-by-screen hotspots.
- Users can copy selected designs to Figma through the Mobbin plugin.
- Collections, uploaded screenshots, and comments support research organization and team discussion.
- The site offers free access with paid plans for broader access.

## Evidence and limits
- Library counts, update frequency, testimonials, and paid-access details are controlled by the site and may change.
- Mobbin is a reference library. Its examples are not a substitute for user research or platform-specific accessibility review.
