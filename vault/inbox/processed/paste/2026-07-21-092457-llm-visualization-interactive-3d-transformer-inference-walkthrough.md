# LLM Visualization — bbycroft.net/llm

**Creator**: Brendan Bycroft
**URL**: bbycroft.net/llm
**Type**: Interactive 3D walkthrough of LLM inference

An interactive 3D visualization that steps through the inference process of a GPT-2-like large language model. Visualizes the full forward pass: token embedding → position encoding → transformer blocks (multi-head attention + feed-forward) → output logits → sampling. Built with 3D rendering for intuitive understanding of transformer internals at every layer.

**Relevance**: Complements Karpathy's "Let's build GPT" and the aihero.dev LLM intro. Excellent visual aid for understanding the geometry of transformer inference.
