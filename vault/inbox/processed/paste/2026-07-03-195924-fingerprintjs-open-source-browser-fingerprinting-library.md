# FingerprintJS — Open Source Browser Fingerprinting Library

GitHub repo by fingerprintjs. 27.6k stars, 2.6k forks, 45.7k dependents. MIT license. The most advanced free and open-source browser fingerprinting library.

Key features:
- Client-side browser fingerprinting — queries browser attributes and computes a hashed visitor identifier
- Stays the same in incognito/private mode and even when browser data is purged (unlike cookies/localStorage)
- v5.2.0 latest release (Apr 7, 2026)
- 913 commits, 68 releases
- TypeScript 98.7%, HTML 1.3%

Installation:
- npm: @fingerprintjs/fingerprintjs
- CDN: openfpcdn.io/fingerprintjs/v5
- Simple API: FingerprintJS.load() → fp.get() → result.visitorId

Limitations (open-source version):
- Accuracy significantly lower than commercial version (fingerprints generated/processed in browser)
- Vulnerable to spoofing and reverse engineering

Commercial upgrade (Fingerprint Identification):
- Closed-source, server-side processing
- 100+ browser/device signals + server-side network-level signals
- Industry-leading accuracy, harder to spoof
- Includes MCP Server for AI coding assistants
- Smart Signals: bot detection, VPN detection, browser tampering detection
- Free account available
