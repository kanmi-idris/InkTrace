# WPSApp: Wi-Fi WPS Security Checker

Source checked: 2026-09-27.

## Scope
- WPSApp is a Google Play utility for checking Wi-Fi security around the WPS protocol.
- The listing describes WPS risk checks, stored Wi-Fi password viewing on supported rooted devices, connected-device discovery, and channel-quality analysis.
- The page reports 100M+ downloads and an update dated August 8, 2026. Store metrics and update dates can change.

## Safety and evidence limits
- The listing warns that a network result is not a guarantee of vulnerability because router firmware and WPS settings vary.
- The developer instructs users to test only their own network and to disable WPS and change weak passwords when needed.
- Root access and Android-version restrictions affect some functions.
- This record omits PIN-generation, connection-testing, and password-recovery procedures. No application was installed or tested.
