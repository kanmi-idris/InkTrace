# Prism — Background & Visual Studio for Designers by Ava Thiery

Prism — free browser-based visual studio for creating backgrounds, textures, and gradients. By Ava Thiery (avathiery.com). No account needed.

3-layer compositing system:
1. Gradient — smooth organic gradient from base shape + 5-color palette (foundation)
2. Image — optional photo blended underneath the gradient
3. Pattern — optional clip into designer tile layouts (bento grids, mosaics, circles, repeating tiles)

Effect stack (composable, each optional with enable switch): Optics, Light, Waves, Glass distortion, Pixelate, Dither, Halftone, ASCII, Grain

Export: high resolution. Share via link that reproduces the exact look (URL-encoded params).

Preset backgrounds on homepage: Spectrum Pane (Fluted Glass), Aurora Mesh (Mesh), Sakura Grid (Halftone). Each opens in studio ready to remix.

Gallery page for browsing community looks. Framer templates available from @ava-thiery.

Keyboard shortcuts supported. Full documentation at /docs.
