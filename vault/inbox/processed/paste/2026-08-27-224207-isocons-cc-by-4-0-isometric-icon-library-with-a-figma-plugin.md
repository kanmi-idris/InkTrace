# Isocons: CC BY 4.0 Isometric Icon Library with a Figma Plugin

## Source overview
Isocons is a browsable library of isometric icons for projects, presentations, and posters, versioned as v2.1 at the time of this capture. The site provides a Figma plugin for direct use in design files, alongside a browsable, filterable, and searchable icon grid on the marketing site itself.

## Categories
The inspected site organizes icons into six categories:
- UI Actions
- Social
- Privacy & Security
- Business & Payments
- Transportation
- Maps

The UI Actions category alone contains several hundred named icons (observed names include Add Box, Arrow circle down, Check Circle, Deployed code, Keyboard double arrow down, Radio button checked, Settings Accessibility, Sync Alt, Tab group, Toggle on alt, and many more), suggesting a large total icon count across all six categories.

## Customization controls
The interface exposes several rendering controls before an icon is added to a selection:
- Isometric projection direction: Left, Top, or Right
- Fill toggle
- Edge toggle
- Stroke width control, with 1px shown as a default/example value
- A slider control, likely for corner radius or another continuous parameter
- A search box with placeholder text suggesting descriptor-based search (e.g. "add" or "check")
- A Checkout button, implying icons can be added to a selection/cart before export or plugin use

These controls indicate the icons are parametrically adjustable rather than static bitmap assets, consistent with an SVG or vector-based rendering system.

## License
The site's License panel states: "Isometric Icons ©2026 is licensed under CC BY 4.0."

Under CC BY 4.0, users are free to:
- Share: copy and redistribute the material in any medium or format, for any purpose, including commercially.
- Adapt: remix, transform, and build upon the material for any purpose, including commercially.

The license cannot be revoked as long as the following terms are followed:
- Attribution: appropriate credit must be given, a link to the license provided, and any changes indicated. This must be done in a way that does not suggest the licensor endorses the user or their use.
- No additional restrictions: users may not apply legal terms or technological measures that legally restrict others from doing anything the license permits.

This is a permissive open license that explicitly allows commercial use, unlike more restrictive icon-pack licenses that limit commercial use or require a paid tier for that permission.

## Figma plugin
The site prominently promotes a "Get the Figma Plugin" call to action, indicating the primary distribution path is a Figma plugin rather than a downloadable icon package, though the browsable web grid also appears usable independently of Figma.

## Evidence boundary
This capture is based on direct browser inspection of the live site, including opening the Categories menu and the License panel. No icon was downloaded, no Figma plugin was installed, and no checkout action was completed during this capture. The exact total icon count across all six categories was not exhaustively counted.
