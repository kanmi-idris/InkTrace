# unstract

GitHub - Zipstack/unstract: LLM-Driven Extraction of Unstructured Data

Unstract uses LLMs to extract structured JSON from documents — PDFs, images, scans. Define what you want to extract using natural language prompts, and deploy as an API or ETL pipeline.

Built for finance, insurance, healthcare, KYC/compliance.

Key Features:
- Prompt Studio: define document extraction schemas with natural language
- API Deployment: send a document over REST API, get JSON back
- ETL Pipeline: pull from folder, process, load to warehouse
- MCP Server: connect to AI agents (Claude etc.) via Model Context Protocol
- n8n Node: drop into existing automation workflows

Quickstart: git clone, ./run-platform.sh, visit http://frontend.unstract.localhost
Login: unstract / unstract

Architecture: Frontend (React), Backend (Django), Worker (Celery), Platform Service (FastAPI), Cache (Redis), Message Queue (RabbitMQ), Database (PostgreSQL), LLM Adapters, Vector DBs, Text Extractors

Document formats: PDF, DOCX, DOC, ODT, TXT, CSV, JSON, XLSX, XLS, ODS, PPTX, PPT, ODP, PNG, JPG, JPEG, TIFF, BMP, GIF, WEBP

LLM Providers: OpenAI, Azure OpenAI, OpenAI Compatible, Anthropic Claude, AWS Bedrock, Google Gemini, Ollama, Mistral AI, Anyscale
Vector DBs: Qdrant, Pinecone, Weaviate, PostgreSQL, Milvus
Text Extractors: LLMWhisperer, Unstructured.io, LlamaIndex Parse
ETL Sources: AWS S3, MinIO, GCS, Azure Blob, Google Drive, Dropbox, SFTP
ETL Destinations: Snowflake, Redshift, BigQuery, PostgreSQL, MySQL, MariaDB, SQL Server, Oracle

Cloud/Enterprise features: LLMChallenge dual-LLM verification, SinglePass & Summarized Extraction, Human-in-the-Loop review, SSO & RBAC, SOC 2/HIPAA/ISO 27001/GDPR, Priority Support with SLA
