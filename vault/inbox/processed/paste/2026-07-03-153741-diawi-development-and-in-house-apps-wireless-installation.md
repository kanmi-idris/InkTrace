# Diawi — Development and In-house Apps Wireless Installation

Diawi is a tool for developers to deploy Development and In-house (ad-hoc) applications directly to devices via wireless installation. Based in Paris, France. Operating since November 2010.

Core workflow:
1. Upload iOS (.ipa, zipped .app) or Android (.apk) application
2. Send the link to testers/clients/friends
3. Open link in browser on device and tap install

Key features:
- Works for iOS 4+ and Android 2+ (legacy support)
- Works for development, ad-hoc, and in-house builds
- Password protection for installation pages
- Custom URLs (paid accounts)
- API access (paid accounts)
- Statistics (paid accounts)
- No expiration on paid plans
- UDID retrieval for iOS
- Compatibility checking
- Mobile web app for testers to find apps via UDID (iOS)
- 'Wall of apps' for app discovery
- Private links — no search or index
- Free tier available
- Additional features: custom URLs, APIs, stats, no expiration on paid accounts

Stats (counter showing real-time uploads/installs since Nov 2010)

Company: Based in Paris, France.
Contact: Twitter @diawi_ios, Matrix chat, GitHub (github.com/diawi)

Comparison notes:
- Older than InstallOnAir and AppsOnAir (since 2010)
- Free tier available unlike InstallOnAir's paid-only expiry extension
- Has API, custom URLs, and stats on paid tier
- Supports zipped .app files in addition to .ipa and .apk
