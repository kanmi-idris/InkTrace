# Drivo - React Native Ride-Sharing App Template

Drivo - React Native Ride-Sharing App Template

## Overview
React Native + Expo template for building ride-sharing or delivery apps (Uber/Grab clone). Includes live map tracking, ride booking, driver onboarding, wallet, in-app chat, and more. Built by Thomino (Native Templates).

## Tech Stack
- Expo SDK 56.0.11
- React Native 0.85
- NativeWind v4 (TailwindCSS-like styling)
- TypeScript 6.0
- iOS + Android compatible
- Light & Dark mode
