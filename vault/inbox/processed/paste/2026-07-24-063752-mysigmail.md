# mysigmail

GitHub - antonreshetov/mysigmail: A free and open-source email signature generator for Gmail, Outlook, Apple Mail, etc.

Features: customization (fonts, colors, avatar shapes, social icons, custom fields), templates (ready-to-use layouts), add-ons (disclaimer, call-to-action).

Built with Vue.js, Bun, Vite. Quick start: git clone, bun install, bun run dev.

SaaS version at https://mysigmail.com with: manage multiple signatures, shared signatures, analytics, presets library, image hosting (CDN). Tools: Sign Off (handwritten signature), URL Builder (UTM-tagged URLs), Banner Maker (coming soon).

Contribution policy: bug fixes only (OSS). Commercial use requires license from reshetov.art@gmail.com.
