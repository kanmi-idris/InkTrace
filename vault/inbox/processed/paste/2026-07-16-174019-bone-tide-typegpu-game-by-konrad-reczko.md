## Post 1: Announcement

Writing games in TypeScript from scratch — performant, nice DX, works on Web and React Native. Bone Tide was written purely in TypeGPU with no engine. Both game logic and shaders written in pure TypeScript.

## Post 2: Credits

- Kay Lousberg (@KayLousberg) — CC0 mesh and animation assets

## Post 3: Development Process

Built in ~2 weeks, started as experimenting with Fable. Used AI extensively but not "vibe coding" — architected the codebase and regularly inspected code. Thesis: human domain knowledge + AI workforce + human art is a great combination for creating actual apps.
