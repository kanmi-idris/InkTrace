## Description

A curated library of premium React micro-interactions and transition components powered by Motion (formerly Framer Motion v12). Installable via CLI — tree-shakeable, lightweight.

## Features

- Clean micro-transitions for buttons, controls, and UI states
- One-click code generation (copy-to-clipboard compiles React + Tailwind + Motion code)
- Dynamic theme system (Dark/Light mode toggle)
- Interactive layouts (Grid, List, Matrix modes)
- Real-time GitHub stargazer stats
- Design inspiration from Oxygen UI

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Motion (v12, formerly Framer Motion)
- Lucide React icons
- Vite build tool
