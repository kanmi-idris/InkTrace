# Puter — Open-Source Internet Computer (Web Desktop / Cloud OS)

HeyPuter/puter — Advanced open-source, self-hostable "Internet Computer" (web desktop environment / cloud OS). 42.5k stars, 3.9k forks, 5,967 commits, 17 releases. AGPL-3.0.

Stack: TypeScript (48.7%), JavaScript (45.9%), Node.js. Includes Rust toolchain.

Features:
- Full web-based desktop environment with apps: Notepad, Voice Recorder, Spreadsheet, Camera, etc.
- Developer platform: AI APIs, Cloud Storage (object storage), Key-Value Database, Serverless Workers
- App Store for publishing and monetizing web apps
- Self-hosting via single curl command (curl -fsSL https://puter.com/selfhost | sh)
- Docker Compose support
- Local development: git clone, npm install, npm start — launches at http://puter.localhost:4100

Self-hosting:
  Linux/macOS: curl -fsSL https://puter.com/selfhost | sh
  Windows: irm https://puter.com/selfhost?os=windows | iex

Hosted service available at puter.com.

Translations available in 30+ languages. Active community on Discord, Reddit, X. Bug bounty program.
