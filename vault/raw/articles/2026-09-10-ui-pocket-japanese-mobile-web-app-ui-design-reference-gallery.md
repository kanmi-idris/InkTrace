# UI Pocket: Japanese Mobile/Web App UI Design Reference Gallery

## Source overview
UI Pocket is a Japanese-language UI design reference gallery site that catalogs real app interfaces, browsable without creating an account or logging in for a limited preview, with full screenshot sets gated behind a login. A user post (translated from Japanese) specifically recommends it for browsing a large volume of smartphone app UIs and highlights that it comprehensively covers a full app's screen flow: the onboarding screens only shown on first launch, account creation, login, the home screen, and further screens beyond that.

## Site structure
The site is organized into top-level sections for mobile apps, web apps, websites, and a general 'library' area (each observed as separate top navigation links: mobile, web, site, library). Within the mobile section specifically, a filter sidebar allows narrowing by category, component, pattern, flow, in-image text, and similar images. A large number of app categories are listed as filter checkboxes, covering areas such as finance, productivity, dating/matchmaking, education, news, entertainment, photo/video, food and drink, reference/dictionary, shopping, graphic design, social networking, health and fitness, sports, lifestyle, travel, weather, books, and medical.

## Content observed
At the time of this capture, the mobile gallery listed entries for several named real apps, each shown with a category label, a short description, and multiple preview screenshots: an Epos-branded finance/card app, a Mail app (categorized under productivity), Tinder (categorized as a dating/matchmaking app for finding friends or romantic partners), Duolingo (described as letting users learn 40-plus languages, including English and Korean, in a game-like way), Notion (described around planning, organizing, and project tracking), and tabiori (described as a simple, well-designed app for creating travel itineraries). A visible prompt states that logging in is required to view the complete set of screenshots for each app, implying the unauthenticated view shown to this capture was a partial preview rather than the full documented flow.

## Access model
The site is free to browse without an account for at least the preview-level content observed in this capture. A separate pricing-plan page is linked from the site footer, implying some level of paid access tier exists for more complete or advanced access, though this capture did not open or verify the specific pricing-plan page's contents.

## Evidence boundary
The site's mobile gallery listing page and its top-level navigation/filter structure were inspected directly via the browser accessibility tree. The site's Japanese-language content is summarized here in English rather than translated line by line. The linked pricing-plan page, the web and website (site) sections, and the library section were not independently opened or verified in this capture, and no account was created or login attempted.
