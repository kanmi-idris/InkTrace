# SEU Knowledge Graph Course

GitHub - npubird/KnowledgeGraphCourse: 东南大学《知识图谱》研究生课程 (Southeast University graduate Knowledge Graph course). Taught by Prof. Peng Wang (pwang AT seu.edu.cn). Spring semester (Feb–May) at SEU Jiulonghu Campus.

Course content (2025):
- Lecture 0: Course intro
- Lecture 1: Knowledge graph overview — cognitive intelligence, KG essence, evolution, vs deep learning vs traditional KBs vs DBs, tech system (extraction, fusion, representation learning, reasoning, storage), bottlenecks and challenges
- Lecture 2: Knowledge representation — semantic networks, production systems, frame systems, concept graphs, FCA, description logic, ontology, ontology languages, KG representation learning
- Lecture 3: Knowledge modeling — ontology engineering, ontology learning, modeling tools, modeling practice
- Lecture 4: Knowledge extraction basics — problems and methods, structured/semi-structured/unstructured data extraction
- Lecture 5: Entity recognition — rule/dictionary-based, ML, deep learning, semi-supervised, transfer learning, pretrained, research frontiers
- Lecture 6: Relation extraction — semantic relations, features, datasets, template-based, supervised, weakly supervised, distant supervision, unsupervised, deep/reinforcement learning
- Lecture 7: Event extraction — rules/templates, ML, deep learning, KB-based; financial event extraction; event evolutionary graph; classic to LLM paradigm
- Lecture 8: Knowledge fusion — heterogeneity, ontology matching, instance matching, large-scale entity matching, applications
- Lecture 9: KG and LLM frontiers — KG for LLM (hallucination mitigation, GraphRAG, knowledge editing) and LLM for KG (NER, RE, KGC, reasoning)

Stars: 4.4k, Forks: 1.1k, 172 commits. Full lecture PDFs in Chinese. Also includes classic reading list covering KG construction, representation, extraction (NER, RE, event extraction), fusion, and LLM-related papers.
