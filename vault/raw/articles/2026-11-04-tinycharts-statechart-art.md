# Kevin T. Ngo statechart-art repository snapshot

Captured: 2026-11-04
Repository: https://github.com/kevintngo/statechart-art

The repository describes four hand-drawn, code-generated statecharts about a boba shop. Each chart corresponds to a TLA+ model. The README says the statechart skill checks the model with TLC, generates Mermaid, and reports rules that hold or fail. The project then lays out and draws charts in a pen-and-coloured-pencil style.

The repository says it is MIT-licensed. These facts describe `statechart-art`; they do not establish that Tinycharts uses the same TLA+ models, checker, or rendering code.
