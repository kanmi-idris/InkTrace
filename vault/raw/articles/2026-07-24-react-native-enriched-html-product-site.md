# React Native Enriched HTML - Product Site

React Native Enriched HTML product site (enriched.swmansion.com/html/) — fully-native rich text solutions for React Native. Built by Software Mansion. Not based on WebView.

Features:
- Fully native text input: spellcheck, autocomplete, text selection all work natively
- HTML input and output: content lives as HTML, exportable anywhere
- Customizable styles: headings, lists, code blocks with reasonable defaults
- Full feature parity on Android and iOS

Key features:
- Inline and paragraph formatting (bold, italic, underline, strikethrough, inline code)
- Mentions with custom triggers (@someone, #channel, emoji pickers)
- Link detection and management (auto-detection of URL-like text, regex support)
- Smart style detection (know which styles active at cursor/selection)
- Inline images (local and remote, single line, auto-height)
- Dynamic sizing (auto-adjusts height, respects min/max limits)

Future plans: nested lists, text alignment, RTL support, accessibility reader (screen readers, WCAG/ACA).

GitHub: github.com/software-mansion/react-native-enriched-html (1k+ stars)
Part of the Software Mansion enriched product family (alongside react-native-enriched-markdown).
