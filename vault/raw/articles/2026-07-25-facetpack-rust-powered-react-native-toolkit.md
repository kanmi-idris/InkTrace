# Facetpack - Rust-Powered React Native Toolkit

https://github.com/ecrindigital/facetpack — The missing toolkit for React Native. Rust-powered performance (OXC replaces Babel). By Ecrin Digital. MIT. 406 stars, 4 forks, 82 commits.
