# SendLib

SendLib — Zero-Config Email for Developers. Send transactional emails with just your Gmail account from any hosting environment, even where port 25, 465, or 587 are blocked.

What it is: A transactional email API that uses Google OAuth2 to send through your connected Google account. No SMTP configuration, no domain/DNS setup, no SPF/DKIM/MX records needed.

Features:
- Send without SMTP restrictions (works on Railway, Render, free cloud hosts that block outbound SMTP)
- Zero DNS setup — no domain, MX, SPF, DKIM needed
- Simple REST API — one POST request, no SDK required
- Inbox delivery — emails sent from your own Google account land in inbox, not spam
- OAuth2 secured — never see/store password, encrypted AES-256 tokens, revocable anytime

API: curl POST https://sendlib.samueltuoyo.com/api/send with Authorization Bearer token, JSON body (from, to, subject, html, plus CC, BCC, attachments).

Pricing:
- Free: 10 connected Gmail accounts, 500 emails/day per account, 15 API keys, 60 req/min, 2MB HTML, 10 attachments, 50 recipients per field, 7-day analytics
- Google Workspace: 2,000 emails/day per account
- Pro (coming soon): pay-as-you-go, more accounts, higher limits, 90-day analytics, open/click tracking, webhooks, scheduled sends

Privacy: Uses gmail.send scope only. Never reads/stores inbox messages. Complies with Google API Services User Data Policy (Limited Use).
