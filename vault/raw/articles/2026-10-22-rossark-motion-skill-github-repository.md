## README summary

The README presents `rossark-motion-skill` as a method and toolkit for animating illustrations, icons, mascots, characters, and scenes. It says the skill aims for calm, believable motion rather than busy movement. The author says the method came from production onboarding and paywall art.

The repository includes a Claude Code skill, a `MOTION.md` project-notes template, React Native and SwiftUI motion engines, live-face templates, video-analysis tools, and demo scenes. The README says the method also works on the web.

The README lists React Native templates using `react-native-svg` and Reanimated, and SwiftUI templates using `TimelineView` and `Canvas`. The tools include scripts for extracting video frames into contact sheets, measuring subject-edge motion, sampling video colors, and rendering demo scenes offline to MP4 and GIF.
