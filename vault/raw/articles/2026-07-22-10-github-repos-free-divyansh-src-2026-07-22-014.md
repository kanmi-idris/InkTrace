Curated list of 10 open-source GitHub repos by Divyansh Tiwari.

1. **OmniRoute** — github.com/diegosouzapw/OmniRoute
   One endpoint, 231 AI providers, 50+ free-tier providers. Connect Claude Code, Codex, Cursor, Cline to Claude, GPT, Gemini for free. Compresses tokens 15–95% with automatic fallback.

2. **OfficeCLI** — github.com/iOfficeAI/OfficeCLI
   Office suite for AI agents. Control Word, Excel, PowerPoint from CLI. No Microsoft Office installation, no dependencies, one binary.

3. **System Prompts Leaks** — github.com/asgeirtj/system_prompts_leaks
   Leaked system prompts from Claude, GPT, Gemini, Grok, Cursor, Copilot, and more. Regularly updated.

4. **OpenCut** — github.com/OpenCut-app/OpenCut (already captured as src-2026-05-18-001)
   Open-source CapCut alternative. Browser-based, no account, no telemetry, no subscription.

5. **AI Job Search** — github.com/MadsLorentzen/ai-job-search
   Claude Code-powered agent that applies for jobs. Analyzes listings, tailors resume, writes cover letters, prepares interview questions.

6. **Meetily** — github.com/zaid-maker/meetily
   Fully local meeting transcription and summarization. Whisper + Ollama, built in Rust.

7. **Vibe-Trading** — github.com/HKUDS/Vibe-Trading
   Natural language and AI agents to build and execute trading strategies.

8. **Strix** — github.com/usestrix/strix
   AI-powered open-source vulnerability scanner. Finds and helps fix security issues.

9. **Superpower** — github.com/superpowerlabs/superpower
   Self-hosted AI workspace. 250k+ GitHub stars.

10. **Firecrawl** — github.com/mendableai/firecrawl (already captured as src-2026-07-22-007)
    Turn any website into clean, LLM-ready data. Industry standard for RAG and data pipelines.
