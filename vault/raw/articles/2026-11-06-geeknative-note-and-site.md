# GeekNative site and user note

## User note

> Cross-platform apps without the cross-platform tech!
>
> It's shaping up well

The user supplied this note with https://geekyants.github.io/geeknative/.

## What the site says

The landing page labels GeekNative open source and v0.1. It describes one prompt and one spec producing three native apps: SwiftUI for iOS, Jetpack Compose for Android, and TanStack Start for web. It says the apps have no shared cross-platform runtime.

The site says the product shares the specification, design tokens, copy, and tests. A coding agent writes and checks three separate native codebases. This is the project's claim, not a test performed for this capture.

## Interpretation

“Without cross-platform tech” means without a shared app runtime or UI framework. It does not mean one codebase. The workflow still uses shared specs, contracts, code generation, and an agent to keep three implementations aligned.
