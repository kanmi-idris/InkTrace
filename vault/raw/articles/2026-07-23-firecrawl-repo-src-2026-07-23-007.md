## Features

### Core Endpoints

| Feature | Description |
|---------|-------------|
| **Search** | Web search returning full page content (markdown, structured JSON) |
| **Scrape** | URL → markdown, HTML, screenshots, or structured JSON |
| **Interact** | Post-scrape interaction via AI prompts or code (click, scroll, write, wait, press) |
| **Agent** | Autonomous data gathering from a description — no URLs needed |
| **Crawl** | Full website crawl with pagination |
| **Map** | Instant URL discovery for a site |
| **Batch Scrape** | Async scraping of thousands of URLs |

### Agent Endpoint

The evolution of `/extract`. Describe what data you need, and Firecrawl searches, navigates, and retrieves it. No URL required.

```python
app.agent(prompt="Find the pricing plans for Notion")
```

Supports structured output via Pydantic schema:

```python
class FoundersSchema(BaseModel):
    founders: List[Founder]

result = app.agent(prompt="Find the founders of Firecrawl", schema=FoundersSchema)
# {"founders": [{"name": "Eric Ciarla", "role": "Co-founder"}, ...]}
```

Optional URL focus to constrain the agent. Two models:
- `spark-1-mini` (default): 60% cheaper
- `spark-1-pro`: complex research, critical data
