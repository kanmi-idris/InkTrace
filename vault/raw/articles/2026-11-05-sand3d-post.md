## Post text

> We're opening 100,000+ 3D objects 🧊🤗, unified in one library, ready for LLM training.
>
> Objaverse assets, CAD parts and articulated mechanisms, all in one language !
>
> For years, 3D research has trained on Objaverse: messy triangle soups, broken meshes, objects with no parts. Every team cleaned it on its own or adapted its models to noisy data, and most of that work stayed private.
>
> That mess held the industry back on what 3D teams need: clean topology, objects split into parts, and a representation people can work on together.
>
> So we rewrote Objaverse and other datasets into one clean representation. Each asset is now a short Python program in sand3d, our open library:
>
> 🔹 every part has a name
> 🔹 every dimension is a parameter
> 🔹 running the program gives a clean asset
>
> 3D code today is scattered across many languages, each written for people and for a different tool. sand3d puts every object in the same language, in 3.8x fewer tokens than raw Blender Python on average.
>
> Everything is open, as one shared dataset that gives everyone the same ground to train and compare on. We want to speed up research on models that work and collaborate on 3D production.
>
> This is only the start: more objects are coming.
>
> 📦 Dataset: https://huggingface.co/collections/Sandflow/sand3d
>
> 🔎 Explorer: https://huggingface.co/spaces/Sandflow/sand3d-explorer
>
> 💻 Library: https://github.com/Sandflow-ai/sand3d
