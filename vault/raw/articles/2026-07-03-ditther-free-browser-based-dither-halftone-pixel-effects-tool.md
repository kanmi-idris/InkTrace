# Ditther — Free Browser-Based Dither, Halftone & Pixel Effects Tool

Ditther — free browser-based dither, halftone, ASCII art, and pixel effects tool by Aashish (blurrhaus/blurr.design). No install, no account required.

8 pixel effects:
- Dither (noise-based organic pixel diffusion)
- ASCII / Characters (text art with customizable character sets)
- Lego (interlocking pixel blocks)
- Voxel (3D-inspired voxel blocks)
- Halftone (print-style dot patterns)
- Dots (circular dot grid)
- Bayer Matrix (ordered dithering, vintage digital display look)
- LED (simulated LED display panels)

How it works: upload image/video → hit Shuffle/Remix for random effect combinations → export. Supports JPG, PNG, WebP, video. No size limits. Built-in 100+ backgrounds (500+ for Pro).

Pricing:
- Free: all 8 effects, duotone system, animation system, 9 Look presets, unlimited Shuffle/Remix, crop/aspect ratio, export up to 1080p, 100+ backgrounds
- Pro ($19/$39 one-time): 500+ backgrounds, 21 premium Look presets, 10 Animation presets, 4K exports, 60 FPS video, save custom Looks, weekly background drops

Privacy: all processing done locally in browser — images/videos never uploaded to servers.

Export: standard or 4K. Save settings as "Looks" to reapply.
Fully responsive (works on mobile).

Made by blurrhaus (@blurrhaus). Blog with tutorials on halftone effects and ASCII art conversion.
