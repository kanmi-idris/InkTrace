User-supplied positioning:

- “A tool that generates a DESIGN.md from any website.”
- Paste a URL and get a semantic design document describing color relationships, typography, spacing logic, and component patterns.
- The framing is that agents make poor UIs because they have not seen or structurally learned from enough good design references.
- The supplied copy says Refero has been building a corpus of roughly 2,000 `DESIGN.md` files from strong products, structured for model consumption.

Official page highlights captured from the referenced pages:

- Refero Styles describes itself as “Design taste, extracted.”
- The styles page says users can search curated references by brand, mood, color, typography, or URL.
- It also says opening a style reveals colors, type, spacing, components, and a `DESIGN.md` that an agent can use.
- The Refero Design Skill repository describes the skill as “Design with data, not defaults.”
- The skill README says agents should research first by searching Refero before designing, drawing on a large corpus of screens and user flows from products such as Stripe, Linear, Notion, Figma, and Vercel.
- The skill also claims to include craft guides for typography, color, spacing, motion, icons, and anti-generic-design rules.
- Installation shown in the repository README:
  - `npx skills add https://github.com/bbssppllvv/refero_skill`
- The same README says the skill requires Refero MCP and shows MCP connection examples using `https://api.refero.design/v1/mcp` with bearer-token authorization.
