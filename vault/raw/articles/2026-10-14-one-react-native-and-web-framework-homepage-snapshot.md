## Product description

- The homepage presents One as a React Native framework for building apps, with web support and shared code.
- It says One works with existing libraries and includes native APIs, routing, OTA updates, data loading, deployment, DevTools, and build commands.
- The page says typed file-system routes support layouts, stacks, and tabs.
- It says SwiftUI and Jetpack Compose are generated from platform SDKs, with typed native views and APIs for haptics, storage, updates, notifications, and other features.
- The page lists OTA updates with rollback, loaders with SSR/SSG/SPA modes, deployment to Vercel, Cloudflare, or a Hono server, and `prebuild`, `run:ios`, and `run:android` without Expo.
- The page says One works with Expo modules, React Navigation, Reanimated, Nitro modules, Tamagui, and NativeWind.
