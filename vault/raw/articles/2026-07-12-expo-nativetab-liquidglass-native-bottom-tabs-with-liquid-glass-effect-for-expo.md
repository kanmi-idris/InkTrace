# expo_nativetab_liquidglass — Native Bottom Tabs with Liquid Glass Effect for Expo

## expo_nativetab_liquidglass

Source: https://github.com/maazjnr/expo_nativetab_liquidglass (27 ★, 9 forks)
Author: maazjnr

### What it is
Expo SDK 54 reference app demonstrating native bottom tabs with a liquid glass aesthetic — combines @react-navigation/bottom-tabs + drawer + native-stack navigation with LinearGradient and Reanimated animations.

### Stack
- Expo SDK 54, RN 0.81.5
- @react-navigation/bottom-tabs v7, drawer v7, native-stack v7
- Reanimated 4.1.1, Gesture Handler 2.28
- expo-linear-gradient, expo-symbols
- react-native-worklets 0.5.1

### Components
- **AnimatedListItem** — animated list row
- **DrawerContent / DrawerSceneWrapper** — custom drawer with scene transitions
- **FadeSlideView** — fade + slide animation wrapper
- **PressScale** — scale-on-press interaction
