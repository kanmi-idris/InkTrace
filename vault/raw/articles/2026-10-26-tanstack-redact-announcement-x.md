## Announcement and replies

The main post introduces TanStack Redact as a smaller runtime for existing React apps. It says users add Redact to build configuration and ship less JavaScript without changing application code. It lists TanStack Start, Vite, Vinext, and Next.js.

A thread reply says TanStack's starter apps saved 47.0 KB with Start, 48.1 KB with Vite, 39.3 KB with Vinext, and 35.7 KB with Next.js. It describes these as emitted client JavaScript and CSS, gzipped, compared with React.

Another reply says Vinext and Next.js support App Router and Pages Router, with React on the server and Redact in the browser. It says Redact renders synchronously, without React's time slicing.

The thread says Redact began as a smaller React runtime for TanStack's own websites. TanStack says other people have used it in production and that it plans to maintain the project.
