# Scrapy — Fast High-Level Web Crawling & Scraping Framework for Python

**Author:** Zyte (formerly Scrapinghub)
**License:** BSD-3-Clause
**Stars:** 63,300 | **Forks:** 11,800
**Latest version:** v2.17.0 (Jul 7, 2026)
**Commits:** 11,220
**Requires:** Python 3.10+

## Quick Start

```bash
pip install scrapy
```

```bash
scrapy startproject myproject
scrapy genspider example example.com
scrapy crawl example
```

## Key Concepts

- **Spider** — defines how to crawl a site (start URLs, parse method, follow links)
- **Item** — container for scraped data (like a dict)
- **Item Pipeline** — sequential processing of items (clean, validate, persist)
- **Downloader Middleware** — process requests/responses (proxy rotation, user agents)
- **Spider Middleware** — process spider input/output
- **Selectors** — CSS/XPath extraction via parsel/lxml

## Built-in Exports

- JSON, JSON Lines, CSV, XML
- Pickle, Marshal
- FTP, S3, standard output
- Custom exporters
