# Mobile Experiments: React Native and Expo UI Studies

## Source overview
Mobile Experiments is a collection of standalone React Native and Expo experiments. The repository focuses on animations, gestures, and mobile UI ideas. Each project is intended to run as its own Expo app and has its own README.

The README describes these experiments:
- ai-chat-ui: chat UI with a drawer sidebar and send-button morph animation.
- audiobook-player: mini player that expands into a full player sheet.
- bolt-clone: ride-hailing flow with map, ride options, and payments.
- bookmark-dissolve: cards that dissolve into particles on delete using Skia.
- crypto-wallet: balance digits scramble and lock in on pull-to-refresh.
- destination-card-expand: travel cards expand into a detail sheet.
- fold-to-delete: drag a folder to a delete zone and fold it away.
- gooey-fab: floating action button splits into actions with a liquid metaball effect.
- hotel-booking: hotel search with orbiting photo onboarding.
- learning-chat: topic cards and a scripted practice chat.
- neobank-wallet: card stack expands with a spring animation.
- retro-terminal: terminal and sci-fi styled animated screens.
- spotify-onboarding: connect flow with an arcing card marquee.
- sticky-note-peel: notes peel and fold under a finger.
- trend-catcher: streetwear discovery feed with parallax collection titles.
- wallet-card-gestures: gesture-driven credit card stack.
- workflow-canvas: node canvas UI for a workflow automation tool.

Commit messages identify coin-pulse as a monochrome crypto app with markets, assets, and trade flows. They identify rent-radar as a liquid-glass map explorer with a scroll-collapsing navigation bar.
