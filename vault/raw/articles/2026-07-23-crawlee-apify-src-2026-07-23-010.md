# Crawlee — Web Scraping & Browser Automation Library for Node.js

**Author:** Apify
**License:** Apache-2.0
**Stars:** 24,900 | **Forks:** 1,600
**Latest version:** v3.17.0 (Jun 4, 2026)
**Commits:** 5,390
**Language:** TypeScript (58.2%), MDX (33.1%), JavaScript (6.8%)

"A web scraping and browser automation library for Node.js to build reliable crawlers. Extract data for AI, LLMs, RAG, or GPTs."

## Design Philosophy

- Single interface for HTTP and headless browser crawling
- Human-like behavior by default (fingerprints, headers, TLS)
- Plugable storage and queues
- Automatic scaling with system resources

## Crawler Types

- **PlaywrightCrawler** — headless browser via Playwright
- **PuppeteerCrawler** — headless browser via Puppeteer
- **CheerioCrawler** — fast HTTP crawling with Cheerio
- **BasicCrawler** — raw HTTP requests
- **SessionPool** — manages proxy rotation and sessions

## Storage

- **Dataset** — tabular/structured data
- **KeyValueStore** — files, screenshots, HTML
- **RequestQueue** — persistent URL queue (breadth/depth first)
- Local filesystem by default, cloud via Apify platform

## Key Technical Details

- Zero-config HTTP2 proxy support
- Auto-generated browser-like headers
- TLS fingerprint replication (not just User-Agent)
- Session management for authenticated crawls
- Hook-based lifecycle (before request, after response, etc.)
- TypeScript generics for typed crawl results
