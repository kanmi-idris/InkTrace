# Fing: Network Discovery and Home Network Diagnostics

Source checked: 2026-09-27.

## Scope
- Fing is a Google Play network utility for discovering devices on Wi-Fi and LAN networks.
- The listing describes device identification, speed tests, port scanning, ping, traceroute, DNS lookup, and network security alerts.
- It also describes device properties from sources such as NetBIOS, UPnP, SNMP, and Bonjour.
- The listing reports 50M+ downloads and an update dated September 11, 2026. Store metrics and dates can change.

## Optional hardware features
- The listing describes Fingbox features for presence detection, device blocking, parental controls, bandwidth analysis, automated speed tests, and home-network vulnerability checks.
- These features depend on the separate Fingbox product and should not be assumed to exist in the free phone application.

## Evidence and limits
- This is primarily a defensive visibility and diagnostics tool.
- Device identification and network results can be incomplete or inaccurate.
- No application was installed or tested.
