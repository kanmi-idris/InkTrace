Repository framing captured from the public README:

- `nativescript-expo` is an Expo project demonstrating how NativeScript can be used as a TurboModule.
- The stated goal is deep iOS integration by directly exposing the iOS SDK in TypeScript.

Motivation captured from the README:

- Use latest SDK APIs directly in TypeScript without adding more dependencies.
- Hot-reload native components without recompiling the React Native project.
- The README connects this experiment to work on a newer NativeScript runtime using Node-API and a built-in JSI backend.

Runtime and architecture framing captured from the README:

- The project frames NativeScript as moving beyond its traditional runtime boundaries.
- It says the JSI backend allows NativeScript apps to use Hermes as an engine choice alongside:
  - V8
  - QuickJS
  - JSC
- It also says this lets NativeScript compile as a JSI module for React Native apps, bringing the native API access model from NativeScript into React Native.

Feature examples captured from the README:

- Apple Wallet / PassKit
  - generate and add `.pkpass` passes directly to iOS Wallet
- Document Scanner
  - native iOS document scanning through VisionKit
- PDF Viewer
  - native PDF rendering through PDFKit
- Native Tabs
  - native tab bar controller integration
- Metal
  - shader-driven shine effect with CoreMotion gyro effects
