# InstallOnAir — OTA iOS/Android App Distribution Platform

InstallOnAir.com is a platform for distributing iOS (.ipa) and Android (.apk) apps over-the-air (OTA). It acts as an alternative to TestFlight for beta testing and internal distribution.

Core workflow:
1. Upload IPA (iOS) or APK (Android) file
2. Get a unique shortened installation link
3. Share link via email, Slack, WhatsApp
4. Testers tap link on mobile browser to install directly — no cables, iTunes, or manual file transfer

Key features:
- Supports .ipa and .apk files
- Automatic plist generation for iOS OTA installation
- Expiring links and manual deletion for security
- QR code for installation
- Recipient email notification
- Pricing: /month, .99/6 months, .99/year for extended expiry

Target users:
- Mobile developers needing TestFlight alternative for quick QA feedback
- Digital agencies wanting branded client preview portals
- Enterprise teams for internal employee app deployment

Design philosophy: 'Best Beta App, iOS App, Android App Distribution Services' — positions itself as a simpler, faster alternative to App Store/TestFlight review processes.
