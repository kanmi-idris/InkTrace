Core library claims captured from the public page:

- Redraw is described as a 2D graphics library built on top of WebGPU.
- It supports:
  - variable strokes
  - colors along paths
  - physically based renderings
  - vector feathering
- Vector feathering is described as enabling fast blurs without a rasterization step.

Programming model notes captured from the public page:

- The page emphasizes TypeScript functions compiled and executed on the GPU.
- Examples use `"use gpu"` inside functions.
- Stroke width and color can vary along path geometry using context values such as `ctx.t` and tangents.

Rendering-pipeline notes captured from the public page:

- The docs explicitly contrast Redraw with typical 2D pipelines that require offscreen textures for backdrop filters.
- The page claims `pushLayer` and `popLayer` are evaluated analytically inside the same render pass.
- It says feather, clip, and tint are folded into SDF math with no offscreen target and no separate rasterization step.

Interpretive note:

- This source fits the React Native and graphics notes as an experimental GPU-native 2D rendering approach, especially for path-driven visuals, blur-like effects, and single-pass analytical rendering ideas.
