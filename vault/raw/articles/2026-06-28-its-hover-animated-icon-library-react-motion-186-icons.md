# Its Hover — Animated Icon Library (React + Motion, 186+ Icons)

Its Hover (itshover.com) — an open-source animated icon library built with React and Motion (motion/react). Created by Abhijit (@abhijitwt).

Key features:
- 186+ animated SVG icons, categorized: UI essentials (arrows, checks, navigation), Social (GitHub, Twitter, Discord, LinkedIn), Tech (Docker, Node.js, Python, TypeScript), Actions (copy, send, cart, settings), Currency (Bitcoin, Ethereum, Dollar, Rupee), Status (alerts, notifications, loading states)
- Motion-first design: every icon animates on hover interaction, built with motion/react
- Drop-in React components compatible with Next.js, shadcn, and modern tooling
- Fully customizable: source available, modify animations, adjust stroke width and colors
- Apache 2.0 license

Installation:
- Via CLI: npx shadcn@latest add https://itshover.com/r/[icon-name].json
- Manual: npm install motion, then copy any icon component from icons/ directory

Tech stack: Next.js 16, React 18+, motion/react, Tailwind CSS 4, shadcn/ui components.
