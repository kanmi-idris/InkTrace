# Searchata MCP tool reference snapshot

Captured: 2026-11-01
Source URL: https://searchata.com/docs/tools
Publisher: Searchata

The tool reference describes 20 read-only tools across search, analytics, page performance, and backlink research. It recommends resolving the connected property before making source-data requests.

The docs describe tools for listing Search Console properties, reading Bing site and crawl details, performance comparisons, SEO opportunities, URL inspection, content guidelines, PageSpeed audits, Chrome UX Report data, and backlink research. The docs state that Searchata does not offer competitor keyword analysis. Backlink lookup can query a public target domain without a connected property.

Data tools require an active trial or paid plan. Searchata documents per-workspace call limits, concurrency limits, source-provider limits, performance quotas, report caching, and crawl credits. Some account and property-specific tools require a connected source. The docs describe plan and credit limits for crawls and performance data.

## Evidence limits

This is a publisher tool reference. Tool names, quotas, and plans may change. I did not authenticate to the MCP endpoint or call any tools.
