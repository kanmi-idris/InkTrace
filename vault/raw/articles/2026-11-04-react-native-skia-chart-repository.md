## Project description and features

The README describes `react-native-skia-chart` as GPU-rendered, animated charts for React Native and Expo, built on React Native Skia and Reanimated. The maintainer calls it a modern successor to `@rainbow-me/react-native-animated-charts`.

The README advertises 15+ chart types and 18 components. Its listed chart families include line, area, sparkline, bars, histograms, pie/donut, scatter, bubble, radar, candlestick/OHLC, heatmap, gauge, and progress rings. It also documents touch scrubbing, selection, zoom, gradients, shadows, glow, blur, color filters, blend modes, path effects, and SkSL shaders.

## Setup requirements

The README instructs users to install `react-native-skia-chart`, the unscoped `react-native-skia`, Reanimated, Worklets, and Gesture Handler. It explicitly warns not to install `@shopify/react-native-skia` for this package because it says that package stops at 2.x. The chart library requires a development build and does not run in Expo Go.

The docs list peer requirements: React >=19, React Native >=0.79, react-native-skia >=3.8.0, Reanimated >=4.0.0, Worklets >=0.7.0, and Gesture Handler >=2.20.0. The docs specify Android minSdk 26 with Vulkan 1.1 and iOS 15.1+.
