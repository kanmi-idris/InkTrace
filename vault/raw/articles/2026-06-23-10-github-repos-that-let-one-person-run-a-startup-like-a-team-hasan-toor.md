## Overview
Curated tweet thread (June 22, 2026, 20.7K views) by Hasan Toor listing 10 open-source repos that replace entire roles/functions in a startup, enabling solo founders to operate like a team.

## The 10 Repos

1. **Windmill** (github.com/windmill-labs/windmill) — Turn any script into internal app, workflow, webhook, cron job, approval flow, or admin panel. Ops layer replacing Zapier + Retool + Slack scripts.

2. **Papermark** (github.com/papermark/papermark) — Open-source DocSend. Share decks/proposals/contracts/investor updates, track who opened what and which pages they viewed.

3. **Lago** (github.com/getlago/lago) — Billing engine for SaaS: subscriptions, usage-based billing, metering, credits, invoices, add-ons, revenue analytics.

4. **Unkey** (github.com/unkeyed/unkey) — API key management: create/revoke keys, rate limit, track usage, protect endpoints.

5. **Langfuse** (github.com/langfuse/langfuse) — AI observability: track prompts, costs, latency, traces, evals, datasets, model outputs.

6. **Novu** (github.com/novuhq/novu) — Notification infrastructure: email, SMS, push, in-app, chat, digests, preferences, workflows.

7. **Formbricks** (github.com/formbricks/formbricks) — Customer research: product surveys, NPS, onboarding questions, churn surveys, in-app feedback.

8. **Dittofeed** (github.com/dittofeed/dittofeed) — Lifecycle marketing: customer journeys across email, SMS, push, WhatsApp, Slack.

9. **Infisical** (github.com/Infisical/infisical) — Secrets manager: API keys, DB passwords, certs, env vars, credentials in one place.

10. **OpenReplay** (github.com/openreplay/openreplay) — Session replay + product analytics: watch user sessions, rage clicks, errors, flow abandonment.
