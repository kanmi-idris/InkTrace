README and docs highlights captured from the public pages:

- `mapcn` is described as free and open-source, ready-to-use, customizable map components for React.
- The project is built on MapLibre GL, styled with Tailwind CSS, and intended to work seamlessly with `shadcn/ui`.
- The docs page describes the project as “copy-paste map components for React.”
- The documented philosophy follows the `shadcn` model: copy the components into your project, own the code, and avoid lock-in.
- The docs emphasize staying close to raw MapLibre APIs so teams can drop down to the underlying map instance when needed.
- Claimed feature areas include:
  - theme-aware light/dark adaptation
  - zero-config defaults
  - composable components
  - markers and popups
  - routes
  - controls
  - arcs and clusters
  - TypeScript support
  - support for any MapLibre-compatible tile provider
- The docs explicitly say no API keys are needed for the default free map-tile setup.
- The README notes a basemap licensing caveat: CARTO basemaps have different commercial and non-commercial terms, and users can switch to OpenStreetMap or other MapLibre-compatible providers.
