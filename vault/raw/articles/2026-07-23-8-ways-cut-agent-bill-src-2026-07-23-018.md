# 8 Ways to Cut Your Agent Bill

**Source:** Pasted text (X/Substack post)
**Author:** Unknown
**Date:** ~Jul 2026

## The Eight Strategies

### 1. Prompt Caching
- System prompt and tool schemas never change between calls → stop paying full price for them.
- Payoff: the moment you have more than one turn, which is always.

### 2. Model Routing
- Send classification, extraction, formatting to a small model. Keep frontier model for the hard step.
- Payoff: when most of your calls are not the call that actually needs the intelligence.

### 3. Skip the Model Entirely
- Parsing dates, regex checks, sorting lists — code does this for free and never hallucinates.
- Payoff: every time you catch yourself asking a model to do arithmetic.

### 4. Early Exit
- Stop the loop when the check passes instead of running to the turn cap by habit.
- Payoff: when your loop has a real success condition (it should).

### 5. Retry Budget
- Two attempts, then hand to a human. The third try rarely differs from the second.
- Payoff: when a failing run can quietly retry all night.

### 6. Tool Result Cache
- The same file read twice in one run returns the same bytes — stop paying for both.
- Payoff: when your agent walks the same repo or hits the same endpoint repeatedly.

### 7. Batch What Is Patient
- Nothing running overnight needs to be instant. Queue it and send as one batch job.
- Payoff: backfills, evals, and anything nobody is waiting on.

### 8. Cap the Output
- Ask for JSON, not prose. Output tokens cost more than input tokens, and prose is mostly filler.
- Payoff: anywhere the answer is consumed by code rather than read by a person.

## Key Quote

"The cheapest token is the one you never send. The second cheapest is the one you send once. Most bills are not one expensive call — they are the same cheap call ten thousand times."
