# CSS tip: remove mobile tap highlight

Captured from user-supplied text on 2026-04-30.

No canonical source URL was provided with the capture.

---

This one line of CSS will make your website feel more native.

On mobile, tapping on clickable elements triggers a blue highlight.

CSS shown in the supplied text:

```css
html {
  -webkit-tap-highlight-color: transparent;
}
```

Claim from the supplied text:

- This removes the mobile tap highlight and can make the site feel more native.
