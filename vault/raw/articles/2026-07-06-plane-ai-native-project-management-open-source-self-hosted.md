# Plane — AI-Native Project Management (Open Source, Self-Hosted)

Plane (plane.so) — AI-native project management platform. Open source, cloud or self-hosted (on-prem, air-gapped).

Four products in one workspace:
1. Projects — project management with initiatives, epics, cycles, progress rollups
2. Wiki — internal documentation tied to work items
3. Plane AI — AI agents that take real assignments; reads across projects, cycles, docs, threads
4. Desk (coming soon) — customer support integrated with project management

AI capabilities:
- Answers from across workspace (query status, blockers, changes)
- Built-in agents for triage, assignment, blocker tracking, automatic updates
- Slack/Teams integration — @Plane in Slack to create work items, assign, sync back
- Native MCP server for AI agent integration

Enterprise features:
- SOC 2, ISO 27001, GDPR, CCPA
- SSO, SAML, LDAP
- Self-hosted via Docker, Kubernetes (Helm charts)
- Prime CLI for install, configure, upgrade, backup, monitor
- God Mode admin panel
- Uptime SLA, automatic backups

Developer features:
- Plane Compose — Projects-as-Code (define in YAML, version in Git, deploy from terminal)
- REST API (OAuth 2.0), webhooks (HMAC-signed), SDKs (Node.js, Python)
- MCP Server for AI agents
- Open API, OAuth apps
- 50+ integrations: GitHub, GitLab, Slack, Sentry, Figma

Pricing: Pro, Business, Enterprise tiers. Free to get started.

Views: Board, Spreadsheet, List, Gantt. Real-time dashboards (velocity, workload, blockers, scope changes).

Customer logos: Sony, Aramco, Dolby, Accenture, Amazon, French Republic, Government of Lithuania.
Case studies: FortyAU (replaced Monday + Trello), MinimalArt (replaced ClickUp), VATES, INITS.

Migration support from: Jira, Linear, ClickUp, Asana, Monday.com. Two Fortune 10 companies migrated from Jira.

Mobile apps: iOS and Android (works with both cloud and self-hosted instances).
Desktop apps: macOS and Windows.

GitHub: github.com/makeplane/plane
