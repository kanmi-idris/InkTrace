# Open Lovable — AI-Powered React App Builder

**URL:** https://github.com/firecrawl/open-lovable
**Stars:** 27.5k
**Forks:** 5.3k
**License:** MIT
**Author:** Firecrawl (firecrawl.dev)

Chat with AI to build React apps instantly. Clone and recreate any website as a modern React app in seconds. An example app by the Firecrawl team (for the complete cloud solution, see lovable.dev).

## Setup

Requires Firecrawl API key + an LLM provider key (Gemini, Anthropic, OpenAI, or Groq). Supports sandbox providers: Vercel (default with OIDC or PAT) or E2B. Optional Morph API key for faster edits ("fast apply").

## Tech Stack

- Next.js (TypeScript)
- Tailwind CSS
- Bun/pnpm

## Key Features

- Chat interface to generate React apps
- Website cloning/recreation from URL
- Multiple AI provider support
- Sandboxed preview (Vercel or E2B)
- Fast apply mode for quicker iterations
