Evidence inspected: public homepage text and visible component catalogue. Pricing and install actions were not opened or performed.

## Product description and installation model

- The website presents SnapCN as a registry of Remotion components for React product-demo videos.
- It says to install source using the shadcn CLI, with an example: `npx shadcn@latest add @snapcn/text-reveal`.
- It states that source lands in `components/snap-cn/`, that the code can be edited, and that there is no SnapCN runtime.
- It says the components use the Remotion API and that Remotion is needed to use them in a user's own project.

## Website counts

- The homepage states there are 46 free components.
- The footer states that the 46 components are MIT licensed and lists 51 Pro components.
- Free-component category counts displayed on the homepage: Text & Titles 14; Captions 2; Logos 5; Screens & Devices 6; Social Proof 2; Scenes 11; AI Chat Input 6.
- These categories sum to the website's stated 46 free components.
- The GitHub README lists 21 components. The inspected sources do not explain the difference. Do not assume one count is stale or that the lists refer to the same set.

## Pricing banner
