## Framework description

- The page describes One as a React framework for full-stack apps across web and React Native, with shared code and file-system routing.
- It says One targets React Native and web with one framework, replacing Metro plus a separate web framework for the described use case.
- It says One runs on Vite for web and uses Rolldown for native builds.
- The page lists typed file-system routes, loaders that tree-shake away on the client, per-page SSG/SSR/SPA/API render modes, JavaScript preloading, and a production server.
- The page describes use cases for cross-platform apps and web-only or native-only projects.

## Data-layer statement

- The page says One recommends Zero as its first-class data solution.
- It says the current `npx one` starter sets up an early alpha of Zero, while a more official One/Zero integration is in progress.
- This is a time-sensitive statement on the page captured on 2026-10-12. It does not establish the maturity of One itself.

## Project acknowledgements

The page says One began as an experiment in porting Expo Router to vxrn, and acknowledges Expo Router, React Navigation, Software Mansion, Remix, Vite, and named contributors.
