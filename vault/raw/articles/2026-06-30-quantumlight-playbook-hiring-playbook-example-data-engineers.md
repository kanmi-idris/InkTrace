# QuantumLight Playbook — Hiring Playbook Example: Data Engineers

Concrete example of hiring playbook for Data Engineer role at scale-up (by QuantumLight/Revolut).

Core skills (all engineers regardless of specialization):
- Software Lifecycle — managing project stages from conception to retirement
- Architecture — designing system structure and organization
- Programming (General) — writing and creating software
- Problem-solving — breaking down complex problems from first principles

Specialized skills for Data Engineers:
- Programming (Python)
- Data Engineering — design, construct, maintain data pipelines/infrastructure
- Infrastructure (IaC, Cloud) — cloud environments, configuration, optimization

Seniority expectations defined per skill level. Skills assessed via structured scorecards with observable behaviours. Minimum thresholds across all areas.

Sourcing guidelines: filtering criteria for quick profile screening.

Hiring process: stages designed to gather structured signals across core skill areas, no duplication between interviews. Scorecards enable independent evaluation and fast debriefs.
