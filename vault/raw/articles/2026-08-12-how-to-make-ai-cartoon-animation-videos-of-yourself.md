## Core workflow
The tutorial presents a five-part system for AI cartoon production:
1. Choose a visual style.
2. Build consistent character sheets.
3. Create scene images with the characters.
4. Generate or lock character voices.
5. Animate scenes and maintain continuity.

The demonstrated workflow uses OpenArt for image and video generation, GPT Image 2 for image generation, Seedance 2 or 2.5 for video, and Hailuo as another possible video model. The speaker also mentions Claude for converting audio references into MP4 files with a black background, and Premiere Pro or Claude for stitching clips.

## Style and character sheets
The tutorial describes a website with more than 30 cartoon styles and reusable prompts. The creator chooses a style and generates a three-panel character sheet from a character image, a blank three-panel template, and a copied style prompt.

The character sheet is used as a reference for likeness and design. The tutorial warns the image model not to copy the reference layout, poses, panels, or background when creating a scene.

## Scene generation
The scene prompt is structured around:
- Output format, such as a 16:9 frame.
- Reference-map explanations for each input image.
- Scene description.
- Camera framing.
- Visual style.
- Details to preserve, such as outfits and proportions.
- Elements to avoid, such as extra characters, text, logos, multiple panels, or a character-sheet layout.

The tutorial uses a stable medium-wide eye-level shot for one example. The generated still image becomes a start frame or reference for video generation.

## Video prompts
The tutorial describes timeline prompts for short scenes. A prompt states what happens during each part of the clip and includes:
- Dialogue.
- Voice prompts.
- Character and visual continuity instructions.
- Audio or dialogue controls.
- Avoidance instructions such as no zooms or cuts when a static cartoon shot is intended.

The example uses a 13-second scene and 1080p output.

## Voice consistency
The tutorial describes two approaches:
1. A text voice prompt repeated in every generation. The example describes pitch, energy, rasp, cadence, and cartoon tone.
2. An audio reference generated or recorded for the character. The audio can come from a recording, ElevenLabs, or Fish Audio. The tutorial converts the audio into an MP4 with a black background so it can be supplied as a video reference to OpenArt without adding visual scene information.

The tutorial recommends reusing the same voice reference across shots. It reports that this produced similar or consistent voices across separate generations.

## Scene continuity
The tutorial presents two continuity methods:
1. Use the last frame of the previous video as the start frame of the next video.
2. Upload the previous video as a reference and prompt the next clip from it.

The speaker considers the second method less reliable in one example because object scale changed between frames. More references may improve consistency. The clips can then be stitched in Premiere Pro or with an AI assistant.
