# React Navigation 8.x Native Stack header item documentation snapshot

Captured: 2026-10-15
Source URL: https://reactnavigation.org/docs/8.x/native-stack-navigator/

## Header item options

The docs list `visibilityPriority` for iOS 27 and later. It sets the priority of a header item when right-side items do not fit. Items with lower priority move to the overflow menu first. Supported values are `low`, `default`, and `high`.

The docs list `description` for action and submenu items. It is secondary text displayed beside the item's label.
