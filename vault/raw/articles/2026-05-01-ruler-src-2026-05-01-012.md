README highlights captured from the public page:

- The plugin helps analyze how much each module and dependency contributes to total app size.
- It supports Android App Bundle analysis with configurable device assumptions such as ABI, locale, screen density, and SDK version.
- It can verify app size against thresholds such as download size and install size.
- It adds `analyze<VariantName>Bundle` tasks for app variants.
- It generates both HTML reports and JSON reports.
- It supports an ownership model through a YAML file so teams can see size contributions by owner.

- `ruler-frontend` is the HTML-report frontend.
- `ruler-models` contains shared models.
- The repository also includes frontend tests and end-to-end tests.
