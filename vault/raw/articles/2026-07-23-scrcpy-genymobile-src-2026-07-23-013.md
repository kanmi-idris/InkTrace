# scrcpy — Display and Control Android Devices

**Author:** Genymobile (maintainer: Romain Vimont @rom1v)
**License:** Apache-2.0
**Stars:** 146,000 | **Forks:** 13,500 | **Watchers:** 1,400
**Latest release:** v4.1 (Jul 12, 2026)
**Commits:** 3,139
**Languages:** C (63.1%), Java (32.7%), Roff, Shell, Meson, AIDL

"Display and control Android devices connected via USB or TCP/IP. It does not require root access or an app installed on the device."

## Key Focus Areas

- **Lightness**: native, displays only the device screen
- **Performance**: 30~120fps, depending on device
- **Quality**: 1920×1080 or above
- **Low latency**: 35~70ms
- **Low startup time**: ~1 second to first image
- **Non-intrusive**: nothing left installed on Android device
- **User benefits**: no account, no ads, no internet required
- **Freedom**: free and open source (Apache-2.0)

## Features

- Audio forwarding (Android 11+)
- Recording to MP4
- Virtual display (separate from device screen)
- Mirroring with device screen off
- Copy-paste in both directions
- Configurable quality (codec, resolution, bitrate, fps)
- Camera mirroring (Android 12+)
- Webcam output via V4L2 (Linux)
- Physical keyboard/mouse simulation via HID (UHID)
- Gamepad support
- OTG mode (USB debugging not required)
- Touch emulation
- Fullscreen mode, window management

## Supported Platforms

- Linux
- Windows
- macOS

## Architecture

- **C client** (SDL2, FFmpeg/libav) — receives and renders video/audio streams
- **Java server** (runs on device via ADB) — captures device display/audio
- **Meson build system**
- **ADB tunnel** for USB or TCP/IP transport
- No root required — uses Android's `MediaCodec` and `SurfaceInput` APIs

## Notable Usage Examples

```bash
# Basic mirroring
scrcpy

# High quality H.265 at 1920x60fps with physical keyboard
scrcpy --video-codec=h265 -m1920 --max-fps=60 -K

# Virtual display running VLC
scrcpy --new-display=1920x1080 --start-app=org.videolan.vlc

# Camera recording to MP4
scrcpy --video-source=camera --video-codec=h265 --camera-size=1920x1080 --record=file.mp4

# OTG mode (no mirroring, just HID control)
scrcpy --otg

# Gamepad support
scrcpy -G
```
