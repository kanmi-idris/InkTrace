# Duo Studio: iPhone Duo mockup studio

## Observed tool
Duo Studio is an interactive mockup tool for a foldable iPhone Duo. Its page offers Render and Figma display modes. Users can add images to the inner display, optional folded display, and outer display. Device controls include hinge angle, Night Sky or Star White finishes, auto-rotate, and a camera-cutout option. Scene controls include Paper, Graphite, and Clay backgrounds, plus studio lighting. Export options include 2048 px or 4096 px PNG and transparent backgrounds. Preset poses include Closed, Book, and Open.

## Relevance to UI design
This is a device-mockup and presentation tool. It can help present foldable-device screen states and hinge poses. It is not an app-screen gallery or a source of product UI patterns. The observed page provides device presentation controls, not a library of app examples.
