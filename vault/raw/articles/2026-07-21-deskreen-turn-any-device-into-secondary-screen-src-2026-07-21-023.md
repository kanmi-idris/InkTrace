Electron.js desktop app that uses WebRTC to stream your computer screen to any device with a web browser. Over 2M downloads in 5 years.

## Key Features
- **Share entire screen** to any browser device over WiFi
- **Second screen** — use any device as extended desktop (with Virtual Display Adapter)
- **Share single app view** — limit to one application window
- **Teleprompter mode** — Flip Screen Mode for video bloggers
- **Multiple connected devices** simultaneously
- **End-to-end encryption** via WebRTC + tweetnacl
- **Works off-grid** — local WiFi only, no internet needed
- **Cross-platform** — Windows, macOS, Linux (even Raspberry Pi)
- **Advanced quality control** — auto/manual quality adjustment

## Tech Stack
- Electron.js, TypeScript (88%), React
- WebRTC (simple-peer), Vite, electron-vite
- Electron Builder for packaging
- BlueprintJS UI components
- TestCafe for E2E testing

## System Requirements
- Windows/Linux/macOS
- 210MB disk, 250MB RAM (per session), any modern dual-core CPU

## Editions
- **Community Edition** (CE) — open source, limited features
- **Pro** — commercial version with additional features

## About
Created by Pavlo Buidenkov. Inspired by the need to use old iPad/tablet as second screen without buying new hardware. Works the same across all OS platforms.
