README highlights captured from the public page:

- The package targets iOS and Android only and is not built for React Native Web.
- The Android blur header effect relies on React Native `filter: [{ blur }]`.
- The README says Android blur requires React Native `0.76+` with the New Architecture (Fabric) enabled.
- On lower Android versions or unsupported setups, the blur layer becomes a no-op while toasts still render.
- On iOS, the implementation uses `expo-blur`.
