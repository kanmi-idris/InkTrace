## Positioning

Product landing page for React Native Enriched Markdown: “fully-native rich text solutions for React Native” — components for rich text rendering and editing that feel truly native.

## Core value props (from site)

### Truly native components
Not based on WebView — both renderer and editor use native text primitives. Text selection, accessibility, and platform gestures behave like system UI. CommonMark standard + many GFM features.

### Editor & renderer in one tool
- Render any Markdown as native text
- Users write with a native format bar; output is clean Markdown
- Use one or both components

### Customizable styles
CommonMark-compliant with customizable styles for tables, task lists, strikethrough, LaTeX math; powered by high-performance md4c parser.

### Works on Android, iOS, and macOS
Cross-platform experience; built on New Architecture for performance/reliability. (Web also supported per GitHub docs for the text renderer.)

## Key features called out on the site

1. **Native text and image interactions** — system menus: Translate, Look Up, Search Web, Share; iOS image context menu for copy / save to Camera Roll
2. **Rich text styling and link control** — bold, italic, links via native format bar; Markdown output; imperative API for styles and links
3. **Accessibility and RTL** — VoiceOver / TalkBack with semantic roles; system font scaling; full RTL layout
4. **Interactive links** — tappable links with custom callbacks
5. **Markdown streaming** — React Native Streamdown wrapper for progressive streaming render (LLM-style token stream UX)
6. **LaTeX math rendering** — inline and block; inline all flavors; block with GitHub flavor
7. **Mentions** — @mention support in the editor for people, channels, topics
8. **Web implementation** — share rich text experience across platforms (renderer)
9. **EnrichedMarkdownInput improvements** — roadmap for more formatting controls, customization, renderer parity

Note: landing copy sometimes says “Enriched HTML” in one subheading (“unlock rich text capabilities with React Native Enriched HTML”) — the product/repo name is Enriched Markdown; treat as marketing slip unless separate Enriched HTML product is confirmed.
