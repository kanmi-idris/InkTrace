# AndronixOrigin - Install Linux on Android

https://github.com/AndronixApp/AndronixOrigin — AndronixOrigin: official backend repository for the Andronix app. Install Linux distributions on Android devices via PRoot (user-space chroot) + Termux.

How it works: PRoot provides user-space chroot, mount --bind, and binfmt_misc without privileges. Termux provides the command line environment.

Supported Un-Modded OS (8): Ubuntu, Debian, Manjaro, Fedora, Kali, Void, Alpine, Arch
Desktop Environments: LXDE, LXQT, XFCE
Window Managers: Awesome, Openbox, i3
Modded OS (4, paid): Ubuntu XFCE, Debian XFCE, Ubuntu KDE, Manjaro XFCE

Andronix is partially open-source: free distro tarballs and shell scripts are open (MIT), Android app and Modded OS files are closed-source. Ad-free, free for un-modded distros. Modded OS and Andronix Premium (sync, web-app) are paid lifetime purchases.

Website: andronix.app, Docs: docs.andronix.app
