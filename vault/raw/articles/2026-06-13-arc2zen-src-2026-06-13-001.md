# Arc to Zen Browser Migration Tool

A complete Python-based migration tool that converts Arc browser spaces, pinned tabs, and open tabs into Zen browser workspaces with proper tab assignment.

## Quick Start

### Prerequisites

- Python 3.7+
- Arc Browser (with spaces and pinned tabs you want to migrate)
- Zen Browser (installed and run at least once)
- macOS or Windows (current implementation)
- `lz4` Python package for session tab injection

### Basic Usage

Run the complete migration:

```bash
python3 migrate_arc_to_zen.py --dry-run
python3 migrate_arc_to_zen.py
python3 inject_session_tabs.py
```

The README says that after the main migration, tabs may only appear as bookmarks or metadata until `inject_session_tabs.py` writes directly to `zen-sessions.jsonlz4`, which Zen reads to render real sidebar tabs.

## What Gets Migrated

- Arc Spaces -> Zen Workspaces
- Space Icons -> Workspace Icons
- Space Colors -> Workspace Themes
- Pinned Tabs -> Zen Pinned Tabs
- Essential Tabs -> Essential Pinned Tabs
- Open Tabs -> Zen Open Tabs
- Folder Hierarchy -> Zen Folder Structure
- Display Order -> Zen Sidebar Order
- Backup Bookmarks -> Firefox Bookmarks

## How It Works

The tool reads Arc's `StorableSidebar.json` to extract:
- Space names, structure, and icons
- Pinned tabs with URLs and metadata
- Open tabs per space
- Folder hierarchy within each space
- Visual ordering using container `childrenIds`

It also includes a workspace-mapping helper:

```bash
python3 src/zen_workspace_mapper.py
```

The README says this maps Arc spaces to Zen workspace UUIDs and writes `workspace_uuid_mapping.json`.

For Zen 1.18+, spaces, pinned tabs, and folders are written directly to `zen-sessions.jsonlz4`. For older Zen versions, the tool falls back to legacy `zen_pins` and `zen_workspaces` SQLite tables.

## Safety Features

- Read-only Arc access
- Automatic Zen backups before changes
- Dry-run mode
- Validation and integrity checks

## Notable Implementation Detail

The repository positions `inject_session_tabs.py` as the key step that turns migrated data into real Zen sidebar tabs, not merely bookmark-like artifacts. That makes this more than an export script: it is a storage-format bridge between two browser-specific workspace systems.

## Claimed Fidelity Features

- Preserves Arc display order using pinned-container `childrenIds`
- Migrates space icons as Unicode emojis
- Migrates space colors using extracted RGB values and Zen workspace theme JSON
- Migrates Arc Essential tabs with workspace associations

## Limitations

- Current implementation supports macOS and Windows
- Arc custom folder icons and colors are not preserved
- The repo is strongest as README-level operational guidance; public evidence here does not independently verify migration correctness across many real profiles
