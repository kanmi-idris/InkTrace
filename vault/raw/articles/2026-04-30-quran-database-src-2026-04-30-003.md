- The repository includes a `quran.sql.zip` file that contains the full database dump.
- The documented schema includes:
  - `quran_surahs` for metadata on all 114 surahs
  - `quran_ayahs` for the original Arabic text of every ayah
  - `quran_ayat_edition` for different editions and translations
  - `quran_addons` for additional metadata and author or scholar information
- The documented setup flow is:
  - `unzip quran.sql.zip`
  - `mysql -u <username> -p <database_name> < quran.sql`

  - frontend and app work such as browsing, audio playback, search, bookmarking, dark mode, and PWA support
