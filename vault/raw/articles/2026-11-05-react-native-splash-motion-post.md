## Verification note

The related repository supports Lottie JSON (`.json`) and dotLottie (`.lottie`) files. It requires React Native's New Architecture. Expo requires a development build; Expo Go is not supported. The README describes a loop-aware exit, optional outro, and fade, but this post's “Smooth transitions” claim was not independently tested. The operating system launch screen remains static before the app process starts; a supplied `--still` image is needed to show the first animation frame. [src-2026-11-05-002]
