"Tell your computer what to do, and it gets it done."

## Quick Start (Python Library)

```bash
pip install browser-use
# or: uv add browser-use
```

Set `.env`:
```
BROWSER_USE_API_KEY=your-key
```

```python
import asyncio
from browser_use import Agent, ChatBrowserUse

async def main():
    agent = Agent(
        task="Find the number of stars of the browser-use repo",
        llm=ChatBrowserUse(model='openai/gpt-5.5'),
    )
    history = await agent.run()

asyncio.run(main())
```

## Architecture

- **Agent** — main class that takes a task + LLM + optional browser + tools
- **ChatBrowserUse** — LLM provider abstraction supporting all major model providers
- **Tools** — decorator-based custom tool system (`@tools.action`)
- **Controller** — internal agent controller for browser actions

## Cloud vs Open Source

| Feature | Open Source | Cloud |
|---------|-------------|-------|
| Cost | Free + LLM | Paid |
| Control | Full code-level | Hosted API |
| Stealth | Basic | Proxy rotation + CAPTCHA solving |
| Scaling | Manual | Auto-scaling |
| Integrations | User-managed | 1000+ (Gmail, Slack, Notion) |
| Persistence | Local | Persistent filesystem + memory |

## FAQ Highlights

- **CLI vs Python lib:** CLI for one-off agent tasks, Python lib for repeatable automation
- **Best model:** `ChatBrowserUse()` with default `bu-*` models (3-5x faster)
- **Free:** Yes, open source. Choose your own LLM provider.
- **Production:** Use Cloud API for scalable browser infrastructure
- **CAPTCHAs:** Use Cloud for stealth browsers + proxy rotation
