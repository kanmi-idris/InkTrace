## Page Description
Predict React Native text heights before rendering. Native TextKit/TextPaint measurement plus very fast JS layout arithmetic. Positioned for FlashList, streaming AI chat, pinch-to-zoom text, obstacle-aware reflow, Dynamic Type, and Expo Web.

## Captured Text Excerpt
expo-pretext presents itself as a missing text-layout primitive for React Native. The README says it combines one native text measurement pass with cached JS layout arithmetic so text can be measured before render and reflowed around arbitrary shapes while still rendering through normal React Native Text and View components.

The README highlights several capabilities:
- Text reflow around circles, rectangles, and arbitrary polygons.
- Exact text heights before render for FlashList and other virtualization scenarios.
- Per-frame layout recomputation fast enough for gestures, physics, or animation-driven relayout.
- Streaming AI chat support through incremental measurement.
- Continued use of the regular React Native rendering tree so accessibility, Dynamic Type, selection, copy and paste, VoiceOver, RTL text, and emoji handling still work.

The installation notes state that the package requires Expo SDK 52 or newer, React Native 0.76 or newer, and the New Architecture or Fabric. Reanimated is optional and only needed for the animation hooks. Expo Go falls back to JS estimates, while development builds are needed for native measurement.
