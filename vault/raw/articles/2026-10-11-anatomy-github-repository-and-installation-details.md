# Anatomy GitHub repository and installation details

## Source scope
This is the public `wheresryan22/anatomy` repository README as displayed on 2026-10-11. The project is described as an open-source Claude Code skill and Agent Skills-compatible folder. Claims are from the project owner.

## Runtime and install details
- The README lists Node 20.10 or later and says the kit uses Node's built-in modules, with no dependencies and no API keys.
- The recommended Claude Code install command is `npx skills add wheresryan22/anatomy -g -a claude-code`. The README also gives project-local and Git clone options.
- After installation, the README's example invokes `/anatomy` with a technical explanation prompt.
- I did not run the install command, download the repository, or generate a figure.

## Output types and project claims
The README describes three output types: standalone SVG/HTML, SVG plus WebGL shaders, and true 3D, which is marked beta. It says results can also be built as React/Next.js components. The README says source code is provided with the generated figure.

The repository is MIT-licensed. It includes example projects such as `dial-indicator`, `desk-computer`, `arcade-cabinet`, `raptor-engine`, `ripple-tank`, `test-rig`, `spot-plate`, and `turning-dial`. The README says the repository has 33 figures/examples.

## Limits
The README also labels 3D as beta. It says the turning-dial example rebuilds parts in true 3D and notes that the 3D geometry audit is slow. See the creator's skill page for stated time estimates and further limitations in `src-2026-10-11-010`.
