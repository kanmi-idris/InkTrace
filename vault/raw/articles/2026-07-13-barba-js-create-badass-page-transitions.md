### What it is
A small (7kb) library for creating fluid, smooth transitions between website pages. Makes multi-page sites behave like an SPA — reduces delay between pages, minimizes HTTP requests.

### Features
- Simplified API — written in TypeScript, works with Promises
- Cross-browser support (progressive enhancement)
- DOM flexibility — custom markup, namespaces, data attribute schema
- Hook system — lifecycle methods for Transitions and Views
- Transition resolution — rules for picking the right transition
- Sync mode — leave and enter hooks can play together
- Page-specific logic — custom logic per View
- Plugin system — official plugins available
- Built-in utilities
- 73+ contributors, Slack community
