# Kinetics - Spring-Physics Motion Library by Colorion

https://kinetics.colorion.co/ — Kinetics: a library of 135 spring-driven interface animations. Built on spring physics instead of fixed-duration easing. Every effect ships three ways: CSS, React, and a copy-paste AI prompt, alongside live stiffness/damping readouts.

Key interaction categories (45/135 shown):
- Card Resize, Magnetic Button, Number Counter (spring bump), Toast Overshoot, Tab Pill Glide
- Accordion Spring (max-height + rotating chevron), Drag to Dismiss (radial fade-out)
- Ripple Feedback, Hold to Confirm (SVG progress ring), Rubber-band Slider
- Like Burst (particle ring), Cursor Trail, Push Button (tactile depress, pure CSS)
- Star Rating, Floating Label (pure CSS), Copy Button (icon crossfade)
- Quantity Stepper, Choice Chips, PIN Input, Password Meter, Pointer Tooltip
- Swipe to Reveal, Rotary Knob, Reorderable List, Expanding Search, Squish Button
- Toggle Pills, Value Scrubber, Speed-Dial FAB, Swatch Picker, Slide to Unlock
- Tag Input, Keycap Press, plus CSS-only: Orbital Action Menu, Contextual Dock (:has()), Inertial Dial, Elastic Lasso

Physics tunings: spring(stiffness, damping), overshoot(), glide(), friction(), decay(), hold(), rubber(), burst(), trail(), lerp(), press(), snap, stagger, tween.

Part of Colorion ecosystem (colorion.co). GitHub: github.com/ckissi/kinetics
