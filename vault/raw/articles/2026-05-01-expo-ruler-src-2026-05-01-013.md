Repository positioning:

- `expo-ruler` is described as an Expo config plugin that configures Spotify Ruler for Android projects generated with `npx expo prebuild`.
- The repo positions itself as a way to wire Android app-size analysis into Expo workflows rather than as a standalone analyzer.

README highlights captured from the public page:

- Install with `npx expo install expo-ruler`.
- Add the plugin to `app.json` under `expo.plugins`.
- Use Gradle tasks such as `app:analyzeReleaseBundle` after prebuild.
- Reports are written to `android/app/build/reports/ruler/release/` as both HTML and JSON.
- Custom variant tasks can be listed via `./gradlew tasks --group="Ruler"`.

Compatibility note captured from the README:
