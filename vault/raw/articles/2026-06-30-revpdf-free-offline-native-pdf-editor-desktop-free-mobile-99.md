# RevPDF — Free Offline Native PDF Editor (Desktop Free, Mobile .99)

RevPDF — free, offline, native PDF editor by solo developer Pawandeep. Built in Flutter + C++, ~30MB installer. Desktop permanently free, mobile $9.99 one-time. 70k+ downloads, 4.6★ Play Store. Product Hunt featured.

Platforms: Windows, macOS, Linux (native), Android, iOS.

Philosophy: No accounts, no cloud, no subscription, no telemetry, no data collection. 100% offline — every operation runs on-device CPU.

18 professional tools (all local):
- Content editing (text & images directly in PDF)
- True redaction + auto-redact (permanently removes sensitive content, not just overlay)
- Annotations (highlight, underline, comments, hyperlinks, bookmarks)
- Draw & markup (freehand pen, shape tools)
- Form builder (text fields, checkboxes, dropdowns, radio groups; auto-detection)
- Form filling (tab through, save, no print-and-scan)
- Electronic signing (draw, type or import; reusable)
- Compression (no visible quality loss)
- Split & merge (mid-page split vertically/horizontally)
- Watermarks (text or image)
- Conversion (PDF↔images, PDF→Word beta)
- Page organization (reorder, rotate, delete, drag-and-drop)
- OCR (offline, scanned docs → searchable text)
- Find & replace (bulk text edits)
- Tabbed viewer (multiple PDFs side-by-side)
- Metadata editor (title, author, subject, keywords)
- Links & bookmarks
- Document scanning (auto edge detection, perspective correction)

Latest version: v4.5.0 (Jun 2026) — auto-redaction, tab view.

Blog: "How I built a 30 MB PDF editor" — story of writing RevPDF 10× smaller than industry standard.

Comparison: Outperforms cloud-based editors (100% offline, no account), subscription editors (free desktop vs $12-25/mo), and built-in OS viewers (full editing).
