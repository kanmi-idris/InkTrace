# Hijacker: Android Wi-Fi Auditing Interface

Source checked: 2026-09-27.

## Scope
- Hijacker is a graphical Android interface for several wireless auditing tools, including Aircrack-ng, Airodump-ng, MDK3, and Reaver.
- The project requires an ARM Android device, root access, and a wireless interface that supports monitor mode.
- The repository states that the application is discontinued while a new iteration is developed.

## High-level capabilities
- The interface can observe nearby access points and client stations, display signal and manufacturer information, and save capture files.
- It provides filters, sorting, aliases, exports, background operation, and device-specific wireless support.
- The project also exposes active wireless-auditing and password-recovery functions through the bundled tools.

## Safety and evidence limits
- The source states that use against networks without permission is illegal and may damage devices when firmware changes are wrong.
- This record does not reproduce attack commands, cracking procedures, wordlists, firmware steps, or targeting instructions.
- Treat the repository as legacy software. Do not assume current Android, chipset, firmware, or tool compatibility.
- No build or runtime test was performed.
