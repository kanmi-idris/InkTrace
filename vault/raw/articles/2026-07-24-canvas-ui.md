# Canvas UI

GitHub - DavidHDev/canvas-ui: open source library of creative, framework-agnostic components drawn on canvas. Fluid simulations, shader effects, and 3D scenes running over live, interactive HTML.

Built on experimental html-in-canvas API (Chrome/Edge 140+) — WebGL effects read and redraw live DOM. Text stays selectable, links clickable, page becomes a texture for fire, fluid, glass distortion. Degrades gracefully to WebGL overlays on unsupported browsers.

Features:
- 24 components: Liquid, Blaze, Glass, Shatter, VHS, Particle Reveal, and more
- Framework agnostic: React, Vue, Svelte, vanilla JS builds for every component
- shadcn-compatible registry: npx shadcn@latest add @canvas-ui/liquid-react
- MCP ready — point shadcn MCP server at registry, AI assistant installs components
- Zero config, self-contained, typed props

Install: npx shadcn@latest add @canvas-ui/<component>-<framework>
Source lands in components/canvasui/ in your project.

Stack: Next.js 16, Tailwind v4, deployed to Cloudflare Workers.
