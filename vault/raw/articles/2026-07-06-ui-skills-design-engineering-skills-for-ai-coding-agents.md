# UI Skills — Design-Engineering Skills for AI Coding Agents

UI Skills (ui-skills.com) — A collection of design-engineering skills for AI coding agents, created by ibelick (Interface Office). Star on GitHub: 3.5k+.

Designed for agents to choose the right skill before making UI changes. CLI entry point: `npx ui-skills start`.

Collection of 18 skills (as of landing page):

1. ui-skills-root — Routing skill: directs to the smallest useful set of UI skills by topic, stack, and intent
2. baseline-ui — Quick UI polish: spacing, hierarchy, typography, layout fixes
3. fixing-accessibility — ARIA labels, keyboard nav, focus management, color contrast, form errors, WCAG compliance
4. fixing-motion-performance — Layout thrashing, compositor properties, scroll-linked motion, blur effects, animation jank
5. frontend-design — Production-grade frontend interfaces (by anthropics)
6. wcag-audit-patterns — WCAG 2.2 audits with automated testing, manual verification, remediation (by wshobson)
7. emil-design-eng — Emil Kowalski's design-engineering philosophy for UI polish, components, animation (by emilkowalski)
8. react-doctor — React Doctor: detect regressions in security, performance, correctness, architecture (by millionco)
9. shadcn — Project-aware shadcn/ui workflow for searching, adding, composing, fixing components (by shadcn-ui)
10. make-interfaces-feel-better — Design engineering principles for micro-interactions, typography, visual details (by jakubkrehel)
11. design-lab — Interactive design exploration: interviews, variants, UI refinement through feedback (by 0xdesign)
12. ui-ux-pro-max — Comprehensive UI/UX with 50+ styles, 97 palettes, 9 tech stacks (by nextlevelbuilder)
13. interface-design — Dashboards, admin panels, SaaS apps (by Dammyjay93)
14. 12-principles-of-animation — Disney's 12 animation principles for web interfaces (by raphaelsalaja)
15. impeccable — Flagship design skill for production-grade anti-generic frontend (by pbakaus)
16. bencium-innovative-ux-designer — Production-grade frontend with creative polished code (by bencium)
17. gpt-tasteskill — High-agency UX/UI with strict layout variance, typography, GSAP motion constraints (by Leonxlnx)
18. frontend-slides — Animation-rich HTML presentations from scratch or PPT/PPTX conversion (by zarazhangrui)

Publishes a registry at ui-skills.com/skills/registry.txt. Has agent-specific pages for Claude Code, Cursor, OpenClaw, Codex, GitHub Copilot.

Topics: Accessibility, Motion, Systems, Visual, Interaction, Performance.
