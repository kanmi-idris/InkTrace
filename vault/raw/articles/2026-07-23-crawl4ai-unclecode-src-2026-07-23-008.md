"Crawl4AI turns the web into clean, LLM ready Markdown for RAG, agents, and data pipelines."

## Origin Story

Author grew up on an Amstrad, specialized in NLP in grad school, built crawlers for research. In 2023, needed web-to-Markdown — the "open source" option wanted an account, API token, and $16, and still under-delivered. Built Crawl4AI in "turbo anger mode" in days. It went viral. Now the most-starred crawler on GitHub.

## Quick Start

```bash
pip install -U crawl4ai
crawl4ai-setup
crawl4ai-doctor
```

```python
import asyncio
from crawl4ai import *

async def main():
    async with AsyncWebCrawler() as crawler:
        result = await crawler.arun(url="https://www.nbcnews.com/business")
        print(result.markdown)

asyncio.run(main())
```

CLI: `crwl https://example.com -o markdown`

## Architecture

- **AsyncWebCrawler** — main async crawler with Playwright backend
- **BrowserConfig** — headless, proxy, user data dir, persistent context
- **CrawlerRunConfig** — cache mode, extraction strategy, markdown generator, hooks
- **ContentFilterStrategy** — PruningContentFilter, BM25ContentFilter
- **MarkdownGenerationStrategy** — DefaultMarkdownGenerator
- **ExtractionStrategy** — JsonCssExtractionStrategy, LLMExtractionStrategy
- **DeepCrawlStrategy** — BFS, DFS, BestFirst with crash recovery

## Anti-Bot Detection (v0.8.5)

3-tier detection:
1. Known vendor blocks
2. Generic block indicators
3. Structural integrity checks

Automatic retry with proxy chain and fallback fetch function.
