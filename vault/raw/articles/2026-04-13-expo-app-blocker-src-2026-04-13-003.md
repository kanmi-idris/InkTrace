## Captured Text Excerpt
`expo-app-blocker` is described as an Expo plugin for app-blocking workflows that aims to remove the usual native setup burden around iOS Screen Time APIs, iOS extension targets, entitlements, Android overlays, and Android manifest wiring.

The supplied feature summary claims the plugin provides:
- An inline system app picker embedded in the app UI.
- A customizable shield screen with icon, colors, text, and blur style.
- Temporary unlock with an automatic relock timer.
- Three iOS extensions auto-generated during prebuild.
- Android foreground service and overlay support out of the box.
- A full TypeScript API.

The positioning claim is that developers can install the package and configure it through Expo config rather than touching Xcode project setup or AndroidManifest wiring manually.
