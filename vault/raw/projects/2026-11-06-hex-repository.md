## What the repository says

The user-supplied shortlink `https://t.co/Vpd33iZ8dw` resolves to the Hex repository. The link appears in a separate X reply by `@tom_sloan_3`, not in Elliot Arledge's Phonon link list.

The README describes Hex as local voice dictation for Mac, Windows, and Linux. It says users hold a key, speak, and release it to paste text. It says the first run downloads a speech model and later processing stays on the user's machine. The README lists an MIT license.

The X reply calls Hex “TTS,” but the README describes dictation. This is a separate project from Phonon. I did not download, install, or run it.
