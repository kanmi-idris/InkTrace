# LFM3-Omni-2B model card audit

## Sources

- Hugging Face model card: https://huggingface.co/LiquidAI/LFM3-Omni-2B
- Liquid AI documentation: https://docs.liquid.ai/lfm/models/lfm3-omni-2b

## Published model details

The model card describes LFM3-Omni-2B as one end-to-end model for text, image, video, and audio input. It can produce text, speech, or interleaved text and speech. The card lists 2.17 billion parameters, a 32K-token context, and a non-reasoning architecture. It describes the model as designed for on-device use.

The model card says the model can perform speech recognition, speech synthesis, translation, audio understanding, visual question answering, and video understanding. This supports the model's documented capabilities. It does not verify the X posts' speed, latency, iPhone, browser, or offline claims.
