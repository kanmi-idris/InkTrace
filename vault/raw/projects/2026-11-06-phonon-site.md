# Phonon product site

## Source

- https://phonon.sh/

## Site claims

The site describes Phonon as local voice typing and says audio, transcripts, dictionary terms, and screen context stay on the Mac. It says there is no cloud account. It describes the macOS app as signed and notarized, with model weights downloaded on first launch.

The site labels Windows as a beta. It says Windows speech recognition and correction run on the CPU without an account or cloud service. The README provides more detail on its Windows beta setup and requirements; see [src-2026-11-06-002].

## Limits

These are product-site claims, not an independent privacy or security audit. I did not download or run the app.
