# munim-maps

## Project description
The repository describes `munim-maps` as a MapKit-based map and 3D overlay library for Expo and React Native. It also provides a Swift Package. The README says it uses React Native Nitro modules and lists an Apache-2.0 license.

## Maps and models
- `MunimMapView` provides a MapKit map with 3D models. `MapModelLayer` can draw over another MapKit map. The README specifically describes using it over `react-native-maps` on iOS.
- The README lists a built-in catalogue of 57 animated or recolourable 3D models, including vehicles, aircraft, rockets, satellites, and people.
- The README says developers can supply USDZ, USD, glTF/GLB, SceneKit, OBJ, PLY, STL, or Alembic models.
- Described features include real-coordinate anchoring, building occlusion, and terrain-aware placement.
