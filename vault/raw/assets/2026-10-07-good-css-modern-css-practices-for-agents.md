# Good CSS

## Product description
Good CSS is a public reference site and agent skill for opinionated modern CSS techniques. The site presents 47 live examples across eight categories: Foundations, Layout, Spacing and shape, Text and media, Interaction, Motion, Show and hide, and Scroll and viewport.

The repository says each practice explains when to use it, shows CSS, explains why it works, lists rules, and credits its source. The techniques use CSS declarations and values, so the author says they can fit plain CSS, Tailwind, StyleX, or other authoring systems. The repo contains a separate skill file and one generated reference file per category.

Examples shown include logical properties, OKLCH colors, fluid `clamp()` scales, focus-visible styles, reduced-motion-aware transitions, and CSS-only layout or interaction patterns. The skill says to check browser support for the target project.
