# React Native clothing rack

## Post claim
Mehdi says the clothing rack is rendered with WebGPU on React Native Skia's Graphite backend. The thread credits @cambreedesigns as inspiration. The post thanks @wcandillon. Its video link resolves to the X post's video. I did not inspect the video.

## Linked build page
Motionary describes the app as a 3D clothing rack with simulated garments that can be browsed, lifted, rotated, and brought into focus. The page lists React Native Skia, React Native, and Expo. It describes a WGSL renderer on Skia v3's WebGPU device and a cloth simulation. The page lists a 4.11 MB app with five drops. It offers this build for $32 and a lifetime bundle for $79.

## Evidence limits
The implementation details and prices are statements on Motionary's product page. I did not run the demo or inspect its visuals. The X post is a showcase, not independent validation of performance or compatibility.
