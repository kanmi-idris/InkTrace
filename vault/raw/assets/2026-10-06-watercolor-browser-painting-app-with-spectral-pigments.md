# Watercolor Playground

## User-shared description
“Open sourced a new vibe coded thing: a watercolor app for the browser 🎨

Pigments mix as spectra. Washes bloom and dry with tide lines. It can trace any SVG with a brush, write in 58 single-stroke fonts, and flood-fill with a wash.

Open source: http://github.com/msurguy/watercolor-playground . Enjoy and share!”

## Repository and live app
The GitHub repository describes Watercolor as a browser painting app. The live GitHub Pages app loaded during inspection. The README says visitors can use a mouse, touchscreen, or stylus. It does not require an install to use the hosted app.

The README describes spectral pigment mixing, wet-paper bleed, hard edges on dry paper, 14 brushes, SVG tracing, wash fill, 10 paper types, reference images, history, and PNG/JPEG/WebP export. It says the project is built with TypeScript, WebGL2, and Preact.

The live Text tool showed 58 font options. The README describes its lettering as single-line plotter fonts. The live app exposes Brush, Water, Pen, Lift, Text, Shape, and Fill tools. It also lists hand painting through webcam input. I did not enable the camera.

## Licensing and project status
The repository is public on GitHub. I did not find a license file or a license field in the inspected README or `package.json`. The package metadata sets `private` to true. The app is publicly readable, but explicit open-source reuse rights are not confirmed by the inspected files. GitHub showed no published releases at inspection time.

## Evidence limits
I inspected the README, repository file list, package metadata, and hosted app UI. I counted the font options in the live text selector. I did not paint, install the project, inspect all source code, or test browser and device compatibility. The claims about paint behavior describe the app's intended simulation; I did not validate them against real watercolor.
