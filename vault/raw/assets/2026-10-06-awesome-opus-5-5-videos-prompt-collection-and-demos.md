# Awesome Opus 5.5 Videos

## Post claim
Aymen says a repository contains more than 475 Claude Opus 5.5 video demos and prompts. The post's video link resolves to the X video. I did not inspect it. A same-author reply links to the repository.

## Repository details
The repository calls itself a growing collection of videos and prompts. It says there are 475 prompts, 100 highlighted examples, and creator links for every entry. Its README says the videos were made by asking Claude Opus 5.5 to write animations as code, including HTML, Canvas, SVG, and Three.js. It lists motion graphics, explainers, 3D scenes, and games. The README says its latest update was 2026-09-29 and added 86 videos.

## Evidence limits
These counts and model attributions are repository-maintainer claims. The links to creator posts provide a path for further checks. The collection itself does not independently establish that each example used the stated model.
