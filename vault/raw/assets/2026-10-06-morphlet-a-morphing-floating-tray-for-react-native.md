# Morphlet v0.1.2

## Post and repository
The post announces Morphlet v0.1.2 and links to its public GitHub repository. The post and two same-author replies link to Android preview videos. I did not inspect the videos.

The README describes Morphlet as a native, morphing floating tray for React Native. It provides trigger, content, header, body, footer, and view components. It supports morph, slide, fade, and scale transitions, plus smooth, snappy, and bouncy animation presets. The README lists an MIT license.

## Requirements
The README says Morphlet requires React Native's New Architecture and Android API 24 or later. Expo projects need a development build. For iOS, the setup instructions include `npm install morphlet` and `cd ios && pod install`.

## Evidence limits
I inspected the README only. I did not install Morphlet, verify the v0.1.2 release, or inspect the preview videos. Compatibility and animation quality remain untested.
